# 회계감사 통합 학습자료

이 폴더는 원래 폴더의 PDF 8권과 Markdown 기준서 36개를 LLM 위키의 원자료로 사용할 수 있도록 Markdown으로 통합·정리한 결과다.

## 시작점

먼저 `00_통합_목차.md`를 읽는다. 서로 다른 교재의 단원 체계를 감사기준 번호와 감사 수행 흐름으로 통일하여, 각 주제와 관련된 모든 자료의 원문 페이지를 연결해 두었다.

## 폴더 구조

- `01_감사기준`: 기준서 원문을 주제별로 묶은 자료. 정의·목적·요구사항 확인에 우선 사용한다.
- `02_기본이론`: 감사 절차의 전체 흐름과 핵심요약. 개념 설명과 구조 이해에 사용한다.
- `03_문제연습`: 주제별 연습, 고급 사례형, 필수암기 및 OX 문제. 기준을 사례에 적용할 때 사용한다.
- `04_기출문제`: 주제별·연도별 기출문제와 해설. 답안 구조와 반복 출제 논점을 확인할 때 사용한다.
- `99_완전성_검증.md`: 모든 결과물의 UTF-8·구조·링크와 원본 페이지 수, 페이지 순서, 텍스트 공백, 의심문자 검사 결과.
- `99_문자_판독_검토대상.md`: 자동 교정 후에도 문맥 확인이 필요한 한자형 OCR 후보의 파일·페이지·행별 목록.
- `99_괄호_검토대상.md`: 열린 괄호와 닫힌 괄호가 대응하지 않는 후보의 파일·행별 목록.
- `99_문맥_교정_기록.md`: 기준서 용어와 반복 문장 합의를 이용해 수정한 문맥상 오탈자의 누적 기록.

## 원문 검색·응답 우선순위

1. 기준서 원문의 정의와 요구사항
2. 기본이론의 해설과 절차 흐름
3. 주제별 문제의 사례 적용
4. 기출문제의 답안 표현과 출제 패턴

자료 간 표현이 다르면 기준서 원문을 우선한다. 다만 개정 전 기출문제는 해당 연도의 출제 맥락을 보존하고 있으므로 삭제하거나 최신 표현으로 임의 치환하지 않았다.

## 원문 보존 원칙

- 모든 PDF는 원문 페이지 순서를 유지하고 `원문 페이지` 구분자를 넣었다.
- 중복되는 문제·설명도 누락 방지를 위해 삭제하지 않았다.
- 이미지 전용 또는 문자맵이 깨진 PDF는 300dpi 한국어 OCR로 변환했다.
- 텍스트가 비거나 지나치게 짧은 페이지는 별도 이미지 OCR로 다시 검사했다.
- 반복되는 명백한 OCR 오류는 다른 교재와 기준서의 정상 용어를 대조해 교정했다.
- 같은 교정 규칙과 구조 검사를 기준서 통합본·목차·README·QA 보고서를 포함한 모든 결과물에 적용했다.
- 정상일 수 있는 영문 약어·숫자·한자·수식은 임의로 삭제하지 않았다.
- 표와 도식은 Markdown에서 읽기 순서대로 선형화되어 있다.

## 추가 가치와 출처

이해상충 추가 안전장치는 2018·2019년의 구체 요구와 연결된다. 기존 기출의 일부 선택을 전체 다섯 장치 요구로 확장했다. 의무교체는 2014·2023년의 구체 요구와 연결하되, 회사 유형별 요소를 합하여 고유 출제횟수로 세지 않았다. 제2의견 안전장치가 필요한 이유를 묻는 기출을 안전장치 목록 자체의 직접 빈도로 사용하지 않았다. 그 밖의 기준서 물음은 현재 정본·초안의 요구와 대조하여 추가했으며, 과거에 한 번도 출제되지 않았다고 단정하지 않았다.

낮은 감사보수·계약서 내용·기본 통제무력화 절차와 직전 배치의 경영진주장·중요성 지표 등은 중복되어 제외했다. 선택·비교 기록은 [조사 장부](research.json), 전체 탐색 범위는 [비교 목록](comparison-inventory.json), 기출 관계는 [원발문과 대응 검토](coverage-review.json)에 남겼다.

- 감사기준서: [KICPA 2026년 7월 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06). 별도 시험 적용연도를 확정한 것은 아니다.
- 윤리기준: [2024-12-19 의결 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=ethstd03&bltnNo=11735541549550&fileSeq=2&subId=sub06). [2026-09-02 개정 공개초안](https://daejon.kicpa.or.kr/board/list.brd?boardId=ethstd02)은 확정 기준으로 적용하지 않았다.
- 법규: [국가법령정보센터 외부감사법 제9조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1028002685), 법률 제20896호·2025-04-01 시행, 2026-09-13 확인. 이사·소속공인회계사 교체를 감사인인 회계법인 자체의 교체와 구별했다.

[공식 발췌·계보](sources/provenance.json), [페이지 시각 대조](sources/visual-review.json), [raw 수집 색인](../../raw/collections/2026-09-13-standard-expansion/index.md)에 원문과 해시를 보존했다.

## 검증 결과

- 담당 agent가 15물음·65개 기준의 원문, 발문, 모범답안, 배점과 부분답안 기대값을 대조했다. [내용 검토 장부](agent-review.json).
- 형상·인용·기존/배치 내 충돌, 정본과 직전 초안을 포함한 메모리 검증, 독립 물음 투영, 공개 투영의 비공개 답안 제거 및 빈 답안의 무호출 0점 확인을 통과했다. [사전 검사](preflight.json).
- **Luna 실제 채점 45건: 43건 정확 일치, 45건 모두 ±1점 이내.** 사전에 정한 모범답안·부분답안·오답 각 15건을 모두 분모에 포함했다. 저장 모범답안은 15건 모두 만점이었다.
- 부분답안 2건은 각각 1점 낮게 평가되었다. 문맥상 생략한 대상 표현을 모델이 요구한 편차이며, 기대점수와 원답안을 유지했다. [원인·수락 근거](discrepancy-analysis.json). 이 편차를 없애기 위한 반복 호출은 하지 않았다.
- 실제 응답 45건의 요청·응답 ID 및 사용량을 보존했다. 입력 135,099토큰, 출력 13,994토큰(추론 2,749 포함), 캐시 읽기 0토큰이다. 금액은 계산하지 않았으며 0달러로 표시하지 않는다. 별도 유료 의미검수는 수행하지 않았다.

실제 채점 실행은 [run-v1](grading/run-v1/summary.json)에 고정한 문항·실행 코드 스냅샷으로 남았다. 응답 재생 검사는 실제 모델 응답의 저장·합산을 확인하는 로컬 검사이며 추가 모델 호출이 아니다. 분석·wiki·raw 검사는 [마무리 확인](completion-checks.json)에서 별도 확인한다.

## 파일 관리

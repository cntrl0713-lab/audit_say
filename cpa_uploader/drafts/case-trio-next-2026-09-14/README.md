각 작성자 폴더의 sets는 승급 전 초안이며, design·review·qa와 출처파일은 실제 사실 의존성·배점과 대표 답안의 기대값을 기록한다. [교차검토 A](a-peer-review.json), [B](b-peer-review.json), [C](c-peer-review.json)는 작성자와 다른 agent의 내용 검토다. 사람의 직접 내용 확인 또는 별도 API 의미검수로 기록하지 않는다.

서면진술과 다른 증거의 충돌, 왜곡표시의 질적 중요성 및 상계, 내부감사기능 활용과 직접적 보조의 경계를 가상의 구체 사실로 재구성했다. 기출·고급회계감사연습의 해당 원발문·해설과2026 공식 기준서 전문을 대조했으며 실제 시험문제를 그대로 옮긴 것으로 표시하지 않는다. 교재 재수록을 새 출제로 세지 않았다.

부분정답은 충족한 독립 의미단위의 정수 점수를 합산한다. 올바른 근거가 판단을 명확히 함축하면 판단도 인정하며, 명시적 반대 결론은 그 판단 점수를 주지 않는다. 독립적으로 옳은 근거까지 일괄 감점하지 않는다.

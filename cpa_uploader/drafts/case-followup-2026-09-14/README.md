# 사례형 후속 제작 6개

사용자 확정 범위는 사례 6개·각 3물음, 사실관계 400자 이상이다. 기출·고급회계감사연습의 원물음과 현행 공식 기준서를 대조해 기존 사례와 구별되는 적용 조건을 구성한다.

`bank-before.json`, `catalog-before.json`, `classification-before.json`은 제작 시작 당시 정본 224세트·474물음과 분류의 보존본이다. `source-catalog.json`은 시작 당시 출처 탐색 단위의 스냅샷이다. 새 출처가 등록되면 별도 후속 스냅샷을 사용하며 시작 파일을 덮어쓰지 않는다.

`a/`, `b/`의 `sets.json`, `design.json`, `review.json`, `qa.json`에 초안, 출처·중복 대조, agent 검토, 실측 전 대표 답안 기대값을 보존한다. 실행·승급·운영 배포의 상태와 증거는 [검토 배치](../../analysis/reviews/case-followup-2026-09-14/README.md)에서 확인한다.

## 최종 상태와 조회

6사례·18물음의 제작·내용 검토·Luna 실제 채점·정본 및 운영 DB 반영을 완료했다. 초안 파일의 `needs_review`는 보존 당시 상태이며, 현재 게시 상태는 정본과 [게시·배포 증거](../../analysis/reviews/case-followup-2026-09-14/README.md)를 따른다. [전체 문제와 모범답안](questions-and-answers.md), [결과 보고](../../../docs/reports/case-followup-2026-09-14.md)에서 최종 내용을 확인할 수 있다.

`a/`는 기중 실증·특정항목 추출·보고 문안, `b/`는 통제 표본·추정 소급검토·그룹감사 증거를 다룬다. [A 독립 검토](a-peer-review.json), [B 독립 검토](b-peer-review.json), [공식 PDF 출처 검토](source-peer-review.json)는 역할과 최종 입력 해시를 구별해 기록했다.

KGA 540의 새 직접 발췌를 반영한 최종 출처 탐색 입력은 `source-catalog-v3.json`이다. 초기본·중간본과 [원자료 수집](../../raw/collections/2026-09-14-case-followup/index.md), [PDF 페이지 이미지](../../raw/collections/2026-09-14-case-followup-pages/index.md)를 보존했다. 2022 교재의 기출변형은 실제 기출 원발문과 구별하며, 재수록을 새로운 출제 빈도로 세지 않는다.

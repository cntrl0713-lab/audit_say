# 사례 분량·물음 수 보강 제작 배치

`bank-before.json`·`catalog-before.json`·`classification-before.json`은 시작 당시 정본과 학습 분류의 보존본이다. `source-catalog.json`은 기존 등록 원자료를 읽은 카탈로그이며 수집 자체나 파일 해시가 공식성·문항 검수 완료를 뜻하지 않는다.

`a/`, `b/`, `c/`는 기존 사례 23개의 보강을, `root/`는 새 사례 2개의 제작을 담당한다. 각 폴더의 `sets.json`은 문항, `design.json`은 실제 출처 단위·판본 가정·기출과 고급연습 대조 및 사실 연결, `review.json`은 담당 agent 내용 검토, `qa.json`은 실행 전 정한 대표 답안과 기대값이다. 별도 유료 의미검수나 사람 확인으로 표시하지 않는다.

통합과 실제 채점·게시 증거는 [후속 검토 장부](../../analysis/reviews/case-expansion-2026-09-13/README.md)에 남긴다. 공식 전사와 학습자료의 원 파일 및 과거 실행은 원래 경로·바이트로 보존한다.

최종 통합·채점·운영 반영을 완료했다. [최종 보고서](../../../docs/reports/case-expansion-2026-09-13.md)와 후속 검토 장부에서 단계별 실제 결과를 확인한다. 작성 당시 초안의 needs_review 상태는 제작 이력으로 보존했으며, 현재 게시 상태는 정본과 새 승급 장부를 따른다.

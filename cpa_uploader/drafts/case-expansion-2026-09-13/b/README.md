# 사례 보강 B

담당 8개 기존 사례를 각각 2개 사례형 물음으로 보강했다. 사실관계 본문은 공백·줄바꿈 포함 583~646자이며 제목·발문을 포함하지 않았다. 총 16물음·45점으로 기존 사례형 8물음의 19점과 새 적용 물음 8개의 26점이다.

| 파일 | 내용 |
| --- | --- |
| `sets.json` | 순수 사례형 교체안 8개. 기존 ID·기존 사례 criterion ID·배점 유지, 신규 `exp1` 추가 |
| `design.json` | version 1 출제 계획, 기존 기준서형 별도 보존 대상, 사실 대응, 실제 기출·고급연습 읽은 위치 및 카탈로그 단위 |
| `review.json` | 전 16물음의 사실 의존성·직접 근거·모범답안·독립 부분점수에 관한 agent 내용 검수 |
| `qa.json` | 대표 부분답안·오답 31개. 모범답안은 문항의 `model_answer`를 사용 |
| `validation.json` | 초안 인용·형상 검사와 메모리 교체 은행 검증, 계획 형상 검사 결과 |
| `build.mjs` | 수동 제작 내용과 근거를 산출물에 반영한 로컬 작성 스크립트. 모델 호출 없음 |

기출·고급연습은 발문·사례 구성의 설계 근거이다. 정답과 criterion은 공식 전사를 직접 대조했다. 13-011의 하위서비스·보충통제는 두 자료군의 급여 서비스조직 문제와 **인접**한 확장이며, 그것을 기출이 직접 요구했다고 기록하지 않았다. 기출 해설에 남은 옛 315의 유의적 위험 목록은 현재 고유위험요소의 공식 근거로 사용하지 않았다.

검수 중 재고 `exp1`은 판단·설계·실행·유지 각 1점, 서면진술 `exp1`은 대상기간·책임근거·의견거절·미제공 근거 각 1점으로 수정하여 독립 부분정답을 복원했다. 06-008의 고아 명칭 '상황 B'를 정리하고 재고 12월 입출고 시점을 과거 발생으로 명료화했다. 12-010의 진술 단순 문구 변형은 미제공으로 단정하지 않는 조건을 유지하며, 신규 상황 B는 전체기간의 명백한 진술 거절로 구별했다.

실행한 검사:

```text
node --import tsx cpa_uploader/validate_draft_v3.ts --file cpa_uploader/drafts/case-expansion-2026-09-13/b/sets.json
validateAuthoringBank(bank-before에 담당 8개만 메모리 교체): errors=[]
validateQuestionAuthoringPlan: 8개 모두 errors=[]
```

메모리 검사에서는 제외한 기준서형을 다시 붙이지 않았다. 그 기준서형은 총괄이 별도 저장 묶음으로 보존·통합한 뒤 최종 은행 검증한다. 실제 Luna 채점·승급·공개본 생성·운영 DB 반영은 총괄 단계이며 이 디렉터리의 agent 검수는 유료 API 또는 사람 확인을 주장하지 않는다.

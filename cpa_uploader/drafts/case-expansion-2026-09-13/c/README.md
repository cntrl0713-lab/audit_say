# 사례 보강 담당 C

7개 기존 사례를 16개 사례형 물음, 총41점으로 구성하였다. 사실관계 본문은 공백 포함 602~669자이며 모든 사례가2개 이상 물음이다. 기존 사례형의34점·criterion ID를 보존하고, 기타정보·이자비용·의견거절 책임단락에7점을 추가하였다. 기존 기준서형은 root가 별도 세트로 보존한다.

- `sets.json`: 순수 사례형 교체 초안. `needs_review` 상태로서 게시본이 아니다.
- `design.json`: 실제 원자료 단위, 원문 페이지·행·파일 해시, 기출·고급연습 적용 범위, 공식 원문·의존 문단, 사실-물음 연결, 기존 criterion 계보 및 v1 출제 계획.
- `review.json`: agent가 직접 수행한16물음·41criterion의 원문·발문·답안·조건·배점 검토. 실제 모델 채점은 root 통합 실행 대기.
- `qa.json`: 대표 부분정답14개와 오답16개. 함축 결론을 제거했다고 오인한 부분정답을 사용하지 않는다. 1점물음2개는 오답만 있다. 저장된 모범답안은 각 물음 만점으로 별도 검토하였다.
- `build.mjs`, `evidence.mjs`: 수동 저작·검토 기록을 산출하는 재현 도구. 생성기를 통한 source packet 또는 독립 모델 의미검수를 수행한 것으로 표시하지 않는다.

검사: `validate_draft_v3.ts --file .../c/sets.json`의 형상·원문 실존 검사 통과. 기준서형을 메모리에서 독립 보존한 전체 은행에 `validateAuthoringBank`를 실행하여 오류0개. 출제계획7개도 공식 v1 계획검증 통과. 이 정적 결과는 실제 모델 채점·운영 DB 반영 완료를 뜻하지 않는다.

# T08-C와 T13-A 전문가 업무 평가 배점 추가 비교

2026-09-11, 읽기 검토. 문항·점수 수정 0회. 비교 입력은 final-153-v3에 선택된 S02 `pilot-08-008/sub2`와 N04 `pilot-13-009/sub3`다.

**기존 c5를 가정·방법과 자료 두 범주로만 나누는 최소 제안으로는 현재 요구 전체의 편차가 충분히 해결되지 않는다.** T08-C는 세 영역을 안내하지만, c4/c5와 모범답안은 각 특성을 실제로 요구한다. T13-A가 ‘특성을 모두 제시’하는 전수 열거이고 T08-C가 사례 자료의 성격에 맞게 설명하는 적용형이라는 차이는 있다. 그러나 관련성·합리성·일관성·재무제표 반영은 서로 독립적으로 맞히거나 틀릴 수 있고, 자료의 완전성과 정확성도 같은 특성은 아니다. 경영진측/감사인측 전문가라는 주체 차이만으로 대등한 평가 특성을 1점 대 10점으로 압축하는 것은 설명하기 어렵다.

직접 원문 500 A59(`src-5aa72e77f5f4f9d048`, L571–581)는 c4의 네 특성과 c5의 가정·방법, 원천데이터, 외부정보 각각의 특성을 명시한다. 620.12의 T13-A는 이 중 발견사항·결론 3, 가정 2, 방법 2, 원천데이터 3을 합쳐 10점이다. T08-C에는 재무제표 반영 1과 외부 시장자료의 관련성·신뢰성 2가 추가되어 평가 범위가 오히려 더 넓다.

두 안 모두 단순 문장 길이 또는 ‘그리고’ 개수로 나눈 것은 아니다. 자료원이 다르면 평가 대상이 다르고, 같은 자료의 완전성과 정확성도 독립 반례가 가능하다는 점을 사용했다. ‘유의적으로 사용한 경우’ 같은 적용 조건, 관련 평가 주장이라는 목적, 수행 결과의 적합성이라는 상위 결론을 별도 점수로 추가하지 않는다. c3의 성격·범위·목적은 현재 비교 요청의 직접 대상인 620.12 평가 특성과 구분해 유지했다.

현재 c4/c5의 모든 특성을 필수로 유지한다면 상세 분리안 쪽이 논리적으로 맞다. 최소안은 전체 배점 제약 때문에 단계적으로 나누는 선택이며 완전한 원자화 해결로 보고하지 않는다. T08-C 54/54 QA 일치는 현재 묶음의 실제 채점 동작이 기대와 같다는 증거일 뿐, 학습·시험 배점의 균형이 적절함을 입증하지 않는다.

# API 중지 및 요소별 정수 배점 검토

사용자의 “일단 api채점은 멈추고 고려해줘” 지시를 총괄에게 전달받은 직후 새 API 호출을 전면 보류했다. 마지막 단일 스트림 세션 24918은 지시 확인 전 이미 exit 0으로 종료했다. 로컬 프로세스 조회에서 담당 실행 명령에 해당하는 node 프로세스는 없었다. 문항·배점·계획·공통 코드·고정 QA 파일 수정은 없다.

## 보존된 실행과 미실행 범위

- 담당 15세트 필수 작성자 QA는 835/835개의 고유 사례를 관측했다. 유효 채점 실행 1,033회 중 실제 모델 원시 판정 991회, 생산 빈답안 경로 42회다. 과거 실패 3회는 유효 관측에서 제외했다. 기존 완료 장부의 미해결 56사례는 모두 유효 관측 3회 이상을 갖는다. 이 숫자는 아래 T12 QA 정정을 반영하기 전 완료 장부 기준이다.
- 마지막 의미 단위 진단은 T06-B/sub1/crit3과 T05-B/sub3/crit5 각 2회다. 원 관측을 포함하면 두 단위의 source_support는 각각 fail/pass/uncertain, uncertain/pass/uncertain이며, 각 3회 모두 유효 응답이다. 새 raw와 원본 지시·입력 해시를 보존했다.
- T06-A/sub3/crit9은 원 유효 nonpass 1회와 새 HTTP 200 형상·인용 검증 실패 1회를 보존했다. 추가 예정 1회는 시작하지 않았다. 검증 실패를 유효 의미 판정으로 세지 않는다.
- T12-C/D의 총괄 승인 QA-only 정정 3건은 메시지로 승인되었으나 후속 파일 작성 전에 중지 지시가 도착했다. 새 QA·보충 대조답안·실측은 아직 없다. 기존 답안·QA·관측은 보존되었다.
- 현재 비교은행의 의미검수 생성 QA는 담당자 실행 0회다. T05-A 60사례/50고유 입력, T08-A 30사례/27고유 입력의 무호출 준비 검사만 완료했다. 아직 실측하지 않았다.

정량 기준은 [835사례 완료 장부](author-qa-completed-refill02-2026-09-11/owned-current-author-qa-evidence-index.json), 마지막 진단 큐는 [독립 진단 실행 장부](semantic-exact-diagnostics-refill02-independent-control/inputs.json)를 따른다. 이후 API 실행은 사용자의 재개 지시 전까지 보류한다.

## 현재 형상이 지원하는 배점

현재 `lib/questionV3.ts`는 1점 criterion에 partial을 허용하지 않고, 2·3점 복합 criterion에는 0과 만점 사이의 정수 partial 값 하나를 둔다. 따라서 3점 criterion 하나에 0/1/2/3의 모든 단계를 동시에 표현할 수 없다. 서술형의 독립 이해 부분마다 1점 criterion을 두고 합산하는 방식이 현 형상과 가장 잘 맞는다. 별도로 답할 수 있는 두 명제를 하나의 2점 criterion으로 묶는 형상도 가능하지만, 어떤 절반을 맞혔는지와 각 필수조건의 영향을 명확히 분리하려면 독립 1점 기준이 낫다.

## 정책상 함정

1. 단어 수나 접속사 수가 아니라 별도로 충족·실패할 수 있는 이해 단위로 나눈다. 이미 제공된 사실의 반복, 동의어, 사례 예시를 새 점수로 만들지 않는다.
2. 조건의 반대는 그 조건을 포함한 명제의 0점 사유다. 다른 독립 명제까지 연쇄적으로 0점 처리하지 않는다. 실제 반대와 단순 미언급도 구별한다.
3. 총괄이 확인한 T07-A의 통제환경 식별과 ‘변경과 관계없이 전기 증거면 충분’이라는 잘못된 효과는 별도다. 효과가 틀려도 통제환경을 올바르게 식별한 독립 점수는 보존한다.
4. 결론과 이유를 나누더라도 구체적 이유가 결론을 분명히 함축하면 결론 점수를 인정한다. ‘부적절’ 같은 정확어를 다시 쓰도록 요구하는 방식으로 부분점수를 구현하지 않는다. 실제 T10-C 및 T12-C의 관측 불일치가 이 위험을 보여준다.
5. 반대로 한 원인을 부정했다고 결과까지 자동 부정한 것으로 확대하지 않는다. T05-B의 경영진 지위라는 이유 부정이 미발견위험의 같음·역전을 진술한 것은 아니다.
6. 점수 분리는 답안 요구의 설계 변경이므로 총점만 늘리는 것과 다르다. 채택 후에는 criterion ID·계획 대응·원자료 관계·QA 기대와 검수 입력을 후속본으로 다시 맞춰야 한다. 현재 835사례의 관측을 변경된 배점의 검증 완료로 승계할 수 없다.

이 문서는 로컬 검토만 기록한다. 상세 사례는 [15세트 배점 검토](scoring-review-15-sets.md)와 [전문가 업무 평가 비교](scoring-review-t08c-vs-t13a-addendum.md)에 연결한다. 문항·배점은 변경하지 않았다.

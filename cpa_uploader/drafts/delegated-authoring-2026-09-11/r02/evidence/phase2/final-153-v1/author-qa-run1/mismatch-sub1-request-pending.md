# R02 요청 중인 서면진술의 포함 표현 오독

`sub1-request-pending`의 동일 입력·스키마 세 실행은 **6/7 → 7/7 → 7/7**이었다. 작성자 기대 7점은 유지한다.

1차 실제 모델은 “아직 받지 못한 서면진술도 … 이미 입수한 서면진술만을 뜻하지 않는다”를 “아직 받지 못한 서면진술만”으로 바꾸어 읽었다. 공식 KGA260.16(c)(ii)의 대상은 감사인이 요청하고 있는 서면진술이다. 포함 표현을 배타적 제한으로 판정한 것이므로 문항·답안·기대 점수의 결함으로 보지 않는다.

1차 `crit5`의 raw 판정은 `contradicted`, 실제 답안 인용은 유효했고 보안 결과는 `none`이었다. 최종 판정도 그대로이며 다른 여섯 criterion은 모두 1점이어서 합계는 6점이다. 따라서 인용·보안·합산 단계의 오류가 아니라 첫 의미 판정의 변동이다. 2·3차에서는 같은 criterion을 `met`으로 읽었다.

원시 판정·인용·trace·결과와 해시는 [조사 JSON](mismatch-sub1-request-pending.json)에 보존했다. 문항 입력을 바꾸지 않고 공통 지시 보완 뒤 새 증거로 동일 사례 세 실행을 확인한다. v1의 불일치를 후속 통과로 지우지 않는다.

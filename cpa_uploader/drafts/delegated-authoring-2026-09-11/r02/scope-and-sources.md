## 출처와 적용

2027년 CPA 시험을 목표로 하되 기본 사례는 2026-01-01 개시 보고기간이다. 260.8은 그 날짜 이후 개시 보고기간부터 시행한다고 명시한다. 금융위원회의 2027년 출제범위 공고가 기준서의 최종 판본까지 지정했다고 해석하지 않는다.

직접 근거는 [총괄 등록 공식 파일](../../../data/official/delegated-r02-kga260-2026.txt)이다. 260.16은 `src-f60ace40f5c68198f9`(PDF171쪽, L119–146), 260.17은 `src-6f2604a72e01ddac48`(PDF172쪽, L147–165)다. 원래의 `src260-16`·`src260-17`은 문항 내부 source ID였으며 위 실제 등록 카탈로그 ID로 연결했다. 과거 학습자료 `src-73fe85bf893193bbc1`·`src-b0ab9073ba65ae159e`는 학습·설계 근거로 남기고 공식 판본 근거로 표시하지 않는다.

[보관 2026년 PDF](../../frequency-gap-2026-09-10/sources/kga-2026-full.pdf)의 169·170·171·172·178–182쪽을 pypdf로 독립 추출해 기존 전사와 대조했고, 공백을 제외한 본문이 9쪽 모두 일치했다. 260.17의 인쇄 순서는 보관 2025년147쪽 화면으로도 확인했다. 공식 URL 재접속은 timeout이었으므로 이번에 새 PDF를 내려받았다고 주장하지 않는다. 파일 바이트 해시와 인용 문자열 해시는 [근거 장부](source-evidence.json)에 따로 기록했다.

[판본 대조](evidence/phase1/edition-paragraph-comparison.json): 260.8·13·16·17·A17–A32의 20개 문단 중 18개는 페이지 머리말·꼬리말과 공백 제외 후 일치했다. A28은 2025년의 '감사기준서 220에 따른 업무품질관리검토자'에서 2026년 '업무품질검토자'로 바뀌었다. 이 예시·용어는 이번 두 물음의 득점 명제가 아니며 기본 사례의 종전 220 적용을 유지한다. A30은 각주12가 (b) 앞에서 뒤로 이동했으나 본문 명제는 같다. A19–A20의 보론2는 PDF191–192쪽도 확보했다. 모든 의존 문맥이 두 판본에서 완전히 동일하다고 기록하지 않는다.

## 물음·criterion 대응

공통지문은 감사의 적용 보고기간만 제공한다. `sub1`은 260.16의 내용을 조건과 추가 설명까지 모두 요구한다. `sub2`는 상장기업에서 260.17이 요구하는 내용을 전부 요구한다. 모두 작성·순서 무관·개수 상한 없음이며 독립 명제는 각 1점이다.

## 빈도와 기존 요구의 차이

[실제 요소 자료](../../../analysis/question-elements/elements/05.md), [coverage](../../../analysis/coverage/topics/05.md), 현재 정본과 총괄의 data·drafts 전체 활성 목록을 대조했다. 상세 원출제 링크와 source unit은 T05-A 계획의 기록을 이어받는다.

- `element-b09df1c3d2cc54b3`: 기출0·확인 모의1(`mock:2023:GS3-6:1`)·독립 연습0·OX0. 고급 연습 원문212·323쪽의 재수록을 한 출제로 센다. 실제 units `src-7c2bb8ae4edc367f78`, `src-1c1ca36a9325219b86`. 예시 제외 요구이므로 전체 260.16을 묻는 sub1과 partial 관계다.
- `element-c5c0040a2c05d070`: 기출1(2019)·확인 모의0·독립 연습0·OX0. 원출제 `cpa_exam:2019:6:1`, 기출 해설A350쪽, `src-cfff47c9de850e2bcb`, 공통문맥 `src-7c74077ed21c20bc17`. 유의적 발견사항 '외'의 요구이므로 sub1 직접 빈도로 쓰지 않는다. sub2의 일부 대응 후보다.
- `governance.communication-benefits`: 기출2(2019·2023)·확인 모의0·독립 연습0·OX0. 대표 `cpa_exam:2023:2:6`, 해설A136쪽, `src-c4a1f75ec283a0442e`, 공통문맥 `src-80a120cf8dd7553698`. 양방향 효익이라는 다른 요구로서 두 물음에 adjacent다.

`pilot-05-001/sub1/crit1~crit2`는 부정 의심의 적시 전달과 추가 절차 논의, `sub2/crit2`는 법규상 제한의 법적 조언 고려다. `pilot-05-003/sub1/crit1~crit3`는 통제미비점 보고의 상대·시점·형태, `sub2/crit4~crit8`은 그 서면 내용이다. 새 260 전체열거와 직접 동일하지 않다. `pilot-05-007`은 이미 은행에 있는 부정 예외환경·해지 절차이므로 새 후보로 집계하지 않았다. R02는 별도 새 출제가 아니라 은행 밖 05-008의 초안 계속이다.

## 실제 검증의 한계와 다음 단계

현재 원본 기준으로 과거 receipt의 content·bank·context·source 해시와 사례 해시는 일치한다. 채점기 합성 해시는 변경되었지만 저장된 raw를 현재 코드로 재처리한 51회와 모든 612개 기대 판정 대조는 일치했다. 과거 '51/51'은 개별 모든 답안의 전체 점수를 독립 모델이 새로 검증했다는 표현이 아니다.

후속본의 적용시점·출처 문맥·검수 비교본이 바뀌므로 최종 입력과 같은 요청이라는 근거 없이 과거 모델 판정을 현재 실측으로 전용하지 않는다. [67행 QA](qa-cases-t05-a.json)는 모든 criterion의 모범답안·허용표현·누락·명시적 반대·범위 경계, 각 물음 빈답안 및 추가 정책·조건 경계를 포함한다. 누락 외 정상 명제도 모두 기대판정에 명시했다. 최종 모델 의미검수·실제 채점·필요한 3회 반복·수정 후 재채점은 비교은행 고정 후 수행한다.

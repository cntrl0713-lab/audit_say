# S01 수동 원문과 판본 증거

이 파일은 수동 저작의 원문 확인 증거이며 자동 source packet이 아니다. 실제 등록 source_refs와 version 1 계획을 사용하고, 검수 CLI에는 `--plan`만 전달한다. 생성 marker를 지우거나 불완전 packet을 complete로 꾸미지 않았다. 직접 근거와 필수 문맥은 문항 source_refs에 함께 넣어 실제 requestContext에 전달한다. 이 Markdown만 원문이 보관된 상태가 아니다.

2027년 CPA 시험 대비, 기본 2026-01-01 개시 보고기간을 적용한다. [총괄 판본 정책](../../../analysis/reviews/delegated-authoring-2026-09-11/edition-policy.md)의 공식 공고·개정 개요·정합개정 해석을 읽었다. 2026년 공표된 220은 종전 문단과 번호·책임체계가 다르며, 등록 회계법인의 2027-12-31 이후 개시/기타 감사인의 2029-12-31 이후 개시 시행을 보고서 발행일로 읽지 않았다. 사례 본문에서 개정 품질관리체계를 선제 적용하지 않는다고 명시하여 종전 220.5의 2026년 개시 적용과 19/20/25/A26을 사용한다. 다른 기준서의 모든 정합수정에 독립적 일괄 시행일이 공고되었다는 주장은 하지 않는다. 이후 시험당국의 특정 판본 지시가 확인되면 다시 대조한다.

[원전 비교](sources/paragraph-comparison.json)에는 선택47문단의 2025/2026 동일 번호 구간을 보존했다. 19구간은 공백 제외 동일하고, 200의 A51/A52/A55/A56/A57은 각주번호·각주 위치·참조표제의 변화가 있으나 이번 직접 명제의 본문은 유지된다. 220의23구간은 개정 체계와 다른 내용을 같은 번호로 비교한 기록이며 동등성 증거가 아니다. 종전19/20/25와 신판19/20/25를 바꾸어 쓰지 않았다. 각주·다음 소제목이 붙은 추출 구간은 직접 명제와 구별했다.

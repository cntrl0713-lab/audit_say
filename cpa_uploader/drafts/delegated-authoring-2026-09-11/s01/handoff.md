## S06에 전달할 확정 경계

`pilot-03-006`은 감사 종료 전 업무조건 변경의 정당성을 갑의 실제 오해와 을의 증거 부족·의견회피로 나누어 적용한다. 정당하지 않은 변경을 거절한 후 원래 감사도 허용되지 않는 상황에서 법규상 허용될 때 해지하고 다른 이해관계자에 대한 계약상·기타 보고의무가 있는지 결정한다.

근거는 기존 [N01 공식 파일](../../../data/official/delegated-n01-kga200-210-230-2025.txt)의210.14~15와 새 [S01 공식 파일](../../../data/official/delegated-s01-kga200-210-220-320-2025.txt)의210.16~17/A31~A35다. 공식2025년36,45~46쪽이며2026년 같은 해당 문단과 대조했다. S06는 중간재무제표 검토의 목표·질문 및 분석절차·감사와의 확신 수준 차이·검토보고 자체를 담당한다. 감사에서 더 낮은 확신 업무로의 전환이 자동 허용되는 것은 아니다.

210.A35의 수행업무·보고서 적합성 요구와 **관련서비스 보고서**에서 당초감사/수행절차를 언급하지 않는 원칙을 구별했다. 합의된절차 업무이고 절차 언급이 통상적인 경우에 한해 그 절차 언급의 예외가 있다. 이 예외를 원감사업무 자체의 언급이나 검토업무 전체 형식으로 확대하지 않는다. 새 조건 합의·기록은 병의 전제이며 기존03-003/sub2 복습 점수를 다시 부과하지 않았다.

`pilot-02-007`은 합리적 확신을 얻는 감사의 고유한계와 사후 수행평가다. 이를 S06의 제한적 확신이나 중간검토 결론으로 자동 치환하지 않는다. 법률상 책임·면책은 S01의 득점 요구가 아니다.

## 총괄 재개 조건

1. 전체49개가 준비된 실제 비교 은행·소스·코드·모델 설정을 고정한다. 현재 스냅샷의 ID/발문 충돌0은 최종 의미 중복 검토를 대신하지 않는다.
2. 세트별 version1 계획을 명시한 수동 `--plan` 경로로 실제 의미검수를 실행한다. 없는 source packet을 만들지 않는다. T01-B 계획에는 [개정220 시행표의 정확 인용](sources/edition-supplement.json)이 포함되어 판본 문맥도 모델 입력에 도달한다.
3. 공통 runner로 QA195사례를 실제 채점한다. 불일치·변동은 같은 설정으로 총3회 이상 확인하고 원문·발문·criterion·기대값·모델/인용/보안/합산 중 원인을 조사한다. 영향 사례를 최종 버전으로 재채점하고 모든 이전 증거를 보존한다.
4. 검토 종료와 문서화 종료, 함축된 판단, 관련서비스 절차언급 예외, 기계적 비율과 판단 결과 같은 비율, 부분 복습을 집중 확인한다. 미래 시험판본 변경이 확인되면 제한된 해당 범위를 재대조한다.

현재 공통 소스 추가 등록 요청은 없다. 원문47개 등록은 총괄이 완료했다. 과거 N01/N06의 완료 증거는 보존했고, N06의 추가 관계제안10건은 별도 `n06/coverage-proposal.json`으로 제출했다.

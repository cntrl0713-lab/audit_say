# T10-A 생성 기대의 전체 수동 대조 제안

[전체 비교](full-comparison-and-lineage.json)에 10단위·40사례·공식 인용4개와 현 은행의 관련 발문/criterion11개를 대조했다. 원40답안을 유지하고 q2.c4의 잘못된 `contradicted` 기대만 `met`으로 제안한다. 잘못된 표본규모 방향 c3과 올바른 추정 이유 c4를 분리한 실제1/1/1점 관측은 그대로다.

이 원 답안은 c4 자체의 반대가 아니므로 해당 종류를 충족한 것으로 확정하지 않았다. [별도 실제 반대 후보](additional-opposite-proposal.json)는 추정 목적 자체를 부정하는 새 답안이며, 기존 유효1점 답안과 관측을 없애는 대체물이 아니다. 실제 추가 실행은 사용자 중지 지시에 따라 수행하지 않았다.

[형상 교정된 미확정 입력](manual-input-proposal.schema-fixed.json)은 문서 파서를 통과했다. 첫 제안의 숫자 schema_version 오류는 원파일 보존 후 문자열 `1.0`으로만 고쳤으며 [계보](schema-envelope-followup.json)에 기록했다. manual-input 확정·사람 확인·새 모델검수 통과로 표시하지 않는다.

# T12-A 최초 일자 보존의 criterion 표현 후속본

[후속 문항](draft-12-560-freq01.json)은 q2.c1의 기존 함축 허용 기준을 주 claim에도 직접 적었다. 원문항·원 QA·원 계획은 보존했다. [계보와 diff](lineage-and-diff.json)에 이전/후속 SHA-256과 바뀐 두 경로를 기록했다. 그 밖의 필드가 동일함을 구조 대조했으며 2물음·7criterion·7점, 학생 발문·모범답안·원 QA 답안·기대점수는 같다.

변경은 560.A13과 이전 c1.scope가 인정하던 두 일자의 병존에 관한 설명이다. 최초 일자 후 절차의 한정 범위를 알리는 추가 일자 기재를 보존의 함축으로 인정한다고 주 claim에 직접 썼다. 최초 일자의 보존만 서술해도 1점이며 추가 일자의 의미를 별도 필수요건으로 요구하지 않는다. 최초 일자를 삭제하거나 대체한다는 명시적 반대는 계속 미득점이다. critical_facts의 scope도 같은 설명으로 맞췄다.

[기존 계획](../../draft-12-560-freq01.json.authoring-plan.json)은 재사용할 수 있다. 판본·사례조건·물음요구·독립 명제·출처·점수를 바꾸지 않은 표현 보완이기 때문이다. 다만 새 문항 SHA의 의미검수와 새 비교은행 반영 여부는 별도이며 옛 receipt를 현재 통과 증거로 바꾸지 않는다.

형상·인용 CLI 검사와 [전용 QA](qa-date-comparison.json) 정적 검사는 통과했다. 원 QA 5개를 변경 없이 추출했고 각 3회 [실제 재채점](phase-two-v4/run-01/summary.json)을 수행했다. 새 claim을 실제 모델 입력에 전달했으며 원시 응답·reason·trace·점수·실행 전후 해시를 보존했다.

| 사례 | 기대 | v4 후속본 관측 |
|---|---:|---|
| q2/omit-1 원 반례 | 5점 | 4/4/4점, c1 not_met |
| q2/model | 5점 | 5/5/5점 |
| q2/opposite | 0점 | 0/0/0점 |
| q2/date-only | 1점 | 1/1/1점 |
| q2/dual-date-one-sentence | 2점 | 2/2/2점 |

15회 중 12회 일치, 원 반례 3회 불일치다. 실행 오류·해시 변화는 없다. c1의 새 claim 전체가 실제 채점 입력에 포함되었어도 reason은 최초 감사보고서일을 유지한다는 내용이 없다고 판정했다. 주 claim 노출 위치 보완만으로는 모델의 함축 해석 문제가 해결되지 않았다. 기대 5점과 원 반례를 유지하고 이 후속본을 실제 검증 pass로 표시하지 않는다. 총괄에게 결과를 전달했으며 추가 반복이나 정본 반영은 하지 않았다.

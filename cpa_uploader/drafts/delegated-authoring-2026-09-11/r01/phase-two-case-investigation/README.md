# 실제 변동 사례의 통합 원인 대조

**첫 4세트의 변동 5사례를 원문·원래 초안·현재 발문·criterion·전체 QA 답안과 대조했다.** [장부](ledger.json)는 v1의 15개 관측과 v2의 4개 후속 관측을 원시 파일·해시에 연결한다. 현재 문항·작성자 QA의 해시는 manifest와 일치하며 이 조사 중 API 호출·입력 수정은 없었다.

| 사례 | 원문·전체답안 대조 | 기대값 판단 | 실제 발생 단계 |
|---|---|---|---|
| T04-A q1/irrelevant-prefix | 무관한 완전 문장 뒤 조정 이익 수치·이유가 그대로 남음 | met/met·2점·none 유지 | raw salad 분류만 변동. v2 총3회 정상 |
| T09-A q1/opposite | 501.5의 같은 기간·대상 추가 절차를 명시적으로 불필요하다고 함 | contradicted·0점 유지 | 최초 judgment의 not_met/contradicted 분류 변동 |
| T09-B q1/condition-boundary | 직접 금액 기재의 방식 설명을 간결히 적고 위험 완전 제거·회신율 반드시 증가를 덧붙임 | 1점 해석을 지지하나 QA 분리 정도를 보완할 여지 | c1 방식 인정이0/1/1. 간결표현 판단과 조건오류가 혼재 |
| T09-B q2/irrelevant-prefix | 필수 회신을 대체할 수 없음과 감사·의견 시사점 결정이 그대로 남음 | met/met·2점·none 유지 | raw salad 분류 변동, 점수는 유지 |
| T10-A q2/irrelevant-prefix | 네 정상 방향·이유 명제가 무관한 문장 뒤에 남음 | 네 met·4점·none 유지 | raw salad 분류 변동, 점수는 유지 |

공통 보안 사례 세 개는 무작위 감사 용어 조합이나 채점 조작 지시가 아니다. 정상 답안 앞에 붙은 문법적으로 완성된 무관한 사실만으로 salad를 기대하도록 QA를 바꿀 근거는 없다. 명시적 반대 사례도 누락과 달리 의무를 직접 부정하므로 두 판정의 점수가 같다는 이유로 기대값을 바꾸지 않는다. 이 네 사례에서 문항·QA 내용의 결함은 확인되지 않았다.

T09-B의 경계 사례에는 별도의 주의가 필요하다. 발문은 공란형의 작성·회신 방식을 모두 묻고, criterion은 미리 정보를 적지 않은 조회서에 조회처가 정보를 제공하는 방식을 표현한다. QA의 “공란형은 상대방이 직접 금액을 적으므로”는 그 방식을 나타내는 간결한 표현으로 볼 수 있다. 하지만 감사인의 미기재를 명시적으로 쓰지 않아, 두 효과에 대한 잘못된 조건만을 독립적으로 시험하는 사례라고 단정할 수는 없다. 따라서 최초 0점 관측을 확정된 grader 오류로만 기록하지 않았다.

장부의 `companion_case_proposal`에는 **미기재와 조회처의 직접 기재를 모두 정확히 설명한 뒤**, 위험 완전 제거·회신율 반드시 증가라는 두 반대 주장을 붙인 답안을 제안했다. 기대는 c1 met, c2·c3 contradicted, 총1점이다. 이 동반 사례로 방식의 간결표현 해석과 조건오류의 영향이 분리된다. 제안은 현재 QA에 추가하지 않았고 실제 채점도 하지 않았다. 원래 기대값을 모델 출력에 맞춰 0점으로 내리는 제안이 아니다.

T09-A의 부분 의미검수 문제는 [원문 대조](../phase-two-v1/t09-a/content-investigation.md)와 [동일 입력 총3회 결과](../phase-two-v1/t09-a/q1-reproduction-summary.json)를 함께 연결했다. 초기 fail 뒤 pass/pass로 바뀌었으며, 지문·발문에 주어진 추가 절차 조건을 답안에 다시 쓰지 않았다는 이유만으로 문항 결함이 확인되지는 않았다.

v2 T09-A는 24개 작성자 QA가 모두 일치했지만 종료 시 공통 코드 변경을 감지했다. 이 사실을 [중지 기록](../phase-two-v2/runtime-change-stop.md)에 보존하고 최신 고정 환경의 완료와 구별한다. 이후 재사용·재실행·동반 QA 편입은 총괄이 새 실행 버전과 범위를 조율한 뒤 진행한다. 원본·현재 문항·QA·과거 실행은 모두 보존한다.

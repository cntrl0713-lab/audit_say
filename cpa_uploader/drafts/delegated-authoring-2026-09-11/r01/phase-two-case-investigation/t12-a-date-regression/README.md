# T12-A 최초 일자 함축의 v4 선행 회귀 준비

총괄의 v4 고정 후 [15회 실제 채점](phase-two-v4/run-01/summary.json)을 완료했다. 원 q2/omit-1은 세 번 모두 4점으로 기대 5점과 달랐고, 정상·명시반대·독립 1점·두 명제 한 문장 답안의 나머지 12회는 모두 일치했다. 실행 오류와 입력 변화는 없다. 새 원시 reason도 최초 일자의 유지가 없다고 판단했으므로 함축 허용 범위의 적용 문제는 아직 해결되지 않았다. 원답안과 기대는 유지한다.

원 QA 5사례를 답안·기대·ID까지 그대로 추출했다. [준비 장부](preparation.json)와 [QA](qa-date-comparison.json)에 원본 해시와 비교 범위를 남겼다. 원 문항·계획·QA는 수정하지 않았으며 이 준비 단계의 API 호출은 0회다.

| 원 사례 | 사전 기대 | 역할 |
|---|---:|---|
| q2/omit-1 | 5점 | 최초 일자 후 절차를 한정하는 추가 일자로 보존을 함축한 원 반례 |
| q2/model | 5점 | 전체 정상 답안 |
| q2/opposite | 0점 | 최초 일자 삭제 등 명시적 반대 |
| q2/date-only | 1점 | 최초 일자 보존만 충족한 독립 명제 |
| q2/dual-date-one-sentence | 2점 | 명시적 보존과 추가 일자 의미를 한 문장에 쓴 대조 |

현재 criterion의 함축 허용 범위와 560.A13, 이전 3회 실패 및 정상 대조는 [v3 조사](../../phase-two-v3/t12-a/author3b/omit1-investigation.md)에 보존했다. 원 반례를 더 명시적으로 교체하지 않는다. 총괄은 원 답안의 5점 기대 유지에 동의했으며 새 환경에서 이 비교 묶음을 먼저 확인하도록 지시했다.

[실행기](run.ts)는 v1/v2/v3 lock을 거절하며 총괄이 새로 고정한 lock과 새 출력 폴더를 명시해야 실행한다. 각 답안을 3회, 총 15회 production grader에서 순차 채점하고 원시 판단·trace·복원 인용·점수·보안 플래그를 보존한다. 기대가 일치해도 3회, 불일치해도 3회이며 실행 오류나 고정 파일 변경 때만 나머지를 멈춘다. 이 5사례에는 조건 경계의 not_met/contradicted 동등 정책을 적용하지 않는다.

새 환경 전달 전에는 `node --import tsx .../run.ts --validate-only`만 실행한다. 실제 실행은 총괄의 v4 고정·재개 지시 뒤 별도 새 폴더에 남긴다. 이 문서와 정적 검사 자체를 실제 채점 증거로 취급하지 않는다.

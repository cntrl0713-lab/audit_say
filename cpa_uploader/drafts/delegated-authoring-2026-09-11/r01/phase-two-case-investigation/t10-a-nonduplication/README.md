# T10-A q1의 지목된 기존 문항과 요구 비교

지목된 두 기존 세트에 대해 T10-A q1 전체가 직접 중복이라는 판정은 근거가 부족하다. 같은 통제테스트 주제를 다루지만, 수행 필요성의 조건과 이미 수행하는 테스트의 표본규모 방향·이유는 다른 판단 대상이다. [상세 증거](evidence.json)는 원 의미검수 fail, final-153-v2 은행의 실제 발문·답안·criterion, 원 계획 및 파일 해시를 보존한다. 추가 API 호출이나 문항·계획 변경은 없다.

| 실제 기존 요구 | T10-A q1의 요구와 관계 |
| --- | --- |
| pilot-07-002/sub1/crit1 및 pilot-07-004/sub1/crit1: 운영효과성에 의존하려는 경우 통제테스트 수행 | 이미 통제테스트를 수행하는 상황에서 의존 정도가 증가할 때의 표본규모 방향과 이유까지 답하지 않는다. 인접 관계이다. |
| 두 세트의 sub1/crit2: 실증절차만으로 증거가 불충분할 경우 통제테스트 수행 | 후속은 이 수행 요건을 묻지 않는다. |
| pilot-07-004/sub2/crit3: 의존이 클수록 더 설득력 있는 증거 입수 | 후속 q1.c2의 운영효과성에 대한 더 많은 확신과 일부 설명이 겹친다. 이 부분 공유는 인정한다. 다만 증거 설득력은 곧 표본 크기라는 뜻이 아니며, 기존 답만으로 후속 c1의 표본규모 증가를 충족하지 않는다. |
| 두 세트의 나머지 물음 | 후속 q1.c3/c4가 요구하는 허용이탈률 초과 여부의 확신 요구수준 증가와 표본규모·이유는 다루지 않는다. |

후속의 공식 근거 KGA 530 보론 2 항목 1에는 통제테스트 수행 필요성의 설명도 포함된다. 그러나 같은 원문 단락에 있다는 사실이 그 설명 전부를 이 물음의 득점 명제로 만들지는 않는다. 실제 q1은 다른 조건이 같을 때 ① 통제 의존 증가, ② 확신 요구수준 증가가 각각 표본규모에 주는 영향과 이유를 묻는다. 원 계획도 이 범위를 명시한다.

의미검수는 q1 전체에서는 ‘수행 요건이 이미 다뤄졌다’며 fail을 냈지만, 같은 실행의 q1.c1~c4에서는 각각 nonduplication pass를 냈다. 이 불일치는 원 판정 그대로 남긴다. 의도된 복습이라는 말을 새로 붙여 중복을 면제하려는 판단은 아니다. 전체 은행 무중복 검증으로 범위를 넓히지 않으며, 지목된 두 세트와의 관계만 조사했다.

원문 인용 줄 범위의 포함 여부는 별도 source_support 쟁점이다. 이 비교로 해당 uncertain을 해결됐다고 보고하지 않는다. 동일 의미검수 입력의 총 3회 재현은 총괄이 수행하므로 아직 확보되지 않은 관측을 이 보고서에 합치지 않는다.

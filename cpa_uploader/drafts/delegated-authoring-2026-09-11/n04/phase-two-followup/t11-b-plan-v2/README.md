# T11-B 기존 명제의 적용 복습 재분류 제안

이번 후속 검토에서 `pilot-11-006/sub3/sub3.crit1`과 `pilot-05-006/sub2/crit3`의 실제 명제 중복을 발견했다. 과거 계획에 이미 명시되어 있었다고 주장하지 않는다. [원문·현재 은행 대조](../../phase-two-case-investigation/t11-b-source-and-overlap/README.md)와 최초 fail receipt를 그대로 보존한다.

[후속 계획 사본](pilot-11-006.json.authoring-plan.v2.json)은 사업상 이유의 부정 징후 평가 한 명제를 특수관계자 거래의 근거 계약 검사에 적용하는 복습으로 명시한다. 이를 신규 커버리지 증가로 세지 않는다. 550.23 전체 적용에서 이 평가가 거래조건의 설명 일관성, 회계처리, 공시, 권한부여·승인 증거 입수와 함께 필요한 이유를 적었다. 단순히 이름이 다른 사례라서 새로운 요구라고 보지 않는다.

문항·답안·criterion·점수·QA는 바꾸지 않았다. sub3은 복습 1점과 추가 네 독립 요구 4점, 세트는 총 16점이다. 원 계획의 예외 두 항목 추가와 차이 설명 보강만 [계보](lineage.json)에 기록했다. 원 manifest와 계획은 그대로이며 총괄이 선택하기 전까지 새 사본은 제안 상태이다.

무호출 검수 준비는 19단위를 구성하고 문항·비교은행 해시가 전후 같은 것을 확인했다. 계획이 모델 입력에 포함되므로 이 세트의 의미검수 입력은 달라진다. 실제 새 의미검수와 생성 사례 채점은 아직 실행하지 않았고, 이 문서를 의미검수 통과로 사용하지 않는다.

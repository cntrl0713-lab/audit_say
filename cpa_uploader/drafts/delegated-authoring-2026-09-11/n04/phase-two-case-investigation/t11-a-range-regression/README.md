# T11-A 범위추정치 검증 종료 판단의 v4 선행 회귀

총괄의 v4 고정 후 [9회 실제 채점](phase-two-v4/run-01/summary.json)을 완료했으며 모두 사전 기대와 일치했다. 원 반례 4점, 저장 모범답안 4점, 명시적 반대 3점을 각각 3회 확인했다. 실행 오류·입력 변화는 없다. v3의 원 관측 3/4/4점은 그대로 보존하고 v4 후속 관측과 구분한다.

[원 QA 3사례](qa-range-comparison.json)를 답안·기대·ID까지 그대로 추출했다. [준비 장부](preparation.json)는 문항·계획·QA·출처 해시를 기록한다. 준비 시점의 API 호출은 0회이며 v4 고정·재개 전달 전에는 실제 실행하지 않는다.

| 사례 | 기대 | 검증 목적 |
|---|---:|---|
| sub3/omit-1 | 4점 | 추가 검증을 계속 수행하는 조치에서 종료 불가 판단이 함축되는 원 반례 |
| sub3/model-answer | 4점 | 현재 저장 모범답안 |
| sub3/opposite-1 | 3점 | 종료 가능이라는 명시적 반대는 판단 0점, 별도 정상 검증 조치는 3점 |

[v3 조사 장부](../../phase-two-v3/t11-a/author3b/omit1-investigation.json)의 원 반례는 점수 3/4/4로 변동했다. 발문은 경영진 점추정치가 범위 안에 있다는 사실만 확인했으며 540.29의 나머지 검증은 아직 수행하지 않았다고 준다. 원답안이 모든 범위 금액의 증거·합리성 및 공시의 추가 절차를 계속 요구하므로 검증 종료 불가를 함축한다. 현재 crit1.scope도 이 조치의 함축을 명시적으로 인정한다. 원 QA의 4점 기대를 유지했다.

총괄 지시에 따라 [실행기](run.ts)는 각 3회, 총 9회를 새 lock 아래 production grader로 실행하도록 준비했다. v1/v2/v3 lock은 거절하고, 원 문항·QA·계획을 바꾸지 않으며, 원시 판단·trace·인용·보안·최종 점수를 별도 폴더에 남긴다. 이 묶음은 조건 경계의 not_met/contradicted 동등 정책을 사용하지 않는다. 준비·정적 검사 성공은 실제 채점 완료를 뜻하지 않는다.

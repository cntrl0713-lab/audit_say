# T11-A 의미검수의 문단 위치 오독

새 bank-v3 실제 의미검수의 21단위 중 두 단위가 출처 지지 uncertain이다. [근거 기록](evidence.json)은 `subquestion:sub3`와 `criterion:sub3:sub3.crit1`의 원 판정·이유를 추출하고, 현재 문항·계획·고정 은행에서 재구성한 요청/스키마 해시가 원 chunks에 직접 기록된 해시와 같은지 확인했다. API는 호출하지 않았다.

두 원 판정은 540.29의 선언 위치 L213–L225와 실제 인용 위치 L180–L192가 어긋난다고 주장한다. 그러나 요청에 들어간 `std-540-29`의 실제 인용은 L213–L219이고, 인접 문맥을 포함한 excerpt는 L185–L245이다. L180–L192는 다른 출처 ID인 `std-540-27`의 실제 인용 위치다. 따라서 29의 인용은 선언 범위 안에 있으며, 서로 다른 문단의 위치를 혼동한 판정이다. 내용·판본·배점·중복에 관한 다른 checks는 해당 두 단위에서도 pass였다.

문항·source_span·출처 파일을 고칠 실제 위치 결함은 이 두 판정에서 발견되지 않았다. 원 model receipt의 uncertain은 그대로 보존한다. 이 조사만으로 전체 21단위·90생성사례가 검수 완료되었다고 주장하거나 formal manual_reasoned pass를 만들지 않는다. 수동 후속을 진행하려면 모든 단위·사례·실인용을 실제 대조하고 원 receipt와 다른 방법·새 증거로 남겨야 한다.

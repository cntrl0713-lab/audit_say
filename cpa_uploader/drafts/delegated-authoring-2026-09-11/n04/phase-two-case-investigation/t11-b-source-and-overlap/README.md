# T11-B 원문 위치와 실제 중복의 분리 조사

[동일 입력·원문·현재 은행 대조 증거](evidence.json)는 추가 API 없이 작성했다. 원 의미검수는 19단위·80사례를 포함하고 두 단위가 non-pass이다. 이 문서는 전체 단위·사례를 검수한 manual receipt가 아니다.

- `subquestion:sub3/source_support`: 선언 위치 L621–L639 안에 실제 550.23 인용 L621–L633이 있다. 모델이 제시한 L595–L613은 이웃 550.22이다. 원 요청의 `source_excerpts`에 두 위치가 각각 올바르게 들어 있으며, 원 요청·스키마 해시와 현 무호출 재구성이 같다. 문항·출처 위치를 고칠 이유가 없다.
- `criterion:sub3:sub3.crit1/nonduplication`: 모델이 지목한 같은 세트 sub2는 550.15의 검사할 문서 목록이어서 틀린 비교이다. 반면 기존 `pilot-05-006/sub2/crit3`는 사업상 논리적 근거 또는 그 결여에 비춘 부정재무보고·자산횡령 은폐의 징후 평가를 실제로 요구한다. 새 550.23(a)(i) 배점 명제와 겹친다.

특수관계자 거래와 근거 계약 검사라는 적용 범위, 거래조건·회계처리·공시·승인 증거의 추가 네 명제는 새 물음의 가치이다. 그렇더라도 기존 평가 명제의 겹침을 없애지는 않는다. 현재 계획은 다른 주제11 문항과의 차이만 설명하고 이 특정 기존 명제의 복습 재사용을 밝히지 않았다. 전부 모델 오류로 간주하거나 원 receipt를 변경하지 않는다.

후속 설계 판단은 두 경로 중 선택할 수 있다. 550.23 전체 적용의 필요성을 근거로 기존 명제의 복습을 명시적으로 유지하고 관계를 기록하거나, 해당 평가를 이미 수행한 것으로 후속 발문을 구성해 나머지 독립 요구를 채점한다. 후자는 문항·배점·QA가 바뀌므로 총괄 결정과 새 고정·검증이 필요하다. 현재 어떤 경로도 적용하지 않았다.

두 단위의 정확한 원 입력 추가 2회씩은 잔액 소진으로 실행되지 않았다. 원 1회씩은 보존했고 현재 새 충전의 복구 확인을 기다린다. 향후 관측이 통과하더라도 이 원문·실제 중복 조사와 최초 non-pass는 함께 남겨야 한다.

# N04 — 회계추정·특수관계자·감사인측 전문가

**1차 초안 준비: 신규 3세트·9물음·53점, 작성자 QA 214사례.** 정적 검사와 무호출 의미검수 입력 준비를 마쳤다. 최종 49개 비교은행을 고정한 뒤 실제 모델 의미검수·채점과 불일치 수정을 이어간다. 실제 검증 완료나 정본 편입을 뜻하지 않는다.

모두 총괄 [ID 장부](../../../analysis/reviews/delegated-authoring-2026-09-11/id-ledger.json)의 N04 배정값이다. 잠정 31→53점은 같은 대상의 독립적인 선택·적용, 서로 다른 대상의 평가, 조건부 후속 행위를 각각 1점으로 구별한 결과다. 물음 수와 주제 범위는 유지했다. [명제별 변경표](design-changes.json)와 [정답·근거 대응](evidence-packet-t11-a.json)을 함께 확인한다.

공식 2025 전문과 2026 전문을 직접 대조하고 등록된 [공식 발췌](../../../data/official/delegated-n04-kga-2025.txt)를 사용했다. 620의 품질관리 문구 차이는 2026년 보고기간에 종전 체계를 적용하는 사례조건과 총괄의 판본 해석으로 다뤘다. [범위·출처·빈도](scope-and-sources.md), [후속 담당 경계](s02-s03-handoff.md), [인계](handoff.md)에서 확인한다.

세트마다 `*.json.authoring-plan.json`은 version 1 계획이다. `evidence-packet-*.json`은 수동 근거 장부이며 생성기 패킷이 아니다. 정식 검수에는 실제 초안, 해당 `--plan`, 총괄의 고정 `--bank`를 전달한다. 이 수동 장부를 `--packet`으로 넣지 않는다. 모델에 필요한 직접 원문은 `source_refs`, 조건·의존 문맥·판본차이는 실제 계획의 `scope.exceptions`에 포함했다.

[정적 결과](static-check.json)는 오류 0이며 세트별 CLI 검사도 통과했다. 400,000자 한도에서 준비용 111세트+N04의 무호출 입력은 각각 298,449 / 264,659 / 319,790자다. 전체 49개 최종 비교본의 길이나 모델 통과 결과는 아니다. 초안 상태는 `needs_review / needs_human_review`를 유지한다.

이 패키지에서는 원자료·정본·공용 출처·coverage·wiki를 수정하지 않았다. 공통 출처 등록은 총괄이 수행했고, [coverage 제안](coverage-proposal.json)은 총괄의 최종 내용 대조 및 snapshot 생성을 기다린다.

# 배점 정책 대표 답안의 최소 실측

소유자는 총괄이다. 서브에이전트의 제작·로컬 검사 인계와 구별되는 새 실행 경로다.

사용자의 추가 허용에 따라 새로운 문항·QA·비교 은행·공통 코드 잠금을 먼저 확인하고 대표 답안 7개만 실제 생산 채점 함수로 실행한다. 불일치 사례만 같은 입력으로 총 3회 확인하며, 다른 사례로 계속할지는 원인을 확인한 뒤 결정한다. 전체 의미검수·전수 QA 실행을 재개하지 않는다.

각 하위 폴더의 `inputs.json`, `case-0001-attempt-*.json`, `summary.json`은 원시 실행 증거다. 기존 결과를 덮어쓰지 않으며 새 실행은 새 경로를 사용한다. 비밀값은 저장하지 않는다.

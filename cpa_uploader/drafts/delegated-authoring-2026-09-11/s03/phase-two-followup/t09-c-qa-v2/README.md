# T09-C 직접 회신 명제의 QA 기대값 후속

총괄이 501.10과 발문·c5 전체·대조군을 독립 대조하여 `sub2/boundary-1`의 c5만 `not_met → met`, 합계 `0 → 1`로 정정하도록 승인했다. 답안과 문항·계획·출처·비교은행은 바꾸지 않았다. c1/c2의 원래 경계 기대도 유지했다.

[후속 QA 65개](qa-cases-t09-c-v2.json)와 [변경 계보](lineage.json)에 원 QA 해시, 한 기대값의 전후, 동일한 원 답안, 원 요청·스키마 직접 해시를 기록했다. 원 답안의 잘못된 발동조건을 독립된 직접 회신 경로 c5까지 전가하지 않는 정정이다.

[실측 후속 결과](followup-result.json)는 원 답안의 기존 유효 3회를 정확히 연결한 1/0/1점과 새 대조군 6회를 구분한다. 직접 회신만 쓰는 정상 답안은 1/1/1점, 경영진에게만 회신한다는 명시 반대는 0/0/0점이며 모든 criterion 기대가 일치했다. 새 대조군은 필수 QA 65개 고유사례나 원 필수 관측 800회에 합산하지 않는다.

원 답안의 가운데 0점은 후속 기대 1점과 여전히 다르다. 기대값의 오류를 고쳤다는 사실과 실제 모델의 변동이 해결됐다는 주장을 구별한다. 원 QA·원 로그·최초 판정은 보존했다. 새 대조군 6회는 두 번째 잔액 소진 중단 전에 완료되었으며, 이 정리 스크립트는 API를 호출하지 않는다.

# S03 원문·판본·설계 근거

공식2025 전문을 기본2026년1월1일 개시 보고기간에 적용하는 사례를 수동 제작했다. 2027 금융위원회 시험공고는 특정 기준서 판본을 지정하지 않았으며 [총괄 시행정책](../../../analysis/reviews/delegated-authoring-2026-09-11/edition-policy.md)의 확인범위와 해석한계를 따른다. 국제 ISA 개정판을 국내 시행으로 자동 대입하지 않았다.

원본은 앞선 조사에서 확보한 [2025 공식 PDF](../../frequency-gap-2026-09-10/sources/kga-2025.pdf)와 [2026 공식 PDF](../../frequency-gap-2026-09-10/sources/kga-2026-full.pdf)를 읽기 전용으로 사용했다. S03에서 별도 재다운로드했다고 주장하지 않는다. 출처는 한국공인회계사회 [2025 공식파일](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11762493343340&fileSeq=7&subId=sub06), [2026 공식전문 ZIP](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06)이다. PDF SHA-256은 각각 `b6b3a965c25cdb5bfdc0bf54838ae1bcc642581eef2d2d9e306a67ac811b0989`와 `59020bf1eba001c1fd0612f3af1098dbef4ca11dc22777b7266c80d39a615f84`다.

[원문 조사](sources/official-investigation.json)는 각 전문의 본문·각주를 물리쪽과 연결한다. 페이지마다 반복되는 기준서 머리말·쪽번호만 제거했고, 부절 제목·각주가 문단 뒤에 따라오는 경우도 임의로 원문을 개작하지 않았다. [2025 발췌 제안](official-excerpts-2025.txt)의 SHA-256은 `a75454ef6d5567074cb80f665a9f5eb65dbeec094d1db52f6444d2f2aba0d906`, [2026 대조 발췌](official-excerpts-2026.txt)는 `f0cf992681a6762dedbf347701e0a2a31c1ff9fa5da8de594c8b9a564d63de3d`이다. 총괄이 원문을 보존하여 [공식 등록파일](../../../data/official/delegated-s03-kga-2025.txt)에 메타데이터를 추가했고 [등록장부](../../../analysis/reviews/delegated-authoring-2026-09-11/source-registration-s03-kga-2025.json)의98개 실제 src ID를 사용했다. 현행 등록파일 SHA-256은 `cc98d534ed8a81cdaf625502c0177d1d193ce7b5193763acd97b3e538a96fbaf`다.

선택98문단 중89개는 공백제거 기준 동일하고9개는 각주 번호·참조 기준서 제목이 다르다. 501.A20의540 제목, 610.5와402.3의315 제목, 610.A15·A16·A17·A20·A21·A30의 각주 차이를 [문단별 비교](sources/edition-comparison.json)에 보존했다. 이 차이를 전문 전체의 완전 동일성으로 일반화하지 않는다. 직접 배점 요구와 국내 직접적 보조 금지의 본문은 대조한 양판본에서 동일하다.

이 의존문맥은 실제 각초안의 `source_refs`에 인용되고 판본·조건 설명은 version1 plan의 `scope.exceptions`에 포함된다. 별도 evidence-packet만 보관해 모델에 들어간 것으로 취급하지 않는다. 자동 생성 의존패킷의 모든 교차참조를 완결한 것으로 표시하지 않으며 수동 `--plan` 경로를 사용한다.

T09-C는2022:8:1의 질문 예시를 새로 회상하게 하고 문서군을 구분한다. 원기출 A211~212쪽의 요구 두 가지를 새5명제 각각의 직접빈도로 사용하지 않는다. T09-D는2025:4:1의 조서불능 판단과2020:9:2의 계정별 추가절차를 확장한다. A36·A312 해설까지 확인했다. 새Q3 상황A는 `pilot-09-001/subq1/crit2`와 **직접 겹치는 의도된 복습1점**이고 상황B의 입증된 미수정오류 의견계열이 새 비교요구다. 이를 미출제 공백으로 부르지 않는다.

T05-C의2024:5:4 A96·101쪽은 두 유형의 책임을 직접 요구한다. 새Q2의250.16까지 확대된 완전열거는 원기출 각명제의 직접빈도로 세지 않는다. 학습 해설의 경영진(또는 지배기구) 축약에 의존하지 않고 공식15(a)의 경영진과 적절한 경우 지배기구 포함이라는 조건을 유지했다.

T13-B는2025:3:3 A29·31쪽의 유의적위험 활용축소와 연결하고, 필수암기/OX 교재 심화18번99·108쪽의 개별업무 세 범주를8개의 독립 평가로 명료화했다. 심화18은 참거짓 OX발문이 아니며 이 교재의 수록1개다. 학습요약 [타인의 업무활용](../../../data/회계감사_통합학습자료/01_감사기준/06_타인의_업무활용.md)의22/23 표기와 공식23/24의 번호 차이를 확인했다. 심화18 해설은 이미23으로 표시하므로 학습자료 모두가 같은 구번호라고 하지 않는다.

T13-C의연습711~712쪽은 서비스감사인 적격성·독립성을 전제로 추가평가 필요성을 묻는다. 원시험 종류·연도 미확정인 해당 수록을 기출 또는 모의로 임의 전환하지 않는다. 새17의9개 평가와18의 하위서비스까지를 직접기출 범위라고 하지 않는다. 해당 [원발문·정답 문맥](learning-original-context.json)을 관계 판단과 함께 보존했다.

형상검사와 관계제안은 의미검수·사람확인·실제채점·정본 반영의 대체물이 아니다. [정본 대조](comparison-notes.json)는 현재05·09·13의23세트 발문·답안·criterion을 보존하고, [coverage 제안](coverage-proposal.json)은9개 요소를13행으로 연결하며 모두 `needs_review`다.

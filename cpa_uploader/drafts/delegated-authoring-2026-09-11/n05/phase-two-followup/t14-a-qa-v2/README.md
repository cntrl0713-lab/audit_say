# T14-A 작성자 QA 기대값 후속 정정

문항·원 QA·원래 실측을 보존하고, 동일 답안의 사전 기대값 한 건만 공식 원문과 발문에 따라 정정했다. [lineage.json](lineage.json)에 원본·후속본 해시, 실제 발문·criterion, KGA 600.20/A39의 정확한 인용과 총괄의 독립 대조 지시를 연결했다.

원래 `sub1/omit-sentence-1`은 “그룹감사인이 해당 부문재무정보에 관하여 충분하고 적합한 감사증거를 입수하여야 한다”라는 답안이다. 이 문장만으로 부문감사인 A에게 의존하지 않거나 그룹업무팀이 직접 절차를 수행한다는 판단을 필연적으로 읽을 수 없다. 일반적인 증거입수 책임은 A의 업무를 이용하는 경우와도 양립한다. 따라서 c1 기대를 met에서 not_met로, 총점을 2점에서 1점으로 정정했다. 발문에 있는 대안 요구를 답안에 쓰지 않은 결론으로 보충하지 않았다.

[qa-cases-t14-a-v2.json](qa-cases-t14-a-v2.json)은 32개 원 사례의 답안을 모두 유지한다. 해당 사례의 기대 판정·합계·그 정정 설명만 변경했다. A에게 의존하지 않고 그룹감사인이 직접 필요한 감사를 수행한다고 명시하는 기존 `sub1/implicit-judgment`는 2점을 유지했다.

최신 `final-153-v3` 비교 은행과 `runtime-v5-bank-v3` 잠금으로 실제 production grader를 실행한 [후속 결과](phase-two-v5-recheck-01/summary.json)는 정정 대상 1/1/1점, 기존 양성 대조군 2/2/2점으로 총 6회 모두 일치했다. 각 관측의 실제 모델, 직접 요청·스키마 해시, 원시 판정, 정수 합산을 보존했다. 문항·은행·공통 채점 코드 변경은 없다.

원 QA에서의 2점 기대와 실제 1/1/1점 불일치는 과거 증거로 남는다. 이후 집계에서는 이를 원 기대값 오류 및 정정 후 재확인 완료로 연결하며, 원 기록을 통과로 덮어쓰지 않는다. 이는 작성자 QA 후속이며 의미검수 receipt·사람 확인·정본 편입 상태를 변경하지 않는다.

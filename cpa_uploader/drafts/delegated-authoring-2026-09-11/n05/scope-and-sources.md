# N05 요구·근거·판본 장부

대상은 T14-A/B 두 신규 세트다. 실제 작성 범위는 [배정서](../../../../docs/plans/question-authoring-by-topic-2026-09-11/assignments/N05-그룹감사의-부문감사인-업무범위.md) 및 이후 총괄의 실행 지시를 따른다. 원계획의 미확정 판본·17점 잠정안은 이번 공식 대조와 승인된 배점 조정으로 구체화했다. 학습자에게는 실제 사례와 발문만 제공하며 내부 계획·요소 ID를 발문에 노출하지 않았다.

## 공식 판본과 확인 범위

공식 KICPA [회계감사기준 목록](https://www.kicpa.or.kr/board/list.brd?boardId=acc0102)을 2026-09-11 확인했다. 목록에는 2026 전문과 개정 220 공고가 게시되어 있다. 별도 국내 개정 600의 시행공고를 이번 조사에서 확보하지는 않았으며, 검색되지 않았다는 이유로 공고가 존재할 수 없다고 단정하지 않는다. 국제 ISA 600 개정의 국내 자동 도입을 전제하지 않는다.

현재 선택 판본은 2025 개정 전문이며 600.7은 2026-01-01 이후 개시 보고기간부터 시행한다. 2026 전문의 대응 시행 문단도 같다. 기본 사례는 2026년 보고기간의 그룹재무제표를 2027년에 감사하는 상황이다. [총괄 판본 정책](../../../analysis/reviews/delegated-authoring-2026-09-11/edition-policy.md)을 따른다. 금융위원회 2027 시험범위 공고는 특정 기준서 판본 지정과 구별한다.

사용하는 등록 공식 파일은 [kga600-2025-review14.txt](../../../data/official/kga600-2025-review14.txt)이며 SHA-256은 `22f6a25d59636722831adc8e50f53c1bb4d711cda61a38eee3434ffbe3be957a`이다. 현재 카탈로그 authority가 `official_transcription`임을 직접 확인했다. 기존 파일 바이트를 수정하거나 중복 공식 파일을 새로 등록할 필요가 없었다. [카탈로그 스냅샷](sources/catalog-snapshot.json)은 조회 시점 기록이며 현재 공용 카탈로그를 대체하지 않는다.

37개 문단 조사 기록은 [official-comparison.json](sources/official-comparison.json)에, 최초 불일치 여섯 건을 보존한 후속 설명은 [comparison-resolutions.json](sources/comparison-resolutions.json)에 있다. 24는 330 인용각주 9→10, A35/A37은 품질관리기준 각주 19→20, A52/A54는 검토업무기준 각주 21→22와 페이지 중간 각주 추출 차이다. A47 단위에는 뒤 도표 일부가 함께 추출되어 문단 본문만 별도로 대조했다. 이 변경은 20·26~29·A39~A41·A55의 답안 명제를 변경하지 않았다. 인용은 선택한 2025 등록 파일의 원문을 유지했다.

[2026 전문 도표 이미지](sources/work-types-chart-0642.png)도 확인했다. 원본 도표의 일부 문구와 아래 목록이 잘려 보여 완전한 대안 열거의 단독 근거로 사용하지 않았다. 29의 실제 본문에 있는 네 유형을 기준으로 한다. 새 source_refs의 좁은 물리쪽 위치는 [quote-locators.json](sources/quote-locators.json)으로 보완했다. 원자료의 페이지 색인 없음과 실제 물리쪽을 혼동하지 않는다.

각 criterion의 1점 명제와 정답·인용은 수동 근거 장부의 requirements에 양방향으로 연결했다. source_refs에는 전체 문단과 필요한 의존 문맥을 보존하고, 각 requirement는 해당 항목의 직접 인용을 사용한다. 자동 생성 packet 완결성이나 생성 해시를 꾸미지 않았다. 실제 grader가 읽는 `critical_facts`에도 판정 범위를 넣었으며 source_span에만 숨겨두지 않았다.

부문재무정보 전체 감사·검토의 중요성 기준은 그 업무유형과 독립적으로 평가한다. 특정 항목 감사나 특정절차에 같은 중요성 명칭을 일괄 적용하도록 확대하지 않는다. 원계획 대비 Q2/Q3 각각 +1점이며 [design-changes.json](design-changes.json)에 총괄 수용 근거를 기록했다.

## 구체 요소·빈도와 기존 요구의 차이

아래 기출 수는 원시험별 요구 빈도다. 모두 모의 0회·별도 연습 0건·OX 0건이며, 이 세 수를 기출에 합산하지 않는다. 원발문·공통지문·출처 위치·actual source_unit_ids·재수록 제외 사유는 현재 JSON에서 가져온 [frequency-evidence.json](frequency-evidence.json)에 보존했다.

대응은 해당 판단·업무유형에 direct이다. A/sub2의 심각한 우려 경계는 해당 요소의 직접 빈도에 별도 가산하지 않는다. 중요성 기준을 분리한 두 점도 같은 원출제의 새 빈도나 커버리지로 중복 계산하지 않는다.

현재 정본 주제14의 5세트·10물음·criterion을 [comparison-notes.json](comparison-notes.json)에 실제 내용으로 보존했다. A는 pilot-14-001/sub2/crit2~5의 이해 결과를 적용하는 심화이고, 문서 검토는 pilot-14-004/sub2/crit8의 사후 검토 필요성 판단과 시점·목적이 다르다. B는 pilot-14-003/sub2/crit7의 업무유형 개요 커뮤니케이션과 다르며, pilot-14-002/sub1/crit3·sub2/crit9의 중요성 개념은 업무유형에 연결한 의도적 복습이다. 진행 초안은 총괄의 활성 버전 목록·준비용 비교본에서 대조했으며 최종49개 동료 비교는 고정 후 다시 한다.

S05/T14-C의 중요성 결정·평가권, 수행중요성, 왜곡표시 보고한도, 부문중요성 합계의 산술배분 오해는 N05에서 채점하지 않는다. [S05 인계](s05-handoff.md)에 용어·근거·확정 범위를 전달한다.

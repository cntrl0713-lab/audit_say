# 담당 18세트 작성자 QA 현행 채점 증거

2026-09-11의 필수 808사례를 모두 실행했다. 실제 모델 783회와 생산 빈답안 경로 51회, 총 834관측을 보존했다. 803사례는 모든 관측이 일치했고 5사례에서는 총 7회의 원시 판정 불일치가 있었다. 이 다섯 사례를 최종 한 번의 일치만으로 통과 처리하지 않는다.

새 전수 실행 800사례와 같은 v4 코드에서 먼저 검증했던 T16-A의 8사례를 합친 분모다. 후자의 8사례에는 각각 3회, 총 24회의 실제 원시 결과가 있으며 [41사례 결합 장부](../../n06/phase-two-v4/pilot-16-010/full-author-qa-linkage.json)로 연결했다. 이 16회의 추가 반복과 다섯 변동 사례의 10회 추가 반복 때문에 관측 수가 고유사례보다 26회 많다. 과거 v3 채점 결과나 넓은 원답안의 탐색 회귀를 이 분모에 포함하지 않았다.

[전체 사례별 증거 색인](owned-author-qa-evidence-index.json)은 새 비교은행 v3 manifest 및 명시된 runtime-v5-bank-v3 lock을 사용한다. 담당 문항·선택된 QA·원문·채점 코드의 해시를 다시 확인하고, 808사례 각각의 현재 `buildGradingPrompt`와 응답 스키마를 API 호출 없이 재계산하여 모든 원시 관측의 해시와 대조했다. 의미검수 지시·비교은행의 변경으로 과거 의미검수 receipt까지 재사용할 수 있다는 뜻은 아니다.

기대값을 유지한 변동은 다음과 같다.

- T02-B `sub2/implicit`: 0/2/2점. 명시된 기준상의 이유가 판단을 함축하는 답안을 첫 회가 결론 문구 미제시로 처리했다. [근거 장부](../../s01/phase-two-v4/pilot-02-007/grading-findings-01.json).
- T03-B `sub1/implicit`: 0/2/2점. 갑·을 사례와 독립된 이유를 연결한 답안을 첫 회가 이미 주어진 세부 사실의 재진술 부족으로 처리했다. [근거 장부](../../s01/phase-two-v4/pilot-03-006/grading-findings-01.json).
- T18-A `sub1/opposite-crit1`: 점수0/0/0, 대상 분류 `not_met/contradicted/not_met`. 작은 규모라면 주권상장법인 제외가 해제된다는 명시적 반대를 단순 미제시로 처리한 변동이다. [근거 장부](../../s06/phase-two-v4/pilot-18-005/grading-findings-01.json).
- T18-A `sub3/boundary-crit11`: 1/1/0점. 판단만 있는 답안에 발문과 명제가 요구한 결정적 이유까지 득점 처리했다. [근거 장부](../../s06/phase-two-v4/pilot-18-005/grading-findings-02.json).
- T19-A `sub1/boundary-crit2`: 2/1/1점. 소극적 결론 문구로부터 별도 요청한 확신 수준의 설명까지 배경지식으로 보충한 변동이다. [근거 장부](../../s06/phase-two-v4/pilot-19-005/grading-findings-01.json).

T02-A/T01-A/T04-B는 총괄이 원문·계약 대조 후 수용한 QA 후속본을 사용했다. 원답안과 과거 QA·실측 파일은 보존했다. 다른 QA·문항·계획은 고정 입력 그대로이다. 모델은 gpt-5.6-luna이며 채점 코드의 v4와 v5 동일성은 [확인 기록](v5-grader-identity.json)과 최종 색인에 남겼다.

이 기록의 완료 범위는 작성자 QA와 그 증거 대조이다. 새 비교은행에서의 의미검수와 생성 사례 실제 채점은 별도 실행 중이며, 사람 확인·정본 편입·게시·배포는 수행하지 않는다.

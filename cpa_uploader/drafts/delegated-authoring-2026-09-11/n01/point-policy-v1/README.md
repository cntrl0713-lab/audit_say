# 담당 18세트 배점 후속본

2026-09-11 승인된 독립 의미단위 1점 합산 정책을 N01·N06·S01·S05·S06의 18세트, 50물음 전체에 적용했다. 16세트의 후속본을 작성하고 T16-B·T15-A는 기존 선택본을 유지했다. 총점은 143점에서 183점으로 바뀌었으며, 183개 criterion 모두 1점/0점 정수 합산이다. 판단을 명확히 함축하는 이유는 판단 점수도 인정하고, 주어진 사실의 반복이나 같은 명제의 재진술은 추가 점수로 세지 않는다.

최종 선택 경로와 물음별 유지·분리 이유, 기존 ID와 새 ID의 대응은 [handoff.json](handoff.json)에 있다. 총괄의 최종 수집 이후 이 장부 및 선택 문항·계획·QA는 동결했다. 공용 문제은행·wiki·coverage·manifest는 총괄이 통합한다.

T19-A는 2/1/3점이다. 물음 3의 낮은 확신은 감사보다 높은 미발견위험에 관한 차이로 설명해야 하며, 중요성 완화가 불가하다는 판단을 반복한 것만으로 그 설명의 점수를 얻지 않는다. T18-A는 규모 요건의 시점·기간·금액 경계를 분리하고, 기업별 판단과 결정적 이유를 별도로 합산한다. 제시된 기업 수치나 지배회사라는 사실만 반복한 답안에는 이유 점수를 주지 않는다.

원래 선택된 QA 808개의 ID·물음 ID·답안은 모두 보존했다. 후속 명제별 기대 판정을 직접 대조하고 새 사례 378개를 보강해 총 1,186개가 되었다. 새 동의표현 사례는 접두어를 덧붙인 원답 복사 대신 실제 대체 문장을 사용한다. 변경된 복합기준의 첫 명제와 추가 명제 모두 완전답안·동의표현·실제 누락·반대·조건 경계를 포함하며, T19-A 물음 2의 비어 있지 않은 누락도 추가했다. 원기준의 0점을 새 하위 명제에 자동 전파하지 않았다. 각 후속본의 `lineage.json`에 원입력 해시·원모범답안·기대 판정 변경과 직접 판단 이유를 남겼다.

[모범답안 대조](model-answer-contract-audit.json)는 50개 답안 전체와 새로 구성한 23개 답안의 필수 조건 보존을 기록한다. 두 번째 문장에 둔 허용 표현·오류 방지 범위는 criterion과 계획에 유지하며 숨은 추가 배점으로 사용하지 않는다. `critical_facts`도 실제 의미에 따라 action·actor·number·conclusion·condition 등의 역할을 구분했다.

[최종 로컬 검사](local-validation/results.json)는 18세트 형상·직접 원문 인용, 변경 16세트의 초안 CLI 검사, 원답안·원지문·출처 보존, 계획 대응, 1,186개 기대 판정의 정수 합산 및 메모리 내 153세트 은행 검사에서 오류 0을 기록한다. 기대 판정을 주입한 합산 검사는 실제 모델 판정이 아니다. 이 배점 변경 작업에서 담당자 API 호출은 0회이며, 과거 API 증거를 변경 후 183점 계약의 실제 검증 완료로 승계하지 않는다. 최소 실측은 총괄이 동결된 통합본에서 별도로 수행한다.

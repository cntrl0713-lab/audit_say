# N06 수동 원문 증거

이 문서는 실제 공식 원문을 확인한 수동 저작의 증거다. `createSourcePacket` 출력이나 complete source packet으로 표시하지 않는다. 등록된 원문을 `source_refs`에 연결하고 version 1 계획을 함께 전달하는 수동 계약이다. 의미검수 CLI에는 해당 `--plan`을 주며 존재하지 않는 `--packet`을 만들지 않는다. 생성 당시 marker를 삭제하거나 해시를 꾸민 경우가 아니다.

원학습자료와 공식 근거의 역할·판본·변형 범위는 [범위 장부](scope-and-sources.md)에 있다. 아래 quote SHA-256은 인용 문자열의 해시이고 파일 SHA-256 및 등록 unit의 content_hash와 구별한다. 1100.69는 실제 연속 본문의 (c)만 선택했으며 나머지는 등록 발췌 범위다. source_span은 해당 실제 파일의 줄 번호다.

필요 문맥은 외부 장부에만 두지 않았다. 각 세트에 다음 등록 source_refs를 함께 넣어 수동 검수 입력의 원문/선언된 인용으로 전달한다. 최종 preflight에서 실제 requestContext에 모든 인용이 포함되는지 다시 확인한다.

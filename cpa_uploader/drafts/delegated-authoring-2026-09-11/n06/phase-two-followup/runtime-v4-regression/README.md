# T16-A 모순 답안의 v4 채점 회귀 준비

[회귀 QA](qa-cases-t16-a-conflict.json)는 [고정41개작성자QA](../../qa-cases-t16-a.json)에서 8개를 그대로 선택했다. 답안·기대값을 수정하지 않았다. 정상 모범답안, 함축 판단, 역순 답안, 두 종류의 부분답안, 두 명시 반대, 실제 점수 오류를 낸 모순 답안을 포함한다. 여기서 부분답안은 2개명제 중 하나만 충족한1점답안이며 부분점수제도를새로추가하지않는다.

[결함 장부](../../phase-two-v3/pilot-16-010/grading-findings-01.json)와 원3회 실측에서 같은 모순답안이2/1/2점을 받았다. `crit5`의 반대 결론을 무시한 raw model judgment 단계의 문제다. `crit6`의 올바른 증거요건은 세 번 모두 인정됐으며 독립 명제로 유지해야 한다. 원답안에는 앞 문장을 명시적으로 취소하거나 정정하는 표현이 없다. 근거는 710.A12 및 현재발문/criterion5·6이며, 원문귀속·점수표·정답명제를 바꿀 필요는 발견하지 않았다.

회귀묶음 자체는 아직 실제 호출하지 않았다. 총괄의 v4 코드·새 runtime lock 확정 후 공통 `run-author-qa.ts --file <고정T16-A파일> --qa <이8사례파일> --output <새N06전용폴더>`로 실행한다. 원반례의 후속반복은 총괄 반복계약에 따르며 기존v3기록을 덮어쓰지 않는다. [사례 연결](case-map.json)은 원QA의 해시와 선택ID를 보존한다.

## 확인한 것과 남은 것

- [최종 정적 검사](static-validation-final.json): 121개 비교 세트와 N06를 합친 124세트의 분류·원문 인용·정수 점수·ID/발문 충돌 오류 0. 작성자 QA 118사례의 물음/criterion/해시/기대점수 합산과 필수 사례 종류를 확인했다.
- 실제 `prepareSemanticReview` 무호출 입력 준비 통과. 입력은 197,589 / 232,631 / 234,438자이며 명시적 400,000자 상한을 적용했다. 비교 은행과 자료를 자르지 않았다. [독립 초안 CLI 검사](cli-validation-final.txt) 3개 통과, [TypeScript 검사](typecheck-final.txt) 통과.
- 의미검수 **미실행**, 실제 모델 채점 **0/118사례**, 불일치 **미측정**. 작성자 기대값이나 정적 합산을 모델 검증으로 표시하지 않는다. 현재 비교 입력은 진행 중 스냅샷이며 전체49개 통합본으로 최종 중복 및 의미검수 입력을 재확정해야 한다.
- 2017 교재 기출변형과 2023 교재 해설의 강조사항 준용을 공식 국내 추가의무로 쓰지 않았다. 원시험의 정확한 변형 전 문구는 추가 대조 대상이다. 710.A12의 선택적 문구를 필수 보고문구로 바꾸지 않았다.
- T16-B Q2의 실제 수정 확인은 기존 `pilot-16-003/sub2/crit5`와 의도된 부분 복습이다. S05/S06에 전달할 보고문단·내부회계 범위는 인계에 명시했다.

## 재현 및 증거 보존

`content-proposal.py` → `build-manual.ts` → `qa-design.py`는 이 폴더만 쓴다. 배정 ID를 수동 사용하며 생성 CLI의 자동 ID 할당은 하지 않는다. 재생성하면 현재 문항·QA 해시가 바뀔 수 있으므로 2차 receipt와 실측 증거의 재사용 가능성을 먼저 판단한다. 검증 재실행은 `verify-local.ts <새 검사 파일명>`으로 새 이름을 사용한다.

[첫 정적 검사](static-validation-01.json)와 [정제 전 버전 ZIP](phase1-pre-refinement.zip)을 보존했다. 현행 활성 문항은 위 개별 JSON 3개뿐이며 ZIP·제안·과거 검사·장부를 신규 세트로 세지 않는다. 정본 편입·공개본 생성·배포·사람 승인은 수행하지 않았다.

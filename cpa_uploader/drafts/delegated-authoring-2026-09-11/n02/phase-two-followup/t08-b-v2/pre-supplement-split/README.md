# T08-B v2 후속 초안

자료 이용의 전제를 sub2 발문에 명시하여 기존 crit3의 조건이 숨은 요구가 되지 않게 했다. 실제 후속 문항·version1 계획·57개 작성자 QA를 이 폴더에 두며 기존 파일과 153 비교은행은 수정하지 않았다.

원 QA의 동의표현2개에 관련성·신뢰성 확인 전제를 복구하고, 원 표현2개는 조건이 빠진 별도 불완전 답안으로 보존했다. 추적 방향만으로 자료 확인 전제까지 자동 충족시키던2개 기대도 후속안에서는 crit3 미충족으로 정리했다. 이 두 기대 정정은 총괄의 선택 전 검토 대상이다. 문항 배점은3물음8점 그대로다.

[변경·해시 장부](lineage-and-change-record.json)에 원본/보존 복사본/후속 파일과 변경 범위를 기록했다. 현재 상태는 후속 초안이며 새 비교은행 연결·실제 의미검수·v4 채점은 총괄 연결 뒤 수행한다.

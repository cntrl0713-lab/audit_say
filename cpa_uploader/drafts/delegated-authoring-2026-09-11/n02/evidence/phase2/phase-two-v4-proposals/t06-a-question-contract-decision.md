# T06-A 문항 원본 유지 판단

발문·공통지문·10개 criterion·315 직접 근거를 대조한 결과, 새 은행 고정 전에 수정해야 할 숨은 요건이나 실제 범위 결함은 발견하지 못했다. 3물음 10점의 원본을 유지할 수 있다. 이 판단은 67개 QA의 의미검증 완료나 실제 채점 통과를 뜻하지 않는다.

불일치 11건은 모두 같은 요청·스키마로 3회 실측되었다. 권한 오용 위험의 설명이 독립 견제 부재를 함축하는지, 독립 검토의 흔적이 개선 통제도 표현하는지, 실행 관찰이 실제 사용 상태를 함축하는지, 반대 명제가 어디까지 적용되는지가 핵심이다. 구체 위험·독립 검토를 이미 표현한 유효 답안을 더 명시적인 답으로 바꾸어 실패를 숨기지 않는다.

sub3-crit9-paraphrase는 실제 수행 관찰에서 사용 상태가 함축될 수 있어 crit10 기대 met/총2점 정정을 검토할 후보이다. sub3-crit10-opposite는 규정 기재만으로 실행을 확정한다는 주장이 추가 적용 절차 필요성과도 양립하지 않아 crit9 contradicted 정정 후보이다. 두 건 모두 원 기대를 보존하고 총괄 판단과 v4 실측을 기다린다. 다른 9건은 우선 원 기대를 유지하며, 특히 흐름 A의 변경·승인 로그 삭제를 독립된 흐름 B의 대사 증적 삭제로 확대하지 않는다.

[11건 원시·인용·보안·합산 조사](t06-a-v3-eleven-case-investigation.json)에 원 답안, 모든 원 기대, 실제 3회 응답, 직접 공식 근거와 해시를 보존했다. 문항·QA 원본과 공통 코드·은행은 수정하지 않았다.

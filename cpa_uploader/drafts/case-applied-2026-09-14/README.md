# 사례형 적용 확장 6개

사용자가 확정한 6사례·18물음·44점의 제작·출처·검토 입력이다. 기출문제와 고급회계감사연습의 발문·해설을 참고해 새 사례를 구성하고 공식 기준서와 대조했다. 각 사례는 3물음이며 사실관계는 851–1,047자다. 모든 물음은 부모 사실을 적용해야 답할 수 있도록 설계했다.

[전체 문제와 모범답안](questions-and-answers.md) · [제작 결과 보고서](../../../docs/reports/case-applied-2026-09-14.md)

[시작 정본](bank-before.json)과 [시작 분류](classification-before.json), 작성자별 [A 초안](a/sets.json)·[B 초안](b/sets.json) 및 a/b 폴더의 설계·내용 검토·대표 부분정답·오답을 보존했다. [A 교차검토](a-peer-review.json)·[B 교차검토](b-peer-review.json)와 별도로 root가 전수 대조했다. agent 검토를 사람의 직접 내용 확인으로 기록하지 않는다.

[최종 출처 카탈로그](source-catalog-final.json), [공식 원문 교차검토](source-peer-review.json), [raw 수집·원본 대조](../../raw/collections/2026-09-14-case-applied/manifest.json)에 출처 계보를 남겼다. 교재 재수록을 새 출제로 세거나 GS 모의를 기출로 합산하지 않는다. 720 FAQ는 기준서 본문과 구별한 비권위성 참고자료다.

실제 Luna 채점과 정본·공개본·암호화본·학습 분류·운영 DB 반영을 완료했다. 실행 및 게시 근거는 [검토 배치](../../analysis/reviews/case-applied-2026-09-14/README.md)를 따른다. 작성 당시 초안의 상태와 바이트는 그대로 보존한다.

[선택한 기존 보증추정 사례의 부분점수 설명](partial-credit-examples.md)은 현재 채점 기준에 따른 설명이다. 이 설명을 위한 새 모델 호출은 하지 않았으며, 이번 신규 6사례의 실측과 구별한다.

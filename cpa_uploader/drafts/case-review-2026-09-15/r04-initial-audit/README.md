# r04: 초도감사 사례의 재구성

29번 사례(`pilot-09-010`)를 사용자 지시와 선택에 따라 초도감사 종합 문제로 다시 만들었다. 현재 판본은 [v2](v2/questions-and-answers.md)다.

v2는 문항 내용을 바꾸지 않았다. 새로 등록한 KGA 300 발췌본에 출처·확인일 두 줄을 더하고 원문 소제목 “시행일”을 뺀 v2 등록본에 맞춰, kga300-13 출처 제목의 줄 표시(L11-L18→L13-L20)만 고쳤다. v1 발췌본은 원자료 카탈로그가 그 소제목을 판본 설명으로 표시했다. v2 폴더에는 [build-draft.mjs](v2/build-draft.mjs)(v1과의 차이를 단언), [sets.json](v2/sets.json), design·lineage·qa([record-docs.mts](v2/record-docs.mts)), [문제지](v2/questions-and-answers.md)가 있다. 아래 표는 v1 파일이다.

| 파일 | 내용 |
| --- | --- |
| [sets.json](sets.json) | 재구성 초안 v1(`needs_review`). [build-draft.mjs](build-draft.mjs)가 원 세트와 등록 전문에서 인용을 그대로 복사해 만든다. |
| [design.json](design.json) | 열두 항목의 옳고 그름과 근거, 물음별 대응표·배점 결정·분류 메모, 정답 암시 제거 내역 |
| [lineage.json](lineage.json) | 원 세트의 물음·criterion이 옳지 않은 항목·함정·열거 요소·삭제 중 어디로 갔는지 |
| [qa.json](qa.json) | 실제 채점 전에 정한 대표 부분정답·오답과 보조 사례의 기대 판정 |
| [questions-and-answers.md](questions-and-answers.md) | [render-sheet.mjs](render-sheet.mjs)로 만든 사람용 문제지와 실제 채점 결과 |
| [sources/extract-kga300.mjs](sources/extract-kga300.mjs) | KGA 300 문단 3·13(2025 전문 PDF 180·182쪽)을 등록 발췌본 `cpa_uploader/data/official/case-review-2026-09-15-kga300.md`(v2)로 만든 도구. v1을 만든 도구는 [extract-kga300-v1.mjs](sources/extract-kga300-v1.mjs)로 보존했다. |

[record-docs.mts](record-docs.mts)는 design·lineage·qa를 한 번 기록한 도구이며 기존 파일이 있으면 쓰지 않는다. 다른 세션이 같은 배치에서 r03(59·30번 병합)을 먼저 사용해 이 작업은 r04로 기록했다.

## 사용자 지시와 선택

- 물음 1: 수정 방향을 질문해 달라고 했고, 제시한 세 방안 중 계획 단계 선택형을 골랐다.
- 물음 2: 어떤 자료가 어떤 경영진주장에 대한 증거를 제공하는지 나열하는 물음으로 바꾼다. 두 해석 중 수험생이 나열하는 열거형을 골랐다.
- 물음 3: 당기 실사·수량변동 자료를 바탕으로 기초 재고자산 항목의 평가에 대한 감사증거를 입수하였다는 함정을 둔다.
- 물음 4: 삭제한다. 초도감사 관련 물음은 사실관계에 맞게 추가한다.

## 구성

- 물음 1(착수·계획 ①~⑤): ① 계약 체결 전 수임 절차와 전임감사인과의 커뮤니케이션(옳음), ② 공시된 전기 재무제표와 전임감사인 감사보고서 열람(옳음), ③ 전임감사인이 조서 열람을 거절하자 기초잔액 증거를 얻을 수 없다고 보고 한정의견을 계획(옳지 않음), ④ 전기 마감잔액의 이월 확인(옳음), ⑤ 전임감사인 한정의견 사유(장기대여금)를 당기 위험평가에 반영하지 않음(옳지 않음).
- 물음 2(열거): 기초 매출채권의 당기 회수 내역 (가)와 기초 매입채무의 당기 지급 내역 (나)가 증거를 제공하는 개시일 잔액의 주장(실재성, 권리와 의무, 완전성, 평가).
- 물음 3(기초잔액 ⑥~⑨): ⑥ 실사 수량을 기초수량으로 조정한 결과로 기초 재고의 수량과 평가 증거를 입수했다고 결론(옳지 않음, 사용자 지정 함정), ⑦ 매출총이익률 분석과 기초 전후 기간귀속 테스트(옳음), ⑧ 기초 장기차입금 잔액의 은행 조회(옳음), ⑨ 부도 거래처 채권의 충당금 미인식을 전기 사항으로 보아 다루지 않음(옳지 않음).
- 물음 4(감사보고서 ⑩~⑫): ⑩ 해결된 전임감사인 한정의견 사유를 당기 의견 변형 사유로 보지 않음(옳음), ⑪ 당기 재무제표에만 의견을 표명(옳음), ⑫ 기타사항문단에서 전임감사인 의견의 유형과 사유를 뺌(옳지 않음).
- 새로 더한 초도감사 요소: KGA 300 문단 13(①), KGA 510 문단 5·6(a)·9·7·13·A7·A9(②·④·⑤·⑧·⑨·⑩), KGA 710 문단 2·17(⑪·⑫).

## 배점

물음 1·3·4는 옳지 않은 항목을 정확히 고른 식별 1점(옳은 항목을 고르거나 빠뜨리면 0점)과 옳지 않은 항목마다 이유 또는 보완절차 중 하나를 핵심 원칙 수준으로 쓴 1점을 둔다. 물음 2는 주장마다 1점인 열거형이다. 물음별 3·4·3·2점, 합계 12점이다.

## 검증과 남은 일

agent 내용 검토, 초안 형상·인용 검사(`validate_draft_v3.ts --against-bank`), 후보 은행 검사, 실제 Luna 채점(v1·v2 모두 대표 12답안 점수 일치, 보조 1회 판정까지 일치)을 마쳤다. 새 KGA 300 발췌본 등록에 따라 분석 생성물과 wiki 원자료 목록을 다시 생성했다. 정본·공개본·운영 DB 반영, 원 세트의 퇴역, coverage 연결 갱신은 하지 않았다. 세부는 [검증 장부](../../../analysis/reviews/case-review-2026-09-15/README.md).

## 변경

1. 원 5물음·12점의 개별 적합성·상세 절차 요구를 번호가 붙은 8개 절차·판단 중 옳지 않은 것을 고르는 2물음으로 바꿨다. 옳지 않은 항목은 물음 1에서 ②·④, 물음 2에서 ⑤·⑥·⑧이다.
2. 제목·사실·발문에 드러나던 정답 결론과 답안 구성요소를 제거했다. 회사·조직 역할, 1~9월 보고서, 하위서비스 제외, 보충통제와 10월 시스템 변경의 전제를 통일했다.
3. 연도는 20X1년으로 썼다. 2027년 시험 대비라는 대상 연도와 기존 판본 적용 가정은 검토 메모에 남겼다.
4. 물음별 정확한 식별 1점, 옳지 않은 항목별 간략한 이유 또는 보완절차 1점이다. 규정 열람을 통한 설계 이해와 실제 운영효과성 입증을 구별한다. 기간 부족과 변경 고려도 별개의 오류로 평가한다.

## 검증

- 직접 내용 대조: 작성 agent가 KGA 402 문단 17·18·A32~A34·A38·A40, 2026 전문의 시행일·본문, 모든 사실·항목·모범답안·기준·기대값을 대조했다. 실제 사람 확인이나 독립 교차검토로 기록하지 않았다.
- 형상·인용·동일 발문 충돌 검사와 현재 은행에 초안을 더한 후보 전체 검사를 통과했다. 학습 분류·사례 단위 투영, 빈 답안·공개본 비밀정보 제외 등 실행 사전검사도 통과했다.
- 대표 실측: Luna 3회 요청으로 물음별 6답안 모두 기대점수와 일치(6/6). 보조 실측: 1회 요청, 2답안 모두 만점 및 기대판정 일치. 입력·출력·캐시 토큰과 요청/응답 ID는 원 로그에 보존했다.
- 일부 식별 기준에서 예상 `contradicted`와 실제 `not_met`이 달랐다. 양쪽 모두 0점이고 오선택을 인정하지 않은 판정으로 내용·점수 오류가 아니므로 기대표를 고치거나 재호출하지 않았다.
- 총 4회 약 $0.00917. 기존 도구의 2026-09-12 단가표에 실제 사용량을 곱한 값이며 청구액과 구별한다.

## 상태

초안 내용검토와 실제 채점은 완료했다. `sets.json`의 상태는 `needs_review`로 유지하며, 정본·공개본·운영 DB 반영과 원 두 세트 퇴역은 기존 사용자 결정대로 지정 검토를 모아 진행한다. 다른 문항은 수정하지 않았다.

제작·검토 스킬과 [공통 사례형 계약](../../../../docs/물음별-학습-단위와-분류-계약.md#사례형-발문과-절차-선택형)에 병합 전제 대조를 보완했다. 실제 생성·기록 도구는 [build-draft.mjs](build-draft.mjs), [record-review.mjs](record-review.mjs), 표시 문서 생성기는 [render-sheet.mjs](render-sheet.mjs)다. 검토·실측 입력은 이미 봉인된 파일이므로 재실행 시 새 판본을 만든다.

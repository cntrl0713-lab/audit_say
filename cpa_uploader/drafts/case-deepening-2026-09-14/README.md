# 사례형 심화 추가 제작

기출·고급회계감사연습의 지문·발문·해설과 공식 기준서를 대조하여 6사례·18물음·38점을 제작했다. 각 사례는 물음 3개와 사실관계 813~913자로 구성했다. 사실관계는 제목·물음을 제외한 `facts` 본문을 LF 하나로 연결한 Unicode 코드포인트 수이며 공백을 포함한다.

[문제·모범답안·부분점수 기준](review-preview.md)은 고정된 제작 입력에서 생성한 검토용 문제집이다.

정본·공개본·암호화본·학습 분류와 운영 DB 반영을 완료했다. [최종 문제·모범답안](questions-and-answers.md)과 [제작·검증 결과](../../../docs/reports/case-deepening-2026-09-14.md)를 함께 확인할 수 있다.

## 입력과 검토 근거

- 작성자별 [A 설계](a/design.json)·[검토](a/review.json), [B 설계](b/design.json)·[검토](b/review.json)에 원발문·해설·공식 문단과 배점 결정을 연결했다. 기출·모의·연습의 직접 요구와 인접 주제를 구별한다.
- [A 독립 검토](a-peer-review.json)·[B 독립 검토](b-peer-review.json)와 [공식 출처 검토](source-peer-review.json)를 보존했다. 기존 은행과 초안의 차이는 [조회 인벤토리](draft-inventory.json)와 개별 설계에 기록했으며 인벤토리 전체를 의미검수한 것으로 표시하지 않는다.
- 사용한 원자료는 [raw 수집 기록](../../raw/collections/2026-09-14-case-deepening/index.md)에 원래 경로·파일 해시·보존본으로 연결했다. 교재에 재수록된 기출을 공식 기출 PDF를 직접 확보한 것으로 표시하지 않는다.
- 부분점수는 독립적인 의미 단위의 정수 합계다. 1점 물음에는 0점과 1점 사이의 정수 부분정답이 없으므로 모범답안과 대표 오답을 실측했다. 총 모범 18·부분 17·오답 18답안은 Luna에서 모두 기대점수와 정확히 일치했다.

위 내용 검토는 agent가 수행했다. 사람의 직접 내용 확인이나 별도 API 의미검수를 수행한 것으로 기록하지 않는다. 과거 peer 기록과 수정 전 B 입력은 그대로 보존하고 후속 기록으로 정정했다.

실제 검수·채점·정본·운영 반영은 [검토 배치](../../analysis/reviews/case-deepening-2026-09-14/README.md)에서 구별한다.

# 승인 범위와 실행 정책

2026-09-14 사용자 요청: “정본·공개본·운영 DB의 물음이나 배점에 모두 반영해줘”.

앞선 기준서형 354물음의 배점 전수 검토와 설명한 정수 부분점수 방식을 적용한다. 분리·통합·중복 정리·과소배점 보완에 필요한 발문·답안·criterion·분류·계보 및 공개본·운영 DB 반영을 포함한다. 이 승인은 사람이 모든 문항 내용을 직접 읽고 확인했다는 뜻이 아니다.

내용은 담당 agent와 통합 검토자가 직접 출처와 대조하고, 별도 유료 API 의미검수를 기본으로 반복하지 않는다. 실제 채점은 gpt-5.6-luna로 저장 모범답안·대표 부분정답·대표 오답을 실행한다. 물음별 ±1점, 대표 답안 95% 이상 허용 목표를 적용하되 내용·출처·형상·보안 오류는 면제하지 않는다. 예산 금액은 이번 요청에서 별도로 지정되지 않았으며 과거 $20 한도를 새 배치에 설정했다고 주장하지 않는다. 제공자 한도 오류에서 모든 새 호출을 멈추고 실제 반환 사용량과 요청 식별자를 보존한다.

과거 입력·실측·승급 장부 및 풀이 기록을 보존한다. 단순 삭제에 따른 잔존 물음은 기존 검수된 학습·채점 계약의 동일성을 증명하며 동일한 모델 입력을 불필요하게 다시 호출하지 않는다. 내용이 변경된 새 물음의 검수와 혼동하지 않는다.

# pilot-01-005 종합문제 대체 및 검토

`pilot-01-005`를 2물음·4점의 단순 판단형에서 3물음·10점의 사례형 종합문제로 대체했다. 세트 ID는 유지했고 제목은 `감사 수임부터 보고서일까지의 독립성·품질관리`로 변경했다.

## 설계 결과

- 공통 지문: 1,079자
- 물음 1: 주식보수, 공동사업, 낮은 보수의 수임 판단 — 4점
- 물음 2: 감사 중 윤리 위반 징후와 독립성 대응 — 3점
- 물음 3: 의견 차이, 업무품질관리검토 완료와 보고서일 — 3점
- 모든 물음: `question_style=case`, `topic_ids=["01"]`
- 배점: 부적절한 항목의 정확한 식별 1점 + 항목별 이유 또는 수정조치 각 1점

기출 반복요소는 [design.json](../../../drafts/pilot-01-005-comprehensive-2026-09-18/design.json)에 기록했다. 2014·2019년 낮은 보수, 2016·2024년 공동사업, 2020·2022년 주식보수 요소와 고급회계감사연습의 다중 상황 판단 형식을 참고했다. 정답 근거는 윤리기준 240.1~2·290.113·290.132와 종전 KGA 220 문단 9~11·19·22·A26에 직접 연결했다.

## 검토 결과

- 형상·원문 인용 실존: 통과
- agent 내용 검토: 3물음, 10 criterion, 미해결 내용 오류 0건
- Luna 대표채점: 모범·부분·오답 9건을 3회 요청으로 실행, 9/9건 ±1점 이내
- 모범답안: 3/3 물음 정확 일치
- 부분답안 한 건: 의견 차이 해결만 적고 보고서 발행 시점을 명시하지 않아 예상보다 1점 낮게 채점됐으나 허용 오차 이내이며 내용 오류는 아님
- 봉인 검토 배치: [batch-v1.json](batch-v1.json)
- 검토 receipt: [receipt-v1.json](receipt-v1.json)

## 반영 범위

로컬 정본, 승급장부, 공개본, 암호화 파생본, 학습 분류, 커버리지 분석, 위키 문제 페이지를 갱신했다. 세트는 `published/verified` 상태다. 운영 데이터베이스에는 반영하지 않았고 읽기 전용 준비검사만 통과했다.

전체 v3 정본 검증, 학습 카탈로그 check, analysis build/check는 통과했다. 위키 생성 결과의 drift는 0건이지만 전체 wiki check는 이번 문항과 무관한 기존 `log.md`의 끊어진 링크 2개와 400줄 제한 초과 때문에 실패한다.

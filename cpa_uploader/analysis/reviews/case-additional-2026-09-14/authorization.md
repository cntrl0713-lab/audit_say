# 사례형 추가 제작 범위

2026-09-14 사용자가 사례형 추가 제작을 요청하고, 제작량 질문에 **6개 사례·사례당 3개 물음**으로 답했다. 이전에 확정한 사례당 사실관계 400자 이상, 기출문제·고급회계감사연습 참고, 모든 물음의 사례 사실 적용을 이어받는다.

검증을 통과한 결과의 **정본·공개본과 운영 DB까지 반영**한다는 대화의 기존 승인도 유지한다. agent의 내용 검토와 실제 Luna 대표 답안 채점 후 게시하며 사용자가 모든 정답을 직접 검수한 것으로 기록하지 않는다. 채점은 ±1점·대표 답안 95% 목표이고 내용 오류의 허용률은 없다. 새 배치 금액 상한은 미지정이며 실제 제공자 한도 오류에서 중단한다.

# 기준서형 수정·스포일러 전수 검토의 범위

2026-09-19 사용자는 사례형 지정 검토(case-review-2026-09-15 r01~r11)에 이어 “기준서형 물음에서도 수정할 사항과 스포일러요소를 확인하고 수정해줘”라고 요청했다.

## 이 배치에서 수행하는 범위

- 대상: 현재 정본의 기준서형 물음 전체(학습 분류 입력 기준 372물음)를 발문·모범답안·criterion·출처와 대조한다. 발문이 득점 내용(정답 항목·핵심어·결론·판단 방향·형제 물음의 정답)을 알려 주는 경우와 그 밖의 수정 사항(답안 형식 표시, 출처와 어긋난 명제, 중복 배점, 채점 입력의 옛 발문 참조)을 고친다.
- 방법: 게시 문항 수정 경로(`cpa_uploader/corrections/`, 세트당 correction 하나)로 고친다. 학습 유형·주제·물음 구성은 바꾸지 않는다.
- 검수: 작성 agent의 내용 대조와 Luna(`gpt-5.6-luna`) 대표 채점(물음별 모범·부분·오답)을 수행한다. 프로젝트 정책(물음별 ±1점, 대표 답안 95% 목표, 내용 오류 허용 없음, 모델 상향 없음)을 이어받는다. 금액 상한은 지정되지 않았으며 제공자 한도 오류에서 중단한다. 별도 유료 API 의미검수는 하지 않는다.
- 반영: 오류가 없고 채점 일관성 기준을 충족하면 로컬 정본·공개본·암호화 파생본·학습 분류·분석·위키에 설치한다. 운영 데이터베이스 반영은 사용자가 직접 실행하는 명령으로 넘긴다.
- 사례형 물음: 혼합 세트(기준서형과 사례형 물음이 함께 있는 세트)의 사례형 물음은 바꾸지 않는다. 사례형 정답 암시 기준에 따른 개선은 사용자가 지정하는 사례 검토에 남긴다(AGENTS.md: 기존 사례는 사용자가 지정한 것만 고친다).

agent 검토는 작성한 agent가 수행한 내용 대조이며 사람의 직접 확인이나 독립 교차검토로 기록하지 않는다.

[병합 종합문제 설계](../../../../docs/사례형-병합-종합문제-설계.md)의 **C등급**을 제작한 일곱 번째 묶음이다. C등급은 "새 병합보다 **기존 갱신본 확장**이 맞는 것"이며, 이미 선택형으로 갱신된 세트에 그 세트가 빠뜨린 논점을 더한다.

`cpa_uploader/corrections/` 경로는 게시 세트의 필드만 고치고 **물음 구성은 바꾸지 못하므로**, 이 작업은 제작 경로를 따른다. 대상 갱신본과 확장 재료를 모두 퇴역시키고 둘을 합친 새 세트를 만든다. 저장소의 기존 선례("52 대체 + 추가 요소 → `case-16-kam-emphasis-20260919`")와 같다.

A·B등급에서 확정한 정책을 이어받는다: 병합 대상에 섞여 있는 기준서형 물음은 **별도 기준서형 세트로 분리 보존**한다. 이번 배치에서는 r31의 `pilot-16-008` 기준서형 2물음이 여기에 해당한다.

이전 묶음의 authorization.md와 배치 단위 [authorization.md](../authorization.md)는 각 실행 manifest가 입력 해시로 고정하므로 고치지 않았다.

## 운영 명령

운영 명령(`--prepare`·`--probe`·`--apply`)은 자동 모드 분류기가 agent 실행을 막으므로 **사용자가 터미널에서 직접 실행**한다. agent는 도구·범위·기록만 준비하고 결과를 장부에 옮긴다. 적용이 실패하거나 결과가 불명확하면 다시 적용하지 않고 읽기 전용으로 상태를 확인한다.

## 이 승인에 없는 것

모델 상향, 별도 유료 API 의미검수, 사람의 내용 확인은 포함되지 않는다. agent 검토는 초안을 만든 agent의 내용 대조이며 독립 교차검토나 사람 확인으로 기록하지 않는다. 게시 stage·기준·후보 사본과 운영 전송 SQL은 커밋하지 않는 `tmp/`에 두고 기록에는 해시만 남긴다.

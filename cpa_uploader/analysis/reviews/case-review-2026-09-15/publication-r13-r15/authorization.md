## 운영 반영과 r12

- 이 시점의 정본에는 다른 세션이 2026-09-20에 설치한 r12(`case-10-analytical-procedures-20260920` 추가, `case-10-completion-analytics-20260914`·`pilot-10-007` 퇴역)가 이미 들어 있고, 운영 active release `2ed1a151`에는 없다. 곧 정본이 운영보다 앞선 상태다.
- 사용자가 "r12까지 같이 운영 반영"을 지시했으므로 이번 증분 릴리스에는 r12의 추가·퇴역 2건이 함께 올라간다. r12 문항 내용은 이 배치에서 수정하지 않는다.
- r12를 설치한 세션이 받은 지시는 정본 설치와 원 2세트 퇴역까지였고 운영 반영은 그 범위 밖이었다. 운영 반영 포함은 이 세션 사용자의 지시에 따른 것이며, 실행 직전에 해당 세션에 통지한다.
- 운영 DB 명령은 로컬 준비검사와 읽기 전용 확인을 먼저 거친다. agent가 운영 명령을 실행할 수 없으면 적용하지 않고 사용자가 실행할 명령과 준비 기록을 남긴다. 적용이 실패하거나 결과가 불명확하면 다시 적용하지 않고 읽기 전용으로 상태를 확인한다.

## 이 승인에 없는 것

모델 상향, 별도 유료 API 의미검수, 사람의 내용 확인은 포함되지 않는다. agent 검토는 초안을 만든 agent의 내용 대조이며 독립 교차검토나 사람 확인으로 기록하지 않는다. 게시 stage·기준·후보 사본과 운영 전송 SQL은 커밋하지 않는 `tmp/`에 두고 기록에는 해시만 남긴다.

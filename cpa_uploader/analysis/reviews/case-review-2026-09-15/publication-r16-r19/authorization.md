# r16~r19 정본 반영과 운영 반영 승인

2026-09-20 사용자 지시: "설계서에 따라서 사례형 문제 제작해서 대체해줘", "정본 설치하고 운영 반영까지 진행해줘"

[병합 종합문제 설계](../../../../docs/사례형-병합-종합문제-설계.md)의 A등급 4묶음을 제작한 다섯 번째 묶음이다. 범위는 사용자가 두 질문에 답해 확정했다.

- 이번 제작 범위는 **A등급 4묶음까지**다(B·C·D등급은 이번 범위가 아니다).
- 병합 대상에 섞여 있는 기준서형 물음은 **별도 기준서형 세트로 분리 보존**한다(퇴역시키지 않는다).

이전 묶음의 authorization.md는 각 실행 manifest가 입력 해시로 고정하므로 고치지 않는다.

- **기준서형 분리**: `pilot-07-006`은 사례형 2물음이 r17 병합본으로 대체되고, 같은 세트의 기준서형 물음 `sub4`(3점)는 새 세트 `pilot-07-006-standards-20260920`으로 옮겨 살린다. 원 발문이 정답 항목을 암시해 문단·항 기호로 범위를 정하는 발문으로 고쳤고 criterion·배점·모범답안·출처는 승계했다. 이 계보를 승급 장부와 coverage에 함께 남긴다.

- 정본·승급 장부·공개본·암호화본·학습 분류 입력과 카탈로그를 갱신하고, 퇴역 세트를 가리키는 coverage 관계를 다시 연결하며, 퇴역 세트의 wiki 생성 페이지는 원 바이트를 보존한 뒤 제거한다. 원 세트의 과거 판본과 풀이 기록은 보존한다.
- 운영 DB에는 증분 릴리스로 반영한다. 기준 원문은 현재 active release `3518cda6`의 저장 원문이며 이 시점의 정본과 같은 바이트다.

## 운영 명령

운영 명령(`--prepare`·`--probe`·`--apply`)은 자동 모드 분류기가 agent 실행을 막으므로 **사용자가 터미널에서 직접 실행**한다. agent는 도구·범위·기록만 준비하고 결과를 장부에 옮긴다. 적용이 실패하거나 결과가 불명확하면 다시 적용하지 않고 읽기 전용으로 상태를 확인한다.

## 이 승인에 없는 것

모델 상향, 별도 유료 API 의미검수, 사람의 내용 확인은 포함되지 않는다. agent 검토는 초안을 만든 agent의 내용 대조이며 독립 교차검토나 사람 확인으로 기록하지 않는다. 게시 stage·기준·후보 사본과 운영 전송 SQL은 커밋하지 않는 `tmp/`에 두고 기록에는 해시만 남긴다.

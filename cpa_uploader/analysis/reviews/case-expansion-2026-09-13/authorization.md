# 사례 분량·물음 수 보강 범위

사용자는 기출문제와 고급회계감사연습을 참고하여 하나의 사례에 물음 2개 이상, 사실관계 400자 이상을 구성하고 추가 제작할 만한 사례는 제작하도록 요청했다. 400자는 제목·발문을 제외한 `facts[].text`를 줄바꿈 하나로 연결하여 공백 포함 Unicode 문자 수로 계산한다고 안내했다.

기존 “정본·공개본과 운영 DB까지 반영” 승인을 이어받는다. 이는 대화의 승인 근거이며 사람의 문항 내용검수를 수행했다는 기록이 아니다. 기존 판본·과거 제출·검수 증거를 보존하고 후속 판본으로 반영한다.

내용은 담당 agent가 실제 원발문·정답·공식 근거와 대조한다. 현재 Luna 모델과 물음별 ±1점·대표 답안 95% 실측 목표, 내용 오류 허용 0 정책을 유지한다. 제공자 한도와 기존 실행기의 $20 배치 기록을 이어받고 한도 오류에서 중단한다. 별도 유료 의미검수나 모델 상향은 하지 않는다. 실제 반환 사용량·비용과 오류는 실행별로 보존한다.

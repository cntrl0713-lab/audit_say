# 2026-09-13 사례 보강 후속 검토

사용자 확정 범위는 [authorization.md](authorization.md)에 기록했다. 최초 기준과 운영 판본은 [baseline.json](baseline.json), 초안 및 실제 자료 대조는 [제작 배치](../../../drafts/case-expansion-2026-09-13/README.md)로 연결한다.

- 기존 41개 사례 중 23개가 물음 2개 이상·사실관계 400자 이상 조건에 미달한다.
- 이 23개를 보강하고 통제무력화·미공개 특수관계자 거래 사례 2개를 추가 제작한다.
- 섞여 있던 기준서형 35물음은 [분리 계보](standard-lineage.json)에 따라 기존 독립 학습 발문·정답·배점을 보존한다.
- 기존 검수·실측·게시 이력은 변경하지 않고 이 배치에서 후속 검증한다. 채점 실행 전 상태는 초안·내용 대조이며 실제 채점과 게시 완료를 뜻하지 않는다.

실제 채점은 `execution-v1/`과 `execution-resume-v2/`의 완료 관측을 보존하여 `execution-resume-v4/`에서 마쳤다. `execution-resume-v3/`는 모델 호출 없는 사전 검사 실패 기록이다. 최종 수락 근거는 `sealed-v1/`이다. `publication-v1/`은 병행 정본 변경을 감지해 설치하지 않았고, 그 추가 문항과 이력을 보존한 `publication-v2/`를 설치했다. `db-publication-v1/`에 운영 반영 및 독립 조회 검증을 보존한다.

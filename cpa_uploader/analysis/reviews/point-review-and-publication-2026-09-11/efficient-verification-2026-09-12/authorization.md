# 이번 실행의 사용자 결정

현재 대화에서 이어받은 지시를 기록한다. 이 파일은 사용자 정책과 작업 범위의 기록이며, 사용자가 문항 내용을 직접 전수 확인했다는 증거가 아니다.

- “모델은 luna를 사용해 / 모델 상향하면 비용 감당이 안돼”
- “물음당 1점 이내 수용”
- “아직 수익을 창출하는 프로젝트가 아니기 때문에 비용통제가 중요한 요소야 비용효율화를 이루기 위해서 +-1점 또는 신뢰도 95%정도로 맞추도록 하자”
- “해당 내용을 agent.md나 스킬에 반영하고 나머지 세트도 마저 검증한 후에 DB적용해줘”
- 남은 검증 비용 상한 답변: “최대 20달러”
- “요청 전에 예상 비용을 확인하면서 토큰 사용해야하면 안 해도 돼 / api제공하는 측에 한도 걸어뒀어”
- “비용효율화를 위해서 신뢰도 95% +-1점 정도의 오차를 허용하는건 채점의 일관성이야 / wiki나 모범답안 등 기반 자료는 완벽해야해”
- “배점을 적절성도 함께 확인해줘”

이에 따라 내용은 agent가 원출처와 전수 대조하고, 별도 API 의미검수는 필수로 반복하지 않는다. 실제 Luna 채점은 사전에 선정한 대표 답안으로 확인한다. 95%는 해당 검증 집합에서 물음별 점수 편차가 ±1 이내인 관측 비율이며 통계적 신뢰도 주장이 아니다. 내용 오류·불명확한 근거·보안·실행 오류는 이 허용률의 대상이 아니다.

검증 후 정본 및 운영 DB 반영은 승인된 범위다. 앱 배포는 포함하지 않는다. 기존 실행과 검수 기록을 보존하고 새 출력·잠금·증거를 사용한다.

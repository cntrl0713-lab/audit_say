# 국내 감사기준서 800 공식 원문 확인

국내 원문을 확인했다. 한국공인회계사회 [800·805·810 공식 게시판](https://www.kicpa.or.kr/board/list.brd?boardId=acc0103)의 최신 개정 게시물은 [2020-09-25 안내](https://www.kicpa.or.kr/board/read.brd?boardId=acc0103&bltnNo=11601007425644)다. 기타감사기준 메뉴가 아니라 회계감사기준 메뉴의 세 번째 탭이다.

공식 [붙임 1 DOCX](kga800-805-810-2020-1.docx)에서 회계감사기준위원회의 2020-09-23 의결, 문단 4의 **2020-12-31 이후 개시 보고기간 시행·조기적용 가능**을 직접 확인했다. 이 날짜는 이번 2026년 개시 가정에 적용 가능하다. 2027 시험공고가 개별 판본을 지정했다는 주장은 하지 않는다.

`pilot-19-003/sub1`은 국내 800.8(a)~(c)의 작성 목적·의도된 이용자·수용가능성 결정에 관한 경영진 조치와 일치한다. `sub2`는 800.9/A9의 관련 기준 준수·예외적 이탈·대체절차와 기존 200.23/A65의 구체 조건을 함께 읽어야 한다. 두 물음의 3점씩을 유지할 수 있으며 국내 출처와 시행 근거를 후속 연결하면 된다.

800.14와 A20은 특정목적 작성 및 다른 목적 부적합 가능성에 관한 강조사항을 요구한다. A21의 이용자 표시·배포 또는 이용 제한은 해당 상황에서 고려하며 일률적인 제한 의무가 아니다. 이 보고 내용은 현재 19-003의 두 물음에 추가 배점할 근거가 아니다.

[판단 장부](decision.json), [전체 순서 추출](attachment-1-paragraphs.json), [등록 전사 및 원문 대응](transcription-evidence.json)을 남겼다. 원문 번호는 별도 셀/문단에 있어 전사에 번호 뒤 마침표·공백만 붙였으며 본문은 변경하지 않았다. DOCX를 PDF로 오인해 쪽번호를 만들어내지 않고 `word/document.xml`의 문단 위치로 연결했다. 첫 다운로드의 `.zip`과 읽기용 `.docx`는 동일 바이트이며 서로 다른 판본이 아니다.

이 조사는 API 채점 0회다. 총괄이 raw와 공식 카탈로그에 등록한 실제 경로·ID를 C가 사용한다. A의 앞선 56세트 검토 인계와 기존 은행·문항·QA는 변경하지 않았다.

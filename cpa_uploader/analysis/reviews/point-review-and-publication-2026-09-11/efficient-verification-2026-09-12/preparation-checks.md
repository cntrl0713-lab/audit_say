# 유료 호출 전 통합 검사

아래 발견은 실제 모델 호출 전에 발생했다. 실패한 준비를 검증 완료로 사용하지 않는다. `candidate-preparation-incomplete-v1/`과 `candidate-preparation-incomplete-v2/`는 manifest 생성 전 중단된 출력이며 실제 API 증거가 없다.

| 발견 | 처리 |
| --- | --- |
| 일부 후속 초안이 객체 대신 단일 원소 배열 | 정확히 한 세트인 배열만 읽도록 통합기를 보완. 문항 바이트는 유지 |
| 국내 800 출처의 page 필드에 XML 위치를 저장하여 KGA 분류 불일치 | C가 과거 인계와 문항을 보존하고 page를 KGA 800으로 교정. 실제 XML 위치는 source_span 유지. 전체 은행 validator의 오류 배열도 검사 |
| A의 모범답안 대표 43개가 저장 모범답안과 바이트 불일치 | 공백·줄바꿈 차이 20개와 다른 표현 23개. 뜻이 비슷한 QA로 실제 저장 모범답안 시험을 대신하지 않고 새 QA 사례를 선정. 이전 답안·기대값 보존 |
| C의 오답 대표 36개가 실제로는 양의 점수를 받는 경계 답안 | 원 기대값을 0점으로 바꾸지 않음. 원 경계 답안을 보존하고 현재 실행 역할의 0점 대표를 새로 선정 |

통합기는 파일을 쓰기 전에 저장 모범답안 바이트, 원 QA 답안과 기대 판정, criterion 전체, 정수 합계와 역할별 점수 범위를 검사한다. 실제 호출 실행기도 같은 사전 차단을 적용한다. 최종 승급 검증의 고정 분모·실제 응답 재생·보안·출처 검사는 별도로 유지한다.

초기 전체 테스트 518개가 통과했다. 국내 800 등록 후 출처 catalog 테스트는 과거 기준서 5종 단언을 6종의 실제 집합·국내 공식 출처·시행 문단·35개 원문 단위 검사로 갱신하여 19개 모두 통과했다. 테스트의 최초 c항 부분문구 가정도 실제 원문에 맞췄으며 실패 로그를 보존했다. 타입 검사 중 다른 작업이 삭제한 jobs 페이지를 과거 Next 생성 파일이 참조하는 오류가 있었고, 현행 route type 재생성 및 개발 서버 갱신 후 재검사한다. 삭제된 앱 페이지를 복구하거나 변경하지 않았다.

최종 준비·실행·DB 결과는 후속 고정 manifest와 결과 보고서를 따른다. 이 문서는 그 단계의 성공을 미리 선언하지 않는다.

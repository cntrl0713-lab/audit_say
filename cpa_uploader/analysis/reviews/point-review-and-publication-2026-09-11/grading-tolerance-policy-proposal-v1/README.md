# 사용자 지정 채점 편차 지침 후속안

이 파일은 현재 실행 입력을 바꾸지 않는 지침 수정안이다. 실행 잠금에 포함된 AGENTS.md·스킬을 아직 수정하지 않았다. 실제 반영 시 이전 바이트와 실행 잠금을 보존하고 후속 수락·실행 버전에 연결한다.

## AGENTS.md에 추가할 공통 원칙

사용자가 채점 모델·비용·허용 편차를 명시하면 해당 작업 범위의 검증 정책에 기록한다. 허락 없이 모델을 상향하거나, 허용된 편차를 없애기 위해 반복 호출하지 않는다. 원문·정답·출처 검증과 실행·응답·보안·증거 무결성 검사는 점수 편차와 구분한다. 원래 기대값·실제 결과·엄격 일치 여부를 보존하며, 사용자 지정 허용 범위로 수락한 결과를 엄격 일치로 바꾸지 않는다. 상세 절차는 검토 스킬의 회귀 지침을 따른다.

## 검토 스킬의 회귀 지침에 추가할 상세 원칙

- 모델·허용 편차는 명시적 사용자 결정이 있을 때 해당 배치에 적용한다. 특정 모델이나 1점 허용을 저장소 전체의 기본값으로 삼지 않는다.
- 물음별 허용 편차는 모든 물음에 각각 적용한다. 다른 물음의 과다·과소 점수를 상쇄한 세트 합계로 판단하지 않는다. 빈 답안 무호출 0점 등 독립 실행 계약은 유지한다.
- 원자료·발문·모범답안·criterion·직접 출처의 결함, 전송·응답 형상·ID·인용 검증·증거 저장 오류와 보안 오탐은 점수 허용만으로 수락하지 않는다.
- 작성자 QA의 완전한 기대표와 생성 사례의 부분 target 기대표를 구분한다. 전체 물음 점수로 비교하려면 답안 전체와 모든 criterion을 직접 대조한 기대 근거가 필요하다. 모델 점수에 맞추어 기대값을 바꾸지 않는다.
- 정확한 기대점수가 불명확하더라도 출처·발문·rubric·답안에서 먼저 산출한 보수적 기대범위가 있으면 최악의 편차로 판단할 수 있다. 기준별 최소·최대의 합을 L, U라 할 때 모든 관측에서 max(|실제−L|, |실제−U|)가 허용폭 이하여야 한다. 실제가 범위 안에 든다는 이유만으로 수락하지 않는다. 실제 점수를 보고 유리하게 범위를 좁히지 않는다.
- 기대값·원 receipt·raw 판정·엄격 matched·모든 반복 관측을 보존한다. 별도 수락 기록에는 원 receipt, 정책, 대상·출처·코드, 전체 기대 근거, 관측 목록과 각각의 물음별 차이를 결속한다. 점수 수락은 의미검수 pass 또는 사람의 실제 내용 확인을 대신하지 않는다.
- 사용자 허용 범위 안이라고 확인된 편차만 없애려는 추가 진단 반복은 하지 않는다. 이미 실행한 반복은 기록에 남기며, 기본 반복 지침보다 사용자의 명시적 호출·비용 제한을 우선한다. 허용폭 밖의 차이와 내용 오류는 근거를 조사하여 수정·재검증하거나 미완료로 남긴다.

## 이번 배치의 확정값과 구분

이번 119세트의 확정값은 기존 `grading-inference-followup-v2/minor-error-policy.json`에 있다. 사용자는 Luna와 물음당 ±1점을 지정했다. 위 제안은 이를 보편적인 1점 허용으로 확장하지 않고, 앞으로도 명시적 사용자 정책을 정확히 적용하기 위한 공통 절차다.

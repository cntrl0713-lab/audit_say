# pilot-08-007 출처·중복 독립 대조

[원 부분 로그](../execution-new-resume-a-v1/semantic-a/pilot-08-007/semantic.json.chunks.jsonl)의 오류 없는 단위 응답 중 source_support fail/uncertain 및 관련 nonduplication을 대조했다. 원 판정은 보존했고 API 호출은 0회다. 전체 검수 통과·사람 확인·DB 반영을 기록하는 문서가 아니다.

## 결론

미기록 거래의 선택 불가능성, 원장 밖 출고·운송·인수 자료의 선정, 변경된 운송기간에 맞춘 검사 범위 조정은 **제시 사실에 일반 기준을 적용한 정당한 추론**이다. 동일한 사례 문장이 기준서에 있어야 하는 것은 아니다. 다만 과거 subquestion 단위가 열거한 출처가 실제 criterion 보완 근거보다 좁은 문제는 구분해야 한다. 새 공식 원문을 추가하거나 정답을 줄일 필요는 이 출처 지적만으로 확인되지 않았다.

## 확인한 경계

- A190은 주장 정의, A31·A32는 목적·방향과 주장별 증거 관련성, 500.7은 관련성·신뢰성 고려, 500.6·A34는 상황에 맞는 절차 설계의 근거다. 자료명과 계약조건은 fact2·fact3, 7일 범위는 fact4에서 읽는다. 모든 원문 인용은 파일의 정확한 부분문자열이며 실제 카탈로그 ID를 확인했다.
- 현재·이전 계획에 **08-001/sub1 복습은 명시되어 있지 않았다**. 이번 대조에서 확인한 제한된 적용복습을 후속 제안으로 남긴다. 관련성·신뢰성의 일반 요건을 새로운 커버리지로 세지 않는다.
- 모델이 든 08-008은 잘못된 peer다. 실제 07-008/sub1과의 기간귀속 적용복습은 원 계획의 T07-C-Q1에 이미 명시되어 있다.
- 세트 내부 crit5↔crit13 중복은 별개의 실질 문제다. 동일한 인식 증빙·기간 대조 답안이 두 물음에서 각각 같은 행동 점수를 받는다. 단순한 문구 보완으로 해소했다고 하지 않으며 문항별 배점 결정은 총괄에 남겼다.

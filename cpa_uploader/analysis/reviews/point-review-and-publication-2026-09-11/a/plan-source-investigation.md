# A 후속 검수 계획·출처 연결 조사

[고정 후보 인계](handoff.md) 이후의 읽기 조사다. 후보·QA·감사 장부·검사 결과를 바꾸지 않았고 API 호출도 하지 않았다. 실제 조회 결과와 단위별 해시는 [조사 JSON](plan-source-investigation.json)에 기록했다. 이는 출처 연결 가용성 조사이며 의미검수 통과 기록이 아니다.

변경한 22세트 가운데 기존 version1 계획의 실제 `set_id` 또는 명시적 게시 ID 계보로 연결되는 것은 `pilot-05-007` 한 세트다. [기존 계획](../../../../drafts/frequency-gap-2026-09-10/draft-05-240-001.authoring-plan.json)의 `draft-05-240-001`은 [release ID 지도](../../../../drafts/frequency-gap-2026-09-10/release/id-map.json)에서 해당 정본 ID로 연결된다. 기존 범위·2025/2026 판본 대조·부정 보고와 업무 해지의 차이를 유지하고 새 배점에 맞춘 후속 계획을 만들 수 있다. 나머지 21세트는 검색된 계획 JSON에서 같은 ID의 계획을 찾지 못했다. 다른 계획의 비교 문항으로 언급된 것을 원래 출제 계획으로 세지 않았다.

|---|---|---|

200.A47/A49·210.19는 총괄이 [실제 공식 발췌](source-evidence.txt)를 별도 등록하거나, 후속 계획에 그 파일·직접 인용·해시를 넣어 실제 모델 입력으로 전달하는 수동 원문 연결을 확정해야 한다. 학습자료 단위 ID를 공식 원전 전체의 ID로 위장하지 않는다. 기존 인용이나 카탈로그 원문에서 페이지·각주를 제거하는 수정도 하지 않았다.

조사 JSON의 자동 포함 후보는 출처 문구 탐색 결과다. 여러 문단이 들어 있는 저장 인용에는 `unit_is_only_part_of_source_quote`가 있으므로 한 후보만으로 전체 범위를 대체해서는 안 된다. 최종 계획 담당자가 실제 득점 근거와 필요한 의존 문맥을 선택하며, 이번 조사에서는 새 `source_unit_id`나 후속 계획을 만들지 않았다.

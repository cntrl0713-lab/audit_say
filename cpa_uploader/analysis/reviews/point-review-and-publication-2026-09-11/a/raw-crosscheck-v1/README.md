읽은 파일 중 실행 생성기·파서 2개는 원위치와 해시만 남겼다. `data`의 전체 파일 목록·해시를 만드는 과정에서만 읽힌 public/promotions/classification JSON 3개는 wiki 의미 입력이라고 하지 않는다. 반대로 수동 `.mjs` 5개는 직접 렌더 읽기 이후의 범위가 아니라 빈도 추출의 선행 입력으로 따로 기록했다. 수동 SCHEMA·안내·생성기 코드와 생성 wiki 페이지는 원자료 사본 후보가 아니다.

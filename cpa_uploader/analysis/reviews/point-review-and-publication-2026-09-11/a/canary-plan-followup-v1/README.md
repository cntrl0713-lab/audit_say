# A canary QA 후속

[QA35](./qa-pilot-01-002.json)는 기존 34개 사례의 모든 필드를 보존하고 원 생성 반례 1개를 추가한다. 대상 sub2의 실제 criterion은6개이며 새 답안은 모두 not_met로0점이다. sub1 빈답안도0점이므로 세트 전체0/9점이다.

원 반례의 법규상 불허 때 부작위만으로 허용·적합한 경우 해지 조치를 취한다는 양의 절차를 함축하지 않는다. 원 기대 not_met 및 과거1·0·0점 관측을 보존하며, 새 작성자 QA에서는 omission 종류로 엄격 not_met를 검사한다.

[변경 장부](./changes.json)에 원34개 전체동일성, 원답안 바이트, 공식220.11(c) 및 각 명제 누락근거를 기록했다. 35개 로컬 형상·합산 오류0, API0이며 새 코드에서 실제 채점은 미실행이다.

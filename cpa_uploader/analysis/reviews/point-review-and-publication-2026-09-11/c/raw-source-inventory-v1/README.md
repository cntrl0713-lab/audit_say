# 원자료 수집 대상 독립 인벤토리

이번 조사에서는 원본을 이동하거나 변경하지 않았다. [수집 입력](candidates.json)은 390개 원래 경로, 89,287,180바이트다. 같은 바이트를 묶으면 377개이며, 6개 중복 그룹의 모든 원래 경로를 [중복 장부](duplicates.json)에 남겼다. 원자료·사본의 역할과 카탈로그 연결·출처 URL 기록·원경로를 파일별로 구분했다.

| 구분 | 경로 수 | 포함 범위 |
| --- | ---: | --- |
| learning | 18 | 통합학습 본문·목차·설명 |
| reference | 39 | 별도 기준서36개와 control/Ethics/law 참고 Markdown |
| official | 40 | 현재 등록된 공식 전사·발췌 |
| verification | 281 | 학습QA4개, 원문PDF/HWP, 추출 텍스트, 페이지 이미지, 원문·해시·문단·등록 계보 JSON 등 |
| wiki-input | 12 | 출처 registry, 요소 추출3종, normalization, curation4종, coverage links, 기준대장, 주제19 출처 기록 |

현행 카탈로그 56파일·7,789단위의 모든 원문 파일과 현재 정본의 모든 `source_refs.file`이 이 목록에 있다. `references` 39개가 최초 통합 당시의 기준서36개와 같은 판본이라는 주장은 하지 않는다. 통합자료22개 전체가 학습 기반이며, 최초 교재 PDF8권은 사용자가 필요 없다고 명시하여 추가 추적을 끝냈다. 미보관 결함에 포함하지 않는다.

[최종 검증](validation.json)은 390파일의 현재 바이트·SHA-256 전수 일치, 카탈로그 누락0, 정본 직접출처 누락0, B의 합성 fixture 혼입0을 확인한다. URL은 95개 경로에서 머리말 또는 메타데이터에 존재하며, 그중17개는 파일과 URL이 JSON의 같은 기록에 직접 연결된다. 이 수치는 실제 다운로드·현행 판본 확인 수가 아니다. HTML의 메뉴 링크와 원자료 URL도 구별해야 한다. `provenance_records`는 경로·파일명에 대한 기계적 탐색 후보이며, 그 기록의 판정을 이번 수집이 승계한다는 뜻이 아니다.

원문 자료의 형태별로는 문서17경로, 웹응답19경로, 페이지이미지23경로, 전사·발췌195경로, 학습본문18경로, 원자료 품질검사4경로, 출처추출·계보JSON102경로, wiki입력12경로다. 문서 수는 같은 FSC 공고 PDF가 여러 옛 체크아웃에 남은 사본을 포함한다. 같은 해시만 물리적으로 공유하고, 서로 다른 버전·전사·페이지추출은 임의 합치지 않는다.

후속 최종 수집은 root의 [471경로 매니페스트](../../../../../raw/collections/2026-09-11-initial/manifest.json)에 있다. 이 폴더의 후보390은 변경하지 않았다. [독립 후속 대조](collection-followup.json)는 전체 원래 파일과 보존본의 바이트·해시, C390 전부 포함 여부, 후속 확보한 주제19 자료와 IRBA800을 확인한다. IRBA800은 현재 URL 확보본이며 과거 해시가 없어 과거 검토 당시와의 바이트 동일성을 주장하지 않는다.

`sources` 폴더만 모으면 빠지는 공식 stage, S03 루트 발췌, A의 추가 인용, 독립 PDF페이지 추출도 포함했다. 추가로 A가 실제 wiki 읽기에서 확인한 [74개 후속 입력](../../a/raw-crosscheck-v1/candidates.json)은 별도 합집합 입력이다. 편집정본·coverage 참조 초안·과거 상태JSON·curated 코드의 역할은 원문 출처가 아닌 wiki 시점 입력이다. 이 후보 목록에는 그 파일의 원문 역할을 잘못 부여하지 않았다.

[최종 미확보·계보 판단](gap-assessment-final.json)을 참고한다. 주제19의 과거 `interim.hwp`는 현재 `s06/sources/interim-2014.hwp`와 당시 SHA가 일치한다. 다른 네 원본은 이 후보 목록 작성 뒤 root가 공식 URL에서 재확보했으며 [독립 바이트 대조](recovery-byte-check.json)로 당시 SHA와 모두 일치함을 확인했다. root가 최종 수집에 추가한다. 따라서 주제19의 기록된 원본5개는 모두 연결된다. 과거 URL만 있던 국제 ISA800 보조근거는 별도 URL-only 기록이다. FSC84640은 후속 게시 HTML·2015 HWP와 연결하되 과거 전문 다운로드 실패와 같은 사건으로 섞지 않는다.

다운로드 manifest의 파일명만 있는 네 경로는 manifest가 위치한 폴더를 기준으로 해석해야 한다. 모두 실제 파일·해시가 일치한다. [기계적 미존재 후보](missing-recorded-files.json)는 옛 경로 그대로 찾은 중간 결과이며 최종 미보관 목록이 아니다. 법령 HTML wrapper는 `external-audit-law-view.html` 본문 및 추출텍스트와 분리한다. 저장된 HTML만 있다는 이유로 공식 전문을 확보했다고 판단하지 않았다.

[제외 목록](exclusions.json)은 코드 snapshot·모델 응답·채점 receipt·문항 묶음·게시 설명·앱 캡처·기출 채용 페이지·다른 프로젝트 자료를 원자료에서 구분한다. 합성 fixture와 실행용 Python 패키지는 제외한다. 기존 자료를 삭제하지 않았으며 보존 위치를 유지한다. 기존 카탈로그는 raw를 새로 재귀 수집하지 않아야 원자료를 이중 등록하지 않는다. 경로·단위 ID·과거 receipt는 유지하고 raw 보존본의 계보로 연결하는 정책이 적절하다.

이 폴더는 로컬 읽기·인벤토리만 수행했다. 문항·배점·DB·공통 코드·원자료 수정 및 모델 API 호출은 0회다. 실제 원자료 복사와 최종 raw 매니페스트 작성은 root가 맡는다.

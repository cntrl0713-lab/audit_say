# 직접 출처 보강 후보 v8

v7의 153세트·350물음·1292criterion·1292점을 유지한 새 후보이다. `pilot-03-001`에 KGA 210.6(b)(i)~(iii) 직접 인용을 한 source_ref로 추가하고, sub1/crit1~3의 source_ref_ids에 그 근거를 연결했다. 기존 발문·사실·모범답안·claim·배점·requirements·문항 ID·상태는 모두 그대로다. 추가 연결을 역적용하면 v7 전체 은행과 deepEqual이다.

공식 원문은 기존 등록 파일 `delegated-n01-kga200-210-230-2025.txt`의 L325–343이다. UTF-8 바이트·정확 부분문자열·인용 SHA·줄 위치를 확인했다. 해당 부분은 실제 카탈로그 `src-fdfd62f7d764e46a4c`의 문단 6 원문에 포함된다. 기존 A11/A14와 정보 제공 능력 전제를 보존하며, 정보 접근의 세 상세 경로를 새 정답이나 점수로 추가하지 않았다. 원자료 파일은 바꾸지 않았다.

`pilot-03-001-plan.json`은 R3의 기존 계획을 이어받아 직접 근거와 03-006/sub1의 부분 관계만 보완했다. 03-001/sub2는 두 일반 고려사항을 기술하고, 03-006/sub1은 갑·을의 사실을 해석하여 정당성과 이유를 판단한다. 일반 원리와 사례 적용 복습의 관계를 이번 조사에서 명시한다. 이전 후속 범위 설명에 들어 있던 v7 은행 참조는 당시 기록이며 새 은행의 승인 해시로 덧씌우지 않았다. 새 선택은 `plan-override.json`에 03 한 세트만 제시한다. 다른 계획은 총괄의 최신 manifest 선택을 유지해야 한다.

350개 분류 결정은 동일하다. 정식 `compileLearningCatalog`와 CLI `--check`를 통과했고, 기준서형 278물음·사례형 72물음, 주제 연결 449개, 학습단위 319개다. 모든 사례형 단위에 해당 부모의 사례형 물음 전체와 사실이 들어 있고 기준서형은 사실 없이 한 물음으로 독립한다. native 유형·주제와 sidecar가 일치하며 공개물에 모범답안·criterion·인용 원문이 노출되지 않는다. 안정된 물음/학습물음 ID는 유지한다. 출처 내용 해시 때문에 03의 두 파생 분류 판본 식별자만 새로 계산되며 이는 분류 결정 변경이 아니다.

`qa-grading-input-continuity.json`은 R3 작성자 QA22의 실제 원 파일·요청/스키마 해시를 새 후보와 연결한다. 전체세트의 실제 요청과 스키마는 22개 모두 정확히 같다. 03의 기준서형 학습단위 2개에 대해서도 각 답안의 선택 입력 전후 해시가 동일하다. 선택 투영을 별도로 모델 실행한 것은 아니다. 이 연속성은 고정된 runtime v6과 현재 채점 코드에 한하며, 이후 코드·답안·명제가 바뀌면 다시 판단해야 한다.

이 단계는 API·DB 호출 0이다. source_ref 추가가 reviewed content 및 전체 비교은행 해시를 바꾸므로 새 은행 epoch에서 선택 대상의 의미검수가 필요하다. `inspectBankSnapshot`의 `ready:false`와 미검수·미게시 119세트 오류를 보존했다. 이 상태 오류 외 구조·원문 인용·공개 compile 오류는 없다. 해당 함수의 `content_review_performed`는 로컬 입력 검사를 뜻하며 모델 의미검수 완료가 아니다. 정본·v7·R3 manifest·과거 receipt는 변경하지 않았다.

생성기와 변경 장부는 `prepare.mjs`, `changes.json`이다. `preparation-attempt-01.json`은 실제 QA schema 해시의 JSON 키 순서 계약을 바로잡은 초기 로컬 검사 실패이고, `preparation-attempt-02.json`은 후보 상태를 운영 import 준비 완료와 혼동한 초기 assertion 실패다. 두 시도 모두 후보 출력이나 API 호출 전에 종료됐으며 원 기록을 보존했다. 성공 결과와 산출물 해시는 `summary.json` 및 `handoff.json`에 있다.

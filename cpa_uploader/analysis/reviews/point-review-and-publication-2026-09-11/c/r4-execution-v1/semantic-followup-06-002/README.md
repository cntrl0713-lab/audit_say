# pilot-06-002 원 판정의 독립 대조

원 receipt의 `fail`과 네 비통과 단위를 그대로 보존했다. 이번에는 API를 호출하지 않았고 기존 은행·계획·출처·답안·criterion·배점·QA를 변경하지 않았다.

| 원 단위 | 원 판정 | 직접 대조 결과 |
| --- | --- | --- |
| sub1/crit2 | source_support uncertain | `src1`은 실제 L99–109에 정확히 포함된다. catalog의 L99–110은 다음 소제목까지 포함한 범위다. 14(b)의 분석적절차는 L102에 존재하며 끝줄 차이를 근거 누락으로 볼 수 없다. |
| sub2 | source_support fail | `src2` 인용은 실제 L115–122의 315.16–18 전체다. req2의 `315.16`은 관련성·신뢰성 평가의 직접 문단이다. 공유 인용 전체의 위치인지 직접 요구의 위치인지 표기의 역할을 혼동할 여지가 있으나 원문 내용은 빠지지 않았다. |
| sub2/crit4 | edition_scope uncertain | 원 계획은 2026-01-01 개시 보고기간과 2027년 후속 감사를 이미 명시했다. 315.10은 그 보고기간부터의 시행을 정하며, 보존 2025·2026 전문의 10·14·16–18은 문서화한 정규화 대조에서 동일하다. 최종 시험의 별도 판본 미지정과 이 적용 가정의 타당성은 구분해야 한다. |
| sub2/crit6 | source_support uncertain | req3의 `315.17–18`은 토의 및 불참 팀원에 관한 직접 담당 문단이다. req2와 공유하는 전체 인용 16–18과의 역할 구분이 필요하다. 실제 토의 의무는 L119–120에 존재한다. |

`source_span`을 전체 인용 범위로만 해석하면 req2·req3의 표기가 좁아 보인다. 이번 최소안은 각 값이 직접 담당 문단을 가리키고 `source_quote`가 공유 문맥 전체를 포함한다는 관계를 명료화한다. 이를 내용 미지지나 파일·인용의 실제 불일치로 과장하지 않는다. 인용을 잘라내거나 전체 끝줄을 맞추기 위해 다음 소제목을 덧붙이지 않았다.

[후속 계획](pilot-06-002-plan.json)은 `/metadata/source_location_and_edition_clarification` 하나만 추가한다. 직접 위치·공유 인용 범위, 같은 공식 전사의 315.10 인용과 기존 판본 가정의 근거를 담았다. 기존 계획 본문과 요구는 모두 동일하다. [필드 변경 및 역변경](changes.json)으로 원 계획과의 정확한 동일성을 확인했다. 이 후속안은 아직 활성화하지 않았다.

[상세 대조](investigation.json)는 다음 증거를 포함한다.

- 원 실제 11단위의 `input_hash`·`schema_hash`와 고정 입력 재구성값의 정확한 일치. 별도 HTTP body 직접 캡처로 표시하지 않는다.
- 공식 전사 L99–124와 실제 모델 입력의 `source_excerpts`, 원 인용 SHA, 카탈로그 단위 위치.
- 보존 2025 PDF 및 2026 PDF의 SHA가 기존 주제06 출처 기록과 같다는 확인. 직접 대조한 추출본 문단·줄·페이지·인용 SHA.
- 315.10·14·16–18의 양판본 본문 일치. 공백·PDF 페이지 표지·해당 페이지 머리말·페이지 분수만 구분했으며 원 인용·각주·파일 바이트는 보존.
- 후속 계획만 선택할 때 이 세트의 11개 의미검수 입력이 변경되고, 대상·필수 출처·응답 schema·문항·은행은 같다는 확인.
- 기존 QA 26개 학생 채점 prompt/schema의 전후 동일성. 실제 재채점은 미실행.

새 판본 정책이나 2027년 최종 시험 판본을 확정한 조사가 아니다. 후속 계획이 선택되면 새 경로·해시·실행 잠금에서 실제 의미검수를 수행해야 하며 원 receipt를 재해시하거나 수동으로 통과 처리하지 않는다. 물음당 1점 편차 허용도 이 출처·판본 검토를 대체하지 않는다.

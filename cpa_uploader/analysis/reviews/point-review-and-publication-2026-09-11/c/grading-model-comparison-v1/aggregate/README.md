# 과거 모델 비교 진단의 독립 통합 확인

Terra 진단 A35·B37·C22의 원시 94개 사례를 직접 확인했다. 비빈 답안 88개는 실제 모델 응답, 빈 답안 6개는 production 무호출 분기이며 모두 첫 관측에서 기대값과 일치했다. 반복·전송/형상 실패·보안 플래그는 0개다. 원시 criterion 732개와 빈 답안 포함 결과 criterion 780개를 정확히 대조했다. 조건 경계의 영점 판정 동률을 이용한 일치는 없다.

루트의 `terra-time`·`sol-time`은 각각 별도 1회 진단이다. 같은 시점 누락 원답안에 두 모델 모두 2점을 주었다. 이 2개를 전체 QA94에 더해 96개 고유 사례라고 부르지 않는다. 보존 관측 전체는 96개(비빈 90개·빈 6개)이며 루트 진단은 분리되어 있다.

입력 객체·원답안·기대값을 현 v8 은행의 세트와 v9 manifest의 QA/계획에 직접 대조했다. 119개 선택 문항·계획·출처 파일 해시와 QA 총 6,040개를 확인했고, runtime-v7 코드 16개도 일치한다. 각 관측의 prompt/schema를 현 코드로 재구성하고, 원시 근거 ID를 답안 인용으로 다시 복원하고, 판정을 순수 합산 함수에 넣은 결과까지 대조했다. 이 로컬 재생은 새 모델 관측이 아니다.

SDK `instructions`는 당시 실행 입력이 결속한 코드 해시와 production 전달 경로에서 재구성했다. 직접 HTTP 요청을 별도 캡처한 증거라고 표현하지 않는다. 요청 모델은 inputs·record·summary에 명시되어 있지만 공급자 응답의 세부 모델 버전은 현재 trace에 별도로 없다.

사용자는 **Luna 유지**를 확정했다. 이 자료는 과거 비교 증거이며 Terra 전환·후속 재사용을 권고하거나 활성화하지 않는다. 공통 기본 모델·전수 manifest·원문·QA·receipt·DB는 수정하지 않았고, 이번 통합 검증의 API 호출은 0회다. 정식 의미검수 통과·전수 품질·사람 승인·승급을 뜻하지 않는다.

검증기의 첫 비교는 원시 `reason:null`과 production 복원 객체의 속성 생략을 동일하게 취급하지 않아 실패했다. 실제 `groundJudgment` 계약대로 해당 정규화를 대조하여 해결했고, 원시 응답·판정·기대값은 변경하지 않았다. 이 로컬 검사 후속도 통합 JSON에 보존했다.

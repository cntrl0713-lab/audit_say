# v7 학습 투영 smoke-v4 인계

새 묶음 `learning-unit-smoke-v4/manifest.json`은 변경 기존 70세트와 신규 49세트의 280물음에서 249학습 단위(기준서형 209, 사례형 40)를 실제 앱 함수로 투영했다. 총점은 1113점이다. 사례형은 부모의 모든 사례형 물음을 한 번에, 기준서형은 사실 없이 독립 발문 한 물음으로 준비했다.

빈 답안 249개는 빈 API 키를 명시한 생산 채점 함수에서 모두 0점·정상 보안 처리를 확인했다. 비빈 저장 모범답안은 249개 모두 요청·schema·전체 criterion met 기대값만 준비했다. 실제 모델 호출은 0회이며 과거 실측을 새 결과로 승계하지 않았다.

18개 실행기 회귀가 모두 통과했다. 3개 worker 실제 CLI dry-run은 각 83개 작업과 모든 입력 해시를 검사했고, 기존 출력 보존 및 STOP 이전 키 미조회도 확인했다. 타입 검사와 세 파일 lint가 통과했다. quota·변동·기록 실패 경계는 합성 fixture이며 실제 모델의 검수·채점 정확도 증거가 아니다.

v3 대비 학생 입력과 grader prompt가 변한 것은 `pilot-03-001--sub1--standard` 한 건이다. 모범답안·criterion·배점·schema는 모두 불변이다. source body/분류 판본 hash는 120단위, 실제 투영 body는 119단위에서 달라졌으며 notes 경로 변경과 실제 발문 변경을 분리했다. `v6-v7-comparison.json`에 모든 249단위별 원·후속 artifact와 차이가 있다.

실행기는 a의 v3에서 고정 manifest hash, 버전 4, v7 catalog 경로만 바꿨으며 나머지 동작은 동일하다. 이전 v3의 모든 묶음 파일·실행기·검사 코드를 원래 해시로 보존했다. 새 실행을 하려면 총괄이 이 runner와 manifest 해시를 잠금에 묶고 새 출력 경로를 지정해야 한다. 아직 모델 실행 지시는 없으며 공통 코드·은행·원자료·옛 실행기는 수정하지 않았다.

해시와 실제 검사 출력 연결은 `learning-unit-smoke-v4-validation.json`을 따른다.

# B canary 후속 입력 v2

R3 실제 원답안 2개를 보존하여 QA35를 QA37로 확장했다. 기존 35개 사례의 모든 필드는 동일하다. 질문·모범답안·criterion·배점·출처·은행·공통 코드·과거 receipt는 수정하지 않았으며 이 준비의 API 호출은 0회다.

- 식별 시점만 있고 전달 적시성이 없는 원답: `crit1=met`, `crit2=not_met`, `crit3=met`, 총 2점. 세 번의 실제 3점 과다 인정 기록과 원 기대를 보존한다.
- 내역을 제시하지 않는다는 원답: `crit4=contradicted`, `crit5=met`, 나머지는 누락으로 총 1점. 원 생성 기대 `not_met`과 세 번의 `contradicted` 관측을 함께 보존한다.

후속 계획은 식별 시점과 전달 시점의 구분, 중립 누락과 명시적 반대의 차이를 두 개의 scope 설명으로 추가했다. 원 요구나 득점 범위를 확장하지 않는다. 새 metadata는 후속 검수 선택 상태이며 검수 완료나 사람 확인이 아니다.

[changes.json](changes.json)에 원답·원기대·3회 전체 기준 판정·원시 파일 해시·직접 원문을 연결했다. [checks.json](checks.json)에 계획 형상, QA37의 전체 criterion 및 정수 합계, 원35개 완전 동일성과 원문 검사를 기록했다. 새 runtime/입력 잠금 뒤 의미검수·실제 채점은 총괄 지시를 따른다.

# v7 실제 학습 단위의 smoke 준비

변경 기존 70세트와 신규 49세트에서 실제 앱 함수로 249학습 단위(209 기준서형, 40 사례형)를 투영했다. 사례형은 부모의 모든 사례형 물음을 함께 담으며 기준서형은 한 물음·부모 사실 없음·독립 발문을 확인했다.

빈 답안 249개는 명시적인 빈 키로 생산 채점기의 모델 미호출 경로를 실행해 0점과 정상 보안 처리를 확인했다. 비빈 저장 모범답안 249개는 요청과 완전 criterion 기대값만 준비했으며 모델 실행은 0회다.

이전 a/learning-unit-smoke-v3의 전체 파일은 원본 해시로 보존했다. v6-v7-comparison.json에 249단위별 실제 차이를 기록한다. 학생 입력 변경 1개, 채점 prompt 변경 1개, schema 변경 0개이며 답안·criterion·기대점수는 불변을 검사했다. 원 실측을 새로운 판정으로 승계하지 않았다.

전체 원세트의 formal QA와 비교하면 237단위에서 prompt, 237단위에서 schema가 다르다. 서명 토큰·DB·XP·UI 상호작용·실제 모델의 모범답안 만점은 이 준비로 검증한 것이 아니다. 원문·공통 코드·현재 실행 manifest는 수정하지 않았다.

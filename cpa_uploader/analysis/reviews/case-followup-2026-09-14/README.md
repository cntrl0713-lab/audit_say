# 사례형 후속 제작 검토

[확정 범위](authorization.md)는 신규 사례 6개·18물음과 검증 후 정본·공개본·운영 DB 반영이다. [제작 입력](../../../drafts/case-followup-2026-09-14/README.md)과 시작 정본 스냅샷을 보존한다.

내용 의미검수는 agent가 각 물음의 사실·발문·모범답안·criterion·배점·공식 출처를 직접 대조한다. 실제 채점은 Luna로 모범·대표 부분·오답을 시험하며 별도 API 의미검수나 사람의 직접 검토로 기록하지 않는다.

[실행 도구](runner-design.md)의 작성·정적 검사와 실제 채점, 게시, DB 배포는 구별한다. 각 단계가 완료되면 새 실행 증거와 결과를 이곳에 추가한다.

## 완료 결과

신규 6사례·18물음·44점을 정본·공개본·암호화본·학습 분류 및 운영 DB에 반영했다. 각 사례는 3물음, 사실관계 834~921자다. 기존 224세트의 본문·정답·배점을 보존했고, 전체 사례 55개 모두 사실관계 400자 이상·사례형 물음 2개 이상을 확인했다. [결과 보고](../../../../docs/reports/case-followup-2026-09-14.md)와 [문제·모범답안](../../../drafts/case-followup-2026-09-14/questions-and-answers.md)을 함께 확인한다.

- [최종 내용 검토](root-content-review.json): 18물음의 원문·발문·답안·배점·유형·주제·판본·기존 문제 차이를 직접 대조했다. 작성자 검토와 독립 교차검토를 연결하며 미해결 내용 결함은 없다. 사람의 직접 내용 검토나 별도 유료 API 의미검수로 기록하지 않았다.
- [실측 봉인](sealed-v1/summary.json): Luna로 18개 요청·54개 대표 답안을 실제 채점했다. 53개 정확 일치, 54개 모두 ±1점 이내다. [1점 과소인정 조사](within-tolerance-notes.json)는 원답안·기대값·관측을 보존하며 허용 편차를 없애기 위한 반복 호출은 하지 않았다. 반환 사용량 기반 비용 추정은 $0.03884045이고, 이번 금액 상한은 미지정이다.
- [정본 설치](publication-v1/install-completion.json): 격리 게시·공개본·학습 분류 검증을 거친 결과와 원본 백업을 보존한다. 과거 승급 장부를 유지했다.
- [운영 DB 검증](db-publication-v1/completion.json): 릴리스 `439d8f1d-bd84-4176-98de-76d9776b6aef`의 공개·비공개 문제와 분류를 독립 조회로 대조했다. 전체 230세트·492물음·409학습 단위를 확인했다.
- [관계 검토](coverage-root-review.json)와 [최종 확인](coverage-final-confirmation.json), [장부 반영](coverage-update.json): 신규 대표 연결 6건은 직접 3건·일부 2건·인접 1건이다. 원출제 빈도와 기존 관계를 보존했다.
- [최종 검사](final-checks-v1/summary.json): 분석 생성·검사, 과거 분석 보존, 위키 생성·검사 모두 통과했다. [로컬 정적 검사](local-static-checks.json)의 타입 검사와 배치 helper lint도 통과했다. 이 검사들을 내용 검토나 실제 채점의 대체물로 쓰지 않았다.

초기 비교본과 통합 직전 비교본, 초안, 출처 전사의 수정 전 버전, 실제 실행 잠금 및 원응답은 당시 바이트 그대로 남겼다. 검증 비율은 위 대표 답안에서의 관측이며 모든 학생 답안의 정확도를 보장하는 수치는 아니다.

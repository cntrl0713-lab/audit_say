# 사례형 후속 제작 범위

2026-09-14 사용자가 “기출문제와 고급회계감사연습을 참고해서 사례형 문제 더 만들어줘”라고 요청했고 제작량 질문에 **6개 사례·18개 물음**으로 확정했다. 각 사례에 3개 물음, 사실관계 400자 이상, 모든 물음의 사례 사실 적용이라는 기존 조건을 이어받는다.

기존 대화에서 승인한 **정본·공개본과 운영 DB까지 반영** 범위를 유지한다. agent의 전수 내용 검토와 실제 Luna 대표 답안 채점 후 검증된 결과를 게시한다. 이 승인을 사람이 모든 내용을 직접 검수했다는 기록으로 사용하지 않는다.

채점은 물음별 ±1점·대표 답안 95% 이상 실측 목표를 적용하며, 원문·정답·발문·배점의 내용 오류는 허용하지 않는다. 새 배치 금액 상한은 지정되지 않았고 provider 한도 오류에서는 중단한다. 이전 배치의 금액이나 성공 관측을 이번 배치에 가져오지 않는다.

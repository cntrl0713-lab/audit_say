# 미보관 과거 근거 파일

이 목록은 자료 이전 점검 당시 보고서의 Markdown 링크가 가리켰지만 실제 파일을 확보하지 못한 과거 근거를 기록한다. 총 **41개 경로(출처·대조 자료 10개, 실제 호출 원로그 31개)**가 18개 보고서에서 42회 참조되었다. 이 파일들은 [이전 장부](migration-manifest.json)의 371개 보존 파일에 포함되지 않는다. 이전 과정에서 있던 파일을 삭제하거나 복원한 결과가 아니다.

**현재 상태는 파일 미보관·원본 대조 불가다.** 과거 보고서나 요약의 실행 주장은 당시 기록으로 남기며, 이 목록만으로 원응답·공식 원문을 확인했거나 현재 검증이 통과했다고 해석하지 않는다. 새 원문 다운로드, 원로그 재작성, 실행 결과 재현은 수행하지 않았다. 다른 자료에 같은 내용이 있어도 아래 원본과 동일하다고 가정하지 않는다.

구 경로와 관리상 예상 경로는 찾기 위한 식별자이며 존재하는 파일 링크가 아니다. 원본을 나중에 확보하면 별도 후속 기록에 실제 확보 경로·시점·출처·검증 가능한 해시를 남기고 이 목록의 해당 항목을 연결한다.

## 적용 판본

목표 연도는 2027년으로 확정되었다. 금융위원회 출제범위 공고, 기준서별 시행일과 예외 및 원문 차이를 확인해 `edition-policy.md`에 근거를 남긴다. 연도 결정 자체가 아직 발표되지 않은 2027년 기준 개정사항까지 확인했다는 뜻은 아니다. 현재 확인 가능한 공식 근거로 설계하고, 향후 시행·시험 적용 미확정 항목은 명시한다.

## 단계

R01·R02·N01부터 최대 3개 작업을 병렬 실행한다. 먼저 원문 대조·제안본·작성자 QA·정적검사까지 준비하여 `draft_ready`로 인계한다. 총괄이 활성본을 선택하고 동료 문항을 포함한 비교 은행을 고정한 뒤 같은 담당자가 실제 모델 의미검수·채점·불일치 수정을 이어간다. `draft_ready`는 제작 완료가 아니다.

새로운 문항·source ID를 자의로 만들거나, 실패를 기대값 변경으로 감추거나, 과거 receipt의 해시를 치환하지 않는다. 채점 모델은 현재 환경 설정을 따르고 실행별 경로를 새로 사용한다. 실제 모델·설정·코드·입력·최종 버전의 해시 및 사례별 결과를 보존한다.

후속 작업의 설계 의존과 공통 코드는 총괄이 전달한다. 초기 기준선은 보존하고 후속 상태는 별도 장부에 기록한다.

## 현재 인수 기록

R01의 기존 6세트·12물음·37점과 R02의 기존 1세트·2물음·12점은 `draft_ready`로 중간 인수했다. 작성자 QA는 각각 143행·67행이다. R02의 과거 원시 응답 재처리 51회·612판정 일치와 새 도구의 빈 답안 1회 일치는 새 모델 실측에 포함하지 않는다. 후속본의 공식 출처·사례·criterion·기대값 변경 근거와 과거 원본은 각 담당 폴더의 인계 문서에 연결되어 있다.

N01을 마무리하는 동안 R02 담당자는 N02, R01 담당자는 N05로 이어서 배정했다. 동시에 실행 중인 담당자는 최대 3명이다. [첫 수집 스냅샷](first-handoffs/manifest.json)은 7개 후속본을 확인한 당시 기록이며, 아직 없는 42개 신규 파일을 누락으로 표시했다. 이 스냅샷을 최종 비교 은행이나 제작 완료 근거로 사용하지 않는다.

공통 실측 도구 [run-author-qa.ts](run-author-qa.ts)는 실제 `gradeQuestionSetV3`를 호출하여 사전 기대값과 판정·정수 점수를 대조하고 원시 응답·trace·입력/코드/출처 해시를 보존한다. 불일치는 같은 설정으로 총 3회 확인한다. [run-review.ts](run-review.ts)는 기존 의미검수 CLI를 현재 모델 설정으로 실행한다. 두 도구의 준비 상태와 전체 초안의 실제 검증 상태는 별개다.

[후속 선택 v3](active-selection-v3.json)는 c8을 검사기간 조정과 인식시점 증빙·기록기간의 대조로 명료화하고, 자료명 공동열거와 특정 일수 설명을 재진술하지 않아도 된다는 범위를 별도로 표시한다. 문항 수·배점·발문·출처 및 55개 원 QA 답안을 유지했으며 명시적 반대 범위에 따른 기대 정정 1개와 보충 6개를 구분했다.

새 비교 은행의 SHA-256은 `5be9693e35b10352f1d73825923d03afafe8e18ca71ddb6cad10191698510821`이다. [입력 준비 검사](final-153-v3-runtime-v5-preflight.json)는 49세트 오류 0, 최대 분할 입력 449477자다. v5 의미검수 지침과 v4 생산 채점 코드는 그대로 유지했다. 총괄이 31세트, 기초 주제 담당자가 기존 작성자 QA를 마친 뒤 자기 18세트를 각각 순차 검수한다. 담당자 수는 최대 3명이며 다른 두 담당자는 각자 남은 작성자 QA·불일치 조사를 이어간다. 겹치는 세트는 중복 실행하지 않는다.

## 공통 코드 확정 통보와 API 충전 후 재개

사용자가 전달한 `grader-hardening-2026-09-11-final-1`은 [대조 기록](hardening-final-1-confirmation-reconciliation.json)에서 실제 파일별로 확인했다. 그 확정본을 바탕으로 이 작업에서 이미 기록한 v4 채점·v5 의미검수 보완을 포함한 14개 파일을 유지한다. API 잔액 부족으로 중단한 과거 실행은 보존했고, 사용자 충전 후 실제 호출을 확인하여 새로운 실행 잠금·출력으로 이어갔다. 후속 controller는 중첩된 잔액·quota 오류를 일반 연결 오류 재시도보다 먼저 판별하여 전체 새 호출을 중단한다.

[활성 QA 후속 선택 v3](active-qa-overrides-v3-followup.json)은 T14-A의 대안 방법을 함축하지 않는 일반 책임 문장과 T07-A의 명시적 반대 범위에 관한 기대 정정을 담는다. 원 답안·원 기대·원 판정을 보존하고 후속 실측을 구별한다. 문항과 비교 은행 및 공통 코드는 그대로다.

의미검수 응답에서 단위별 필수 인용이 두 번 누락되면 그 단위는 수락하지 않는다. [후속 로컬 실행 도구](continue-semantic-partial.ts)는 이를 미해결로 보존하고 나머지 독립 단위까지 실제 검수한다. 하나라도 미해결이면 `partial-actual-model-evidence.json`만 기록하며 정식 receipt나 pass로 표시하지 않는다. 완전한 실제 receipt의 fail/uncertain, 형상 검증으로 미완성인 단위, 생성 사례 실제 채점, 작성자 QA는 각각 별도로 집계한다.

[작성자 QA 진행 집계](required-qa-index-after-refill-v3-progress-02.json)는 집계 시점에 필수 2389개 중 2084개가 실제 실행되었고 56개에서 불일치 관측이 있음을 기록한다. 이는 완료 선언이 아니다. 배점 검토는 49세트 전체 읽기와 주제 간 비교를 마쳤으며 주제19의 5→6점 등 후속안을 보고했다. 제안 배점을 현재 모델 실패에 소급 적용하지 않았다.

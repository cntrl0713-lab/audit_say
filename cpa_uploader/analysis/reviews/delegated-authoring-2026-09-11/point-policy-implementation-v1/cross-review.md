# 총괄 배점 교차검토

세 담당자의 49세트·131물음별 변경·유지 이유와 분리 대응을 읽고, 변경된 발문·정답·기준 및 관련 원문을 대조했다. 이 기록은 실제 모델 의미검수 receipt가 아니다. 최종 파일 선택과 해시는 수집 manifest 및 validation에 기록한다. API 호출은 하지 않았다.

- **T19-A**: 대상 반기재무제표와 재무보고체계는 지문 정보이므로 결론 문장의 길이에 비례해 점수를 만들지 않는다. 확신 수준, 소극적 결론, 서면진술 의무를 평가한다. 중요성 판단의 기초와 낮은 확신에 따른 미발견위험 차이는 구별할 설명이므로 분리하되, 완화 불가 판단을 표현만 바꿔 두 번 채점하지 않도록 보완했다.
- **T08-C / T13-A**: 경영진측·감사인측 전문가의 가정·방법·데이터 평가특성을 나란히 대조했다. 실제 발문이 각각 요구하는 관련성·합리성·완전성·정확성은 독립 배점한다. 전문분야 이해와 합의사항을 묻지 않은 T13-A에 이를 추가하지 않는다. T08-C는 수행업무 이해와 관련 분야, 발견사항 평가, 회사·외부 자료 검토를 요구하므로 요구량 자체가 큰 연습으로 유지한다.
- **T07-A / T08-B**: 전기 증거의 계속적인 관련성과 신뢰성, 확인 방법은 발문이 서로 구별하여 요구하므로 나눈다. 기초자료의 관련성·신뢰성 평가와 같은 수준으로 맞췄다.
- **T10-C**: 지문에서 이미 기대치를 계산한 상태이므로 도출 완료 사실의 재진술에는 새 점수를 만들지 않는다. 추가로 필요한 기대치의 정확성 평가가 독립 요구다. 정보의 성격·관련성은 원문에서 동일 정보의 적합성을 다루는 한 고려요소이므로 단어 개수대로 쪼개지 않는다.
- **T18-A**: 발문이 구별해 요구하는 대상 시점·기간과 금액 경계를 각각 평가한다. 사례 판단과 이유를 나누되 A/B의 숫자, D의 연결재무제표 작성 사실을 복사하는 것만으로 이유 점수를 주지 않는다. 그 사실이 기준상 충족 또는 제외를 뜻하는 연결이 필요하다.
- **T09-C**: 발동조건 내용 두 개와 OR 관계를 별도 요구로 평가한다. 조건 내용이 맞고 AND 관계가 틀린 답안의 조건 식별 점수는 보존한다. 기존 두 기준은 조건 식별로 좁히고 관계 점수와 중복하지 않도록 했다.
- **T12-B / T09-D**: 발문이 가능한 의견 종류를 모두 요구하므로 종류별로 배점한다. 실제로 여러 의견을 동시에 표명해야 한다거나 발문에서 제외한 중요성·전반성 설명까지 해야 한다는 요건을 추가하지 않는다.
- **T13-B / T13-C**: 조직 내 위상·정책이 객관성을 지원하는 정도는 하나의 평가요소다. 보고서가 다루는 시간범위와 테스트·결과의 주장 관련성도 각 하나의 평가대상이며, 문구 속 명사마다 별도 점수를 만들지 않는다.
- **T11-B / T17-B**: 최신 계획에서 정리한 기존 문항과의 적용 복습 관계를 보존한다. 새 세부 배점이 새 출제·커버리지 증가를 뜻하지 않는다.

각 물음의 최종 근거는 `per-question-point-audit.json`으로 수집한다. 작성자 QA는 원답안을 보존하고 바뀐 독립 명제를 다시 판정한다. 로컬 형상·원문 인용·기대 점수 합산 검사를 실제 모델의 정답 인정 동작 확인과 구분한다.

## 후속 QA의 독립 재대조 예시

- T08-C/sub2: 가정·방법의 관련성과 합리성을 올바르게 제시하고 자료 검토를 부정한 원답안은 네 명제의 4점을 인정한다. 회사·외부 자료의 다섯 특성을 제시하고 가정·방법 검토를 부정한 원답안은 5점을 인정한다. 옛 복합 기준의 0점을 모든 하위 기준에 복사하지 않았다.
- T10-C/sub2: 정보의 외부 원천을 고려하면서 나머지 신뢰성 검토를 면제한 답안에는 올바른 원천 고려의 1점만 남긴다.
- T12-D/sub2: 모든 관련 정보의 제공·접근 진술은 맞고 거래의 기록·반영 진술을 부정한 답안은 정보 의무에 대한 1점을 인정한다. 성실성에 관한 다른 물음의 이전 QA 정정도 계승했다.
- T19-A/sub3: 완화 불가 판단만 1점, 판단과 중요성의 기초만 2점, 독립적인 확신·미발견위험 구별까지 3점이다. 옳은 근거가 판단을 분명히 함축하는 답안은 결론 문구를 중복 작성하지 않아도 인정한다.
- T18-A/sub3: 주어진 숫자·연결 작성 사실만 복사한 답안은 0점이다. 올바른 판단에 틀린 이유를 붙인 답안은 판단 1점, 적용을 분명히 뜻하는 정확한 결정적 이유는 해당 사례 2점이다.

새 문항의 임시 형상 검사에서 공통 채점 안내를 여러 `critical_facts`에 복사한 중복을 발견했다. 이를 각 명제의 실제 요구와 조건으로 정리하도록 수정했고, 공통 검사 규칙을 완화하지 않았다. 새 QA의 동의표현 검사는 접두어만 추가한 원답 복사가 아니라 의미가 같은 다른 표현을 사용하도록 보완했다.

# 초안 물음별 학습유형·주제 매핑 검토

최신 49세트·132물음의 발문과 criterion을 전수 읽고 [이관 매핑](draft-classification.json)을 작성했다. 기존 학습유형인 기준서형 64·사례형 68을 유지했다. 51물음에 복수 주제를 지정했으며 전체 주제 연결은 188개다. 이 기록은 로컬 수동 분류이며 독립 검토 대기 상태다. 실제 모델 검수·채점, 사람 승인, 정본 편입 또는 DB 반영을 수행한 기록이 아니다.

## 입력과 적용 기준

- [최신 선택 manifest](../delegated-authoring-2026-09-11/final-153-style-v2/manifest.json)와 [학습유형 index](../delegated-authoring-2026-09-11/question-style-v2/index.json)의 실제 문항을 읽었다. 입력 파일·문항·주제 정의의 해시는 JSON에 기록했다.
- [주제 정의](../../../wiki/scripts/topic-definitions.mjs), [OX 학습 순서](../../../wiki/scripts/ox-study-order.mjs), 주제별 설계 지침을 기준으로 분류했다. 부모 주제를 일괄 복사하지 않았다.
- 별도로 채점되는 다른 주제의 학습내용이 있으면 연결하고, 지문에 등장하는 대상·근거 원문의 예시·단순 용어는 추가 주제의 사유로 쓰지 않았다. topic_ids 배열은 OX 순서이며 첫 주제가 주주제라는 계약은 없다.
- 전문 절차의 범위는 해당 전용 주제에 우선 대응시켰다. 모든 감사절차를 증거 08에, 모든 커뮤니케이션을 05에, 모든 의견 언급을 15에 자동으로 추가하지 않았다. 이유에는 실제로 추가한 요구의 내용을 적었다.
- 기준서형은 기존 독립 발문과 빈 사례 참조를 유지하고 사례 부모 없이 학습할 수 있게 매핑했다. 사례형은 원세트와 기존 사실 참조를 유지한다. 물음의 원문·답안·criterion·배점·QA를 변경하지 않았다.

## 중요한 물음별 경계

- T07-C/sub3는 부모 주제 07을 복제하지 않고 **08만** 연결했다. 채점하는 것은 기업생성정보의 정확성·완전성과 신뢰성 확인 생략의 적절성이다. [주제07 지침](../../../wiki/question-generation/topics/topic-07-design.md)도 정보 품질 자체의 기초 학습을 08과 대조하도록 구별한다.
- T08-C의 네 물음은 **08**이다. [주제08 지침](../../../wiki/question-generation/topics/topic-08-design.md)의 경영진측 전문가를 620의 감사인측 전문가와 섞지 않았다. 반면 T13-A/sub3는 감사인측 전문가의 고유 평가와 원천데이터의 독립된 증거 특성을 함께 평가하여 **08·13**으로 연결했다.
- T11-B/sub3는 특수관계자 계약의 사업상 이유를 통해 부정재무보고·자산유용 은폐 징후를 평가하는 실제 명제가 있어 **05·11**이다. 확인서·회의록 검사 목록인 같은 세트 sub2에는 외부조회 발송 규칙을 묻지 않으므로 09를 추가하지 않았다.
- T12-A/q2는 후속사건 절차·보고서 날짜와 형태·강조사항/기타사항문단을 따로 요구하여 **12·15·16**이다. 계속기업의 별도 중요불확실성 단락을 묻는 T12-B에는 그 단락을 강조사항문단으로 보아 16을 추가하지 않았다.
- T09-C/sub3의 부문정보는 **09**이다. 이는 501의 표시·공시 절차이며 600의 그룹·부문감사인 업무를 묻지 않아 14를 추가하지 않았다. T14-B와 T14-C의 부문중요성은 [그룹감사 지침](../../../wiki/question-generation/topics/topic-14-design.md)의 고유 범위로 분류했다.
- T13-C/sub1은 서비스조직 유형2 보고서에 더하여 이용자 통제의 설계·실행 이해와 운영효과성 테스트를 각각 요구하여 **06·07·13**이다. T17-B/sub1에는 재무제표 실증절차의 무왜곡 결과로 통제효과성을 입증할 수 없다는 실제 복습 명제가 있어 **07·17**을 연결했다.
- T17-A/sub1의 내부회계 의견은 **17**이다. 재무제표 의견과 다른 경영진 진술의 신뢰성을 따로 요구하는 sub2는 **12·15·17**이다. 1100의 내부회계 커뮤니케이션을 265의 재무제표감사 보고와 혼동하지 않는다.
- T19-A/sub2의 **12·19**는 서면진술 학습의 연결이며 적용 기준을 580으로 변경한다는 뜻이 아니다. 이 검토 문항의 직접 근거는 검토준칙이다. sub3는 중요성 판단기준과 검토의 확신 차이를 독립적으로 요구하여 **04·19**이다.

## 사례 사실 참조의 예외

pilot-11-005/sub3는 사례형이지만 기존 case_fact_ids가 비어 있다. 범위추정치 안에 경영진 금액이 포함된 사실만 확인했고 다른 검증은 수행하지 않았다는 사례가 발문 첫 두 문장에 있기 때문이다. 실제 부모 shared_context는 존재한다. 총괄은 부모 사실관계가 존재하고 발문에 사례 사실이 있는 경우 이 형상을 DB에서 허용하기로 확인했다.

없는 사실 ID를 만들거나 무관한 f1~f3를 강제로 연결하지 않았다. 향후 사실관계를 부모로 정리할 때 원문 요구와 명제를 보존할 필요가 있으며, 이번 분류에서 문구를 이동하지 않았다. 명백한 학습유형 오류로 판단하여 변경한 물음은 없다.

## 검증과 보존

- 분류 132행과 최신 선택의 132개 고유 물음 ID가 일치한다. 세트 49개 파일의 실제 SHA-256은 manifest·style index와 일치한다.
- 모든 주제 ID와 명시한 사례 fact ID가 존재하며 기준서형 64개는 독립 발문이 있다. 중복·누락·형상 오류는 0개다.
- 출처 원문이나 판본의 새 판단, 문항 수정, 모델 호출, DB 쓰기를 수행하지 않았다. 이번 변경 파일은 이 Markdown과 대응 JSON 두 개다.
- 분석·wiki의 공통 입력은 바꾸지 않아 전체 생성기를 재실행하지 않았다. 로컬 분류 검사는 정식 의미검수나 사람 확인을 대신하지 않는다.
- JSON SHA-256: 0c5386f1416ed14206a7724e20f8e00c38724b3ddf5fcf447845bcad3a14f498.

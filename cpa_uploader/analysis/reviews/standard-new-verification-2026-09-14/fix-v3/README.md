## 실제 채점

기존 관측 재사용 계약은 같은 은행 판본에서만 성립한다. 그래서 두 세트의 모든 물음(e01 sub1–4, s03 sub1·3·4, 7물음)을 Luna(gpt-5.6-luna)로 새로 채점했다. 답안과 기대값은 [standard-backlog-publication](../../standard-backlog-publication-2026-09-14/README.md) 수락 manifest의 모범·부분·오답 원답안을 그대로 썼다.

- 21건 모두 기대점수와 정확히 일치했고 strict도 21건이다.
- B1 부분답안은 수정 전 기대 3·실제 2에서 실제 3이 되었다. B2 부분답안은 기대 2·실제 1에서 실제 2가 되었다.
- 호출 21회, 입력 62,226토큰(캐시 0), 출력 6,554토큰(추론 1,315 포함). 요청·응답 ID는 [acceptance-completion.json](acceptance-completion.json)에 있다. 실행기의 고정 단가로 계산하면 약 $0.0234이며 청구서 금액이 아니다.
- 담당 agent의 재대조와 이 관측을 [batch.json](batch.json)으로 묶어 비용 통제 수락 검증을 통과했다. 사람의 직접 검수는 아니다.

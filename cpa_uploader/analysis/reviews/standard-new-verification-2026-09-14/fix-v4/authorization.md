## 관찰별 처리 결정

O1–O6 가운데 문항 결함은 O1–O3이다. O4·O5는 추적·연결이 남은 상태이며, O6은 중복이 없다는 확인이다. 관찰마다 실제로 고칠 대상을 아래와 같이 정했다.

| 관찰 | 처리 | 정본 영향 |
| --- | --- | --- |
| O1 부분 유지 세트 제목 | 재편 뒤 남은 물음에 맞게 7세트의 `title`을 바꾼다. 분류 태그의 원 제목은 재편 전후 물음을 묶는 계보 표시로 파생 std-points 세트와 공유하므로 유지한다 | 7세트·9물음 재채점 |
| O2 명칭 열거 물음의 `type` | 경영진주장 명칭 여섯 개만 요구하는 2물음의 답안 형식을 `descriptive`→`enumeration`으로 바꾼다. 퀴즈 화면의 "서술형" 표시가 "열거형"으로 바뀐다 | 2세트·2물음 재채점 |
| O3 세분 배점 | [공통 배점 계약](../../../../../docs/물음별-학습-단위와-분류-계약.md#배점과-물음별-타당성)의 "조사·수식어·주체·조건을 단어마다 나누어 1점씩 주지 않는다"에 따라, 원문의 한 열거 항목을 동사·대상별로 나눈 두 물음을 원문 항목 단위로 합친다. `4906e3107ecd/sub1`은 315.21(a)(iv)의 유치·육성·유지 3점을 1점 항목으로 합쳐 4점→2점, `1cae16e579d0/sub1`은 580.4의 "다른 감사증거의 성격이나 범위에 영향 없음" 2점을 1점으로 합쳐 4점→3점이 된다 | 2세트·2물음 재채점, 총점 −3 |
| O4 윤리기준 판본 감시 | 현재 판본(2024-12-19 의결 전문) 기준으로는 정확하므로 문항 내용은 바꾸지 않는다. 확정되지 않은 2026-09 공개초안을 반영하면 오히려 오류가 된다. 감시 대상 8물음과 재대조 조건을 수동 지침([주제01 지침](../../../../wiki/question-generation/topics/topic-01-design.md))에 기록해 날짜별 보고서를 읽지 않아도 알 수 있게 한다 | 없음 |
| O5 coverage 미연결 49물음 | 미연결은 미출제 확정이 아니다. 49물음마다 `question-elements`의 기출·연습 요소를 찾아 실제 발문과 대조하고, 대응 관계가 성립하는 것만 reviewed 관계로 추가한다. 후보·기각 이유를 함께 남긴다 | 없음(links.json) |
| O6 인접 사례형 물음 | 사례형은 사실 적용을, 기준서형은 원문 요구를 묻는 인접 관계로 중복이 아니다. 고칠 문항 결함이 없어 데이터를 바꾸지 않는다. O5 관계 탐색 중 같은 요소에 사례형이 걸리면 기록만 한다 | 없음 |

O3는 사용자가 승인한 2026-09-14 배점 재편의 일부를 되돌리는 조정이다. 재편 당시 메모("독립 인력관리 행위", "성격과 범위를 각각 평가")는 당시 판단 기록으로 남기고, 새 메모로 이번 조정과 이유를 덧붙인다.

## 비용과 실측

- 채점 모델은 Luna(`gpt-5.6-luna`)를 유지한다. 허용 오차 ±1점, 목표 95%.
- 기존 관측 재사용은 같은 은행 판본에서만 성립하므로, 바뀐 11세트의 모든 물음(13물음)을 모범·부분·오답 1건씩 새로 채점한다(39건 예정).
- O1·O2 물음은 기존 수락 대표답안과 기대값을 그대로 쓴다. O3 물음은 합친 기준으로 기대값을 다시 판정한다. `1cae16e579d0/sub1`의 부분답안은 합친 기준을 시험하는 새 답안으로 바꾼다. 기존 부분답안은 바뀌지 않은 두 기준만 다룬다.
- 금액 상한은 사용자가 지정하지 않았다. 허용 범위 밖 결과에만 원인 조사와 표적 재검사를 한다.
- 사람의 직접 검수는 하지 않는다. 담당 agent 검토와 실제 모델 채점을 구분해 기록한다.

# 기준서형에 추가할 독립 물음 검토 — 2026-09-13

현재 정본에는 기준서형으로 추가할 여지가 있다. **10개 영역·14개 독립 물음 후보**를 선정했다. 우선순위가 가장 높은 것은 **양방향 커뮤니케이션의 효익, 전수조사가 적합한 상황, 계속기업 의문 식별 후 아직 묻지 않은 추가절차**다. 세 요구는 교재의 기출 원물음에서 각각 2회 확인되며, 현재 은행의 가까운 물음과 실제 요구가 다르다.

이는 후보 탐색 결과다. 14개는 아래 범위로 나눌 때의 제안 수이며 확정 제작량이나 완성 문항 수가 아니다. 새 발문·모범답안·criterion·배점은 제작하지 않았다.

## 확인 범위

- [현행 정본](../../../data/cpa_question_sets_v3.authoring.json): 154세트·351물음. [현행 분류](../../../data/learning-question-classifications.json): 기준서형 279물음·사례형 72물음. 모든 정본 물음 키와 분류 키의 일대일 대응을 확인했다. 운영 DB를 조회한 수치는 아니다.
- 전체 물음의 발문 목록을 읽고, 선정 후보에 인접한 물음은 모범답안과 criterion까지 직접 대조했다. 모든 기존 정답·출처·배점에 대한 전수 의미검수는 아니다. 후보는 특정 회사의 사실을 해석하지 않고 일반 적용 조건과 기준서 내용만으로 답하도록 한정했다.
- `data/`와 `drafts/`의 JSON 7,734개를 읽어 실제 문항 형상을 찾았다. 정본에 없는 9개 세트 ID는 현재 `pilot-05-007·008`, `pilot-09-008`, `pilot-13-006·007·008`, `pilot-15-005`, `pilot-16-008·009`에 대응하는 옛 초안이었다. 별도 미완성 9세트로 계산하지 않았다. 같은 ID의 보존 수정판도 별도 새 세트로 세지 않았다.
- [통합 현황](../../../wiki/_meta/authoring-dashboard.md)과 coverage의 은행 해시가 현행 정본과 일치함을 확인했다. 다만 관계 확인 완료 0건·검토 대기 167건인 현황이므로 미연결 수를 내용 공백 수로 사용하지 않았다.
- 아래에서 사용한 원문·전사 파일은 [raw 수집 기록](../../../raw/collections/2026-09-11-initial/manifest.json)의 보존본과 실제 SHA-256이 일치한다. 문단 위치·원물음·인접 물음의 답안과 criterion은 [근거 장부](evidence.json)에 보존했다.
- 한국공인회계사회의 [회계감사기준 게시판](https://kicpa.or.kr/board/list.brd?boardId=acc0102)을 추가 검색했다. 후보 내용의 직접 근거는 아래 보관 원문이며, 이 검색을 새 시험 적용연도·판본 확정으로 취급하지 않았다.

## 새로 늘리지 않아도 되는 내용과 보류 후보

이미 들어 있는 **후속사건 한정절차·이중일자**, **계속기업 불확실성의 공시별 보고**, **공란형 조회**, **표본규모의 기존 네 변화**, **기업생성정보 검증**, **감사인측 전문가 평가**, **미공개 특수관계자 대응**은 과거 공백 목록에 있더라도 새 공백으로 세지 않았다. 각각 현재 `draft-12-560-freq01`, `draft-12-570-freq01`, `draft-09-505-freq01`, `draft-10-530-freq01`, `pilot-08-003·006`, `pilot-13-009`, `pilot-11-003` 등에 있다. ID가 `draft-`로 시작해도 현행 정본 수록 여부로 판단했다.

`pilot-07-002/sub1`과 `07-004/sub1`의 통제테스트 수행 조건, `pilot-09-003/sub1`과 `09-004/sub1`의 조회 발송 거부 대응, `pilot-16-002/sub2`와 `16-006/sub2`의 개별 KAM 기술은 이미 반복된다. 같은 요구를 새 회사명이나 다른 표현으로 한 번 더 만드는 것은 추가 우선순위가 낮다. 기존 중복을 삭제하거나 합치는 작업은 하지 않았다.

**업무수행이사·업무보조자 의무교체 규정**, **이해상충 자문업무의 안전장치**도 추가 검토 대상이다. 전자는 법규·윤리 규정의 기업 구분과 기간, 후자는 윤리 규정의 해당 판본·범위 확인이 더 필요하다. 기준서형이라는 학습 유형에는 넣을 수 있지만 이번의 기준서 근거 14물음과 구분하여 보류했다. 교재 빈도는 각각 2014·2023 및 2018·2019에 확인되나, 현행 규정의 구체 기간·의무를 이번에 확정하지 않았다. PPS 금액 계산 후보는 현재의 계산 문제 제외 지침에 따라 선정하지 않았다.

## 결과와 변경 범위

새로 만든 파일은 이 보고서와 [근거 장부](evidence.json)뿐이다. 정본·공개본·분류·coverage·wiki·DB·채점 코드는 수정하지 않았다. 실제 모델/API 호출에 의한 의미검수와 채점은 0회이며, 신규 문항 검증이나 게시 완료를 의미하지 않는다.

정본·분류의 물음 키 대응, 현황표의 은행 해시, 사용 원자료와 raw 보존본의 바이트 일치, 보고서 링크를 확인했다. 읽기·보고 작업이므로 앱 빌드나 전체 테스트는 실행하지 않았다.

- 2027년 CPA 시험 대비. 기본 사례는 2026년 1월 1일 개시·12월 31일 종료 보고기간의 재무제표를 2027년에 감사한다. 2025 공식 전문을 선택하고 2026 공식 전문의 해당 본문 및 적용자료를 직접 대조했다. 540.10/550.8/620.4는 2026년 1월 1일 이후 개시 보고기간 시행을 명시한다. 2027 금융위원회 시험범위 공고는 특정 기준서 판본을 지정한 공고와 구별한다. 총괄 edition-policy.md의 사례설계 정책을 적용하며 시험당국이 모든 판본을 확정했다는 의미로 사용하지 않는다.
- 620.8(e)와 A10~A15는 2026 전문에서 품질관리정책·절차를 품질관리시스템으로 바꾸고 관련 설명도 개정했다. 공고 4항의 단계적 시행표와5항의 관련기준서 개정, 개정개요37~46/75 및 변경표29~33을 종합한 총괄의 사례설계 해석에 따라, 이 사례는 2026년 개시 보고기간이며 개정 품질관리체계를 선제 적용하지 않는 종전 정책·절차 체계로 한정한다. 확보한 공고에620 전체 정합수정의 별도 일괄 시행일 문구까지 있는 것은 아니며 이를 별도 공식 시행일 확정으로 표현하지 않는다. 적용대상 여부를 고려한다는 핵심 명제는 양판본 모두 같다. 시스템이라는 동의 표현을 허용하며 외부전문가의 언제나 미적용이라는 판본 의존 일반명제는 배점하지 않는다.
- 총괄 ID 장부에 따른 수동 제작. source_refs와 requirement 인용은 등록 공식 파일의 exact 부분문자열이며 사례·발문·답안은 재구성했다.
- 1차 정적 초안 준비. 실제 의미검수와 모델 채점은 전체49 비교은행 고정 후 수행한다.
- 수동 evidence-packet은 생성기 source packet이 아니다. 생성 당시 해시 표시를 만들거나 자동 의존패킷 완결성을 사칭하지 않는다.
- 2026-09-11 승인된 독립 내용별 1점 정책의 후속본. API 0회, 과거 의미검수·실측은 이 배점계약의 검증 완료로 승계하지 않는다.
- 2026-09-11 사용자 확정: 사례 사실과의 연계가 필요한 물음은 사례형, 기준서만으로 답할 수 있는 물음은 기준서형. 기준서형은 사례 지문 없이 독립 발문으로 구성한다. 학습 묶음은 유형별로 분리한다. 정답·criterion·출처·ID·배점은 유지하며 모델 검증 완료로 승계하지 않는다.

2027 시험 적용 여부는 아래 판본 기록과 공식 시험 공고 확인 상태를 따른다. 게시 상태 또는 이 색인의 생성 상태로 대신 확정하지 않는다.

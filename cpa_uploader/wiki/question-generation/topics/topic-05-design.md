# 주제05. 부정·법규·커뮤니케이션 문항의 조건과 예외

[검토 보고서](../../../../docs/archive/과거-검토-증거/reports/question-review-2027/주제-05-부정과-커뮤니케이션-검토-수정-기록.md) · [물음별 근거 장부](../../../analysis/reviews/question-review-2027/05.json)

주제05를 제작·수정할 때의 주의사항이다. [주제05 검토 보고서](../../../../docs/archive/과거-검토-증거/reports/question-review-2027/주제-05-부정과-커뮤니케이션-검토-수정-기록.md)와 [기준대장](../../../analysis/reviews/question-review-2027/standards-register.json)의 공식 URL·판본·문단을 확인한다. 아래 내용을 발문이 요구하지 않은 추가 득점 요건으로 넣지 않는다.

| 구분 | 보존할 내용 | 근거 |
| --- | --- | --- |
| 부정 의심의 보고 | 경영진 연루 부정의 의심과 확정을 구별한다. 전원 경영참여 예외·법규상 금지 조건을 보존하고, 지배기구에 적시 전달할 사항과 감사절차의 성격·시기·범위 논의를 구별한다. 법적 조언의 고려 가능성을 모든 경우의 의무로 바꾸지 않는다. | 240.42, 260.7 |
| 통제무력화 대응 | 위험 평가결과와 관계없는 절차 수행, 기간 전체 테스트의 필요성 고려, 개별적으로 합리적인 판단에서도 편의와 부정위험의 관련성 평가, 전기 유의적 추정치의 판단·가정 소급검토를 보존한다. | 240.33(a)–(b) |
| 수익인식 위험 추정 | 추정 배제 근거가 없는 상황의 판단과 예외를 구별한다. 해당 업무에 가정을 적용할 수 없다고 결론 내리면 그 **이유**를 문서화한다. 예외가 보충 설명이면 발문에 없는 별도 점수로 만들지 않는다. | 240.27,48,A31 |
| 비경상 거래 | 정상 사업과정 밖 거래 **또는** 기업·환경의 이해와 감사 중 입수정보상 비경상적으로 보이는 유의적 거래의 조건을 보존한다. 사업상 논리적 근거 또는 결여에 비춘 부정한 재무보고 수행·자산횡령 은폐 목적의 징후 평가를 형식적 적법성 확인으로 대체하지 않는다. | 240.33(c) |
| 유의적 내부통제 미비점 | 265.9의 지배기구·적시·서면과10(a)의 조건부 경영진 보고를 구별한다. 구두 선보고는 서면 의무를 대체하지 않으며 적시성을 모든 기업의 동일한 보고일로 고정하지 않는다. 내역·잠재적 영향·세 가지 관점 설명을 최상위 다섯 항목으로 오인하지 않는다. 잠재적 영향 계량화·시정 권고는 필수 사항이 아니다. | 265.9–11,A13–A14,A28 |
| 법규위반과 외부 보고 | 의심되는 사례도 포함한다. 성격과 발생 상황의 이해는 하나의 상위 절차에 속한 독립 명제일 수 있다. 외부 보고 의무 여부와 법규·윤리상 확립된 책임에 따른 상황 적합성 판단을 무조건 보고로 바꾸지 않는다. | 250.19,29 |

통제 식별·설계 평가·실행 여부 확인(240.28)을 운영효과성 테스트로 대체하지 않는다. 주제17의 통합감사 보고 요건도265의 재무제표감사 보고에 그대로 적용하지 않는다. 기준서 일부 문단만 묻는 학습목표라면 발문에서 범위를 명확히 하되, 기존에 요구한 사항을 채점에서 빠뜨린 결함을 숨기기 위해 범위를 축소하지 않는다.

2026-09-08 확인한 공식2025·2026 전문의250.10에는 시행일이 `202X년 12월 15일 이후 종료`로 남아 있다. 또한240.27의 문서화 교차참조47과 직접 요구사항48이 맞지 않는다. 원문 인용을 임의로 고치지 말고 직접 문단·미확정 사유를 기록한다. 이 메모는 해당 판본의 확인 기록이며 후속 정정이나 다른 연도까지 적용할 영구 규칙이 아니다. 2027년 동일 적용 가정과 최종 시험 판본 확정을 구별한다.

## 사용 범위

현재 정본의 발문·사실·정답·criterion과 공식 출처는 [[source-review-map]] 및 각 세트 색인에서 함께 확인한다. 이 지침의 검토 상태는 신규 초안의 검수 완료나 2027 시험 적용 확정을 뜻하지 않는다. 공통 정책과 충돌하면 [[question-design]] 및 현재 검증 계약을 먼저 적용한다.

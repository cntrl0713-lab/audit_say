# 연계형 문제 설계와 최소 문제 유형

## 기본 단위

제작 파일의 `linked_question_set`과 학습자가 푸는 단위를 구분한다. 새 출력은 같은 학습 유형의 1~4개 물음으로 작성하고 답안과 채점은 `subquestion`별로 분리한다. 공통 계약과 실제 DB·제출 코드의 연결은 [물음별 학습 단위](../../../docs/물음별-학습-단위와-분류-계약.md)를 따른다.

```text
case: 부모 사실 → 사례형 물음 1~4개 → 물음별 answer·criteria
standard: 사실 없음 → 독립 물음 하나 → answer·criteria
```

기준서형을 여러 개 제작했어도 학습 화면·제출은 한 물음씩 구성한다. 사례형의 공통 지문 아래에는 사례형만 둔다. API는 확정한 학습 단위의 선택 물음과 답안을 결속하며 다른 물음의 답안·점수·복습 기록이 섞이지 않게 한다. 원문 세트·물음 ID는 자료 계보로 보존한다.

## 허용 문제 유형

### 1. descriptive

단답, 정의, 목적, 이유, 비교, 절차, 보고사항을 모두 포함한다. 전문용어의 의미와 조건은 `claim`·`critical_facts`로 보존한다. 현재 v3에 없는 `match_mode` 필드를 추가하지 않는다.

### 2. enumeration

발문이 한정한 범위의 항목을 모두 요구한다. 일부 선택을 요구한 원문은 범위와 개정 이유를 기록하고 모두 작성하도록 고친다. `selection={type:'all',n:null}`, `constraints={ordered:false,max_entries:null,overflow_policy:'none'}`을 사용한다. 상위 항목 수와 하위 채점 명제 수를 혼동하지 않는다. 문장·번호·줄바꿈 개수로 정답을 자르지 않는다.

### 3. judgment

O/X, 예/아니오, 가능/불가능, 적절/부적절, 감사의견 등을 묻는다. 근거도 채점하면 발문에 명시한다. 판단과 근거의 분리/결합 배점은 criterion 계약에 적는다. 요구 조치에서 결론이 분명하면 판단을 인정하되 명시적 반대 결론은 인정하지 않는다.

비교형·표형·시기별·조건별은 별도 채점 유형이 아니다. 사례형·기준서형도 위 세 가지 `type`과 별개의 학습 유형이다. 사례형의 서로 다른 시점·상황은 부모 사실과 물음에서 구분한다.

## 학습 분류: 기준서형과 사례형

모든 물음은 사실관계와 연계해야 답할 수 있으면 `case`, 기준서 내용만으로 답할 수 있으면 `standard`다. 발문·부모 사실·criterion을 직접 읽고 각 물음의 `question_style`과 하나 이상의 `topic_ids`를 정한다. 부모 주제를 자동 복제하지 않으며 다주제를 허용한다.

주제는 검색 필터로 사용한다. 검색된 사례형 학습 단위는 다른 주제의 물음까지 소속 물음 전체를 보여 주며 주제 검색에 맞춰 풀이 범위를 자르지 않는다.

설계할 때 사례형에 필요한 부모 사실을 남기고 기준서형의 공통사실은 비운다. 기준서형의 발문은 다른 물음이나 특정 회사·자료·보고서 초안 없이 정답을 낼 수 있어야 한다. 특정 사례를 발문으로 옮겨 독립 발문처럼 보이게 만들지 않는다. 세부 판정 기준·DB의 `case_set_id`/`standalone_prompt`·과거 판본 이관은 [공통 계약](../../../docs/물음별-학습-단위와-분류-계약.md)을 따른다.

분류 이유와 원문 해시는 해당 검토·제작 장부에 보존한다. [기존 제작 배치의 후속 분류](../../analysis/reviews/delegated-authoring-2026-09-11/question-style-v2/README.md)는 그 배치의 증거이며 모든 새 문항의 분류 정본으로 사용하지 않는다. 분류 완료를 의미검수·실제 채점·사람 승인으로 표시하지 않는다.

## 분할 규칙

- 독립적으로 답할 수 있는 원문의 번호별 물음은 별도 subquestion으로 만든다.
- 새 출력은 같은 학습 유형의 1~4개 물음으로 구성한다. 한 물음에 서로 독립된 업무 이해·결론 평가와 가정·방법·자료 검토를 과도하게 묶지 않는다. 분할 시 기존 criterion과 총점을 보존하고 새 물음 ID 및 표시 순서를 별도로 기록한다. 기준서형은 학습 시 각 물음으로 다시 분리한다.
- 판단+이유, 결론+근거, 비교 자체, 같은 범위의 열거, 조건부 순차 절차는 의미를 보존해 묶는다. 나열 순서는 강제하지 않되 절차의 선후관계는 criterion에서 평가한다.
- `이 경우`처럼 문맥 의존적인 표현은 실제 사실 의존성을 확인한다. 사례형의 필요한 사실은 부모 지문에 보존하고 기준서형의 일반 조건은 독립 발문에 명시한다.
- 원문에 주어진 사실의 단순 반복에는 점수를 주지 않는다.

## 정수 배점

- 기본 원자 요소: 1점, `met=1`, `not_met=0`. 원자 요소 하나에 소수 부분점수를 두지 않고, 물음의 부분정답은 충족한 요소의 정수 점수를 합산한다.
- 일부 criterion만 충족하면 그 정수 점수는 유지한다. 모두 작성은 물음 전체의 전부 정답/전부 0점 방식이 아니다.
- 열거형은 발문이 요구한 독립 요소마다 기본 1점을 부여한다. 명칭을 요구하면 명칭만으로 충족할 수 있고 같은 요소의 동의어·반복은 한 번만 채점한다.
- 서술형도 발문이 실제로 요구한 독립 내용·행위·관계·근거를 나누어 각각 배점한다. 핵심 내용·적용 방법·이유를 모든 서술형의 필수 세 항목으로 일괄 추가하지 않는다. 단어·접속사·문장 수, 주어진 조건의 반복이나 해설 분량으로 요소 수를 정하지 않는다.
- 판단과 독립된 근거를 함께 요구하면 각각 채점한다. 요구 조치·이유가 판단을 명확히 함축하면 정해진 결론 문구를 반복하지 않아도 판단을 인정한다. 같은 의무의 긍정·부정 표현은 별개 명제로 중복 배점하지 않는다.
- 필수 조건·주체·시점·부정은 해당 명제에 보존한다. 한 부분의 오류는 그 부분에 적용하고 다른 정확한 독립 명제의 점수는 유지한다. 관련 단어만 있고 필요한 행위·관계가 없는 답을 부분정답으로 간주하지 않는다.
- 별도 가중치가 필요한 경우 정수 배점과 부분 충족 계약을 명시한다. 1점 criterion에 소수 partial을 넣지 않는다.
- 총점은 저장하지 않고 득점 가능한 요소의 합으로 계산한다.
- 파일럿 당시의 세트 8점 제한은 적용하지 않는다. 발문이 요구하는 독립 명제를 복원했을 때 점수를 잘라내거나 서로 다른 요구를 억지로 묶어 상한에 맞추지 않는다. 요구사항의 추가·분리는 근거와 배점 변화를 검토 장부에 기록한다.
- 같은 문장이 독립 명제들을 충족하면 동일 인용을 허용한다. 동일 사실을 여러 criterion에 중복 배점하지 않는다.
- 배점 변경 시 모든 물음의 요구와 기존 기준을 대조하여 분리·유지 이유와 criterion ID의 전후 대응을 기록한다. 이전 답안과 실측 증거를 보존하고 바뀐 명제의 기대값을 답안 전체에서 다시 정한다. 옛 복합 기준의 미충족을 새 하위 요소 전부의 미충족으로 자동 전파하지 않는다.

## 생성 금지

- 실제 산술을 요구하는 계산 문제
- 출처에 없는 기준서 문단·기간·수치
- 해설에만 있고 발문이 묻지 않은 지식을 득점요소로 추가한 문제
- 작은 사실 변경으로 결론이 달라질 수 있는 무검수 사례 변형
- 정의·관계·조건을 묻는데 무관한 키워드만으로 통과시키는 기준. 명칭 자체를 요구한 경우에는 명칭만으로 해당 점수를 인정한다.

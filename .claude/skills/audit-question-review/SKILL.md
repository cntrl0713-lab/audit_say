# 회계감사 문제·물음 검증과 수정

작업을 시작하기 전에 [공통 검토 스킬](../../../.agents/skills/audit-question-review/SKILL.md)을 읽고 따른다. 실제 채점·채점 계약 검토에는 공통 본문 옆의 `references/regression-cases.md`도 읽는다. 이 파일은 Claude Code의 진입점이다.

공통 본문에 있는 프로젝트 경로는 현재 작업 중인 저장소 루트에서, 본문의 상대 Markdown 링크는 그 공통 본문 파일에서 해석한다. 사용자의 이번 요청과 앞서 확정한 범위를 함께 적용한다. 지침 갱신은 공통 본문에서 수행한다.

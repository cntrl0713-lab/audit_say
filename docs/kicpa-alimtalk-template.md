# 수습·신입 CPA 채용공고 알림톡 심사 준비안

작성일: 2026-09-09. 수정일: 2026-09-10. 상태: 내부 검토용 초안. 업체 선정, 사업자·비즈니스 채널 등록, 템플릿 신청과 실제 발송은 보류한다. 이 문서는 신청용 문구와 제품 화면 요건을 준비하며, 승인 또는 운영 가능 여부를 확정하지 않는다.

## 1. 신청할 메시지의 범위

Audit Say 회원이 `/settings`에서 직접 선택한 채용공고 조건에 새 게시물이 들어오면, 해당 공고 한 건을 안내하는 정보성 템플릿을 검토한다. 현재 선택 가능한 조건은 다음 두 가지다.

| 저장값 | 신청 화면에 표시할 조건 | 발송 대상 공고 |
| --- | --- | --- |
| `trainee_cpa` | 수습CPA 게시판의 전체 공고 | KICPA 수습CPA 게시판에서 새로 확인된 공고 |
| `cpa` | CPA 게시판의 수습·신입 공고 | KICPA CPA 게시판에서 제목에 `수습` 또는 `신입`이 포함된 새 공고 |

한 가지 이상 직접 선택하며, 지역·법인·세부 직무를 선택한 것처럼 표현하지 않는다. 법인 상세의 채용공고 탭을 방문했다는 사실만으로 해당 법인의 알림을 신청한 것으로 처리하지 않는다.

공고 정보는 **제목·회사명·게시일과 원문 확인 버튼**으로 제한한다. 버튼에는 검증된 `source_url`을 사용한다. 마감일·공고 본문·연락처·이메일·첨부파일은 수집하거나 메시지에 넣지 않는다. 지원 방법과 마감 여부는 수신자가 원문에서 확인한다.

카카오의 [알림톡 발송 예시 §3 ‘직업/견적 추천’](https://kakaobusiness.gitbook.io/main/ad/infotalk/send-example)은 사용자가 요청한 구직조건에 맞는 공고 안내를 심사 가능 사례로 제시한다. 조건에 맞는 여러 공고를 반복 안내할 때는 복수 메시지가 발송된다는 동의 또는 고지가 필요하다. 동일 표에서 무료 뉴스레터 등의 일반 구독 안내는 불가 사례로 구분한다. 따라서 이 서비스의 게시판 조건 선택이 해당 직업추천 사례에 부합하는지는 신청 화면과 실제 문구를 함께 제시하여 사전 확인한다. 무료 서비스라는 이유만으로 정보성 또는 광고성이라고 단정하거나 승인을 보장하지 않는다.

## 2. 템플릿 본문 초안

아래 `{{...}}`는 문서용 변수 표기다. 발송업체의 실제 변수 문법이 아니다.

```text
[Audit Say] 요청하신 CPA 채용공고 안내

Audit Say에서 신청하신 조건에 해당하는 새 공고 1건을 안내드립니다.

회사: {{company}}
공고: {{title}}
게시일: {{posted_at}}

지원 방법과 마감 여부는 공고 원문에서 확인해 주세요.
신청하신 조건에 해당하는 공고가 여러 건이면 각각 안내됩니다.
수신 변경과 중단은 ‘채용 소식 설정’에서 할 수 있습니다.
```

| 버튼명 초안 | 목적 | 논리적 링크 |
| --- | --- | --- |
| 공고 원문 확인 | 해당 공고 한 건의 원문 열기 | 검증된 `source_url` |
| 채용 소식 설정 | 조건 변경·수신 희망 해제·설정 삭제 | 서비스의 `/settings` |

버튼명은 고정 문구로 둔다. 원문 확인 버튼은 전체 게시판이나 무관한 홍보 페이지가 아닌 해당 공고를 가리킨다. 실제 링크를 확인하지 못한 공고를 임의의 게시글 번호나 URL로 채우지 않는다.

### 심사용 변수 예시

다음은 문구 검토를 위한 가상 데이터이며, 실제 채용 중인 회사나 공고를 뜻하지 않는다. 실제 신청 시에는 확인된 공고 표본과 실행 가능한 링크로 교체한다.

| 변수 | 가상 예시 | 값 처리 원칙 |
| --- | --- | --- |
| `company` | 예시회계법인 | 회사명 미확인 시 `원문 확인`; 임의 추정 금지 |
| `title` | 2026년 수습회계사 채용 | 실제 제목 사용; 길이·광고 혼입을 업체 규격에 맞춰 검토 |
| `posted_at` | 2026-09-09 | 게시일 미확인 시 `원문 확인` |
| `source_url` | 실제 신청 전에 확정 | 공식 KICPA HTTPS 공고 링크만 사용 |

변수마다 예시값을 제출하고 본문의 발송 주체·신청 근거를 고정 문구로 유지한다. 이는 변수만으로 이루어진 템플릿과 가변 버튼명 등의 반려 기준을 피하기 위한 작성안이다. 문구·변수·예시를 포함한 최종본은 [알림톡 심사 가이드 §2](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit)에 따라 다시 확인한다.

## 3. 신청·동의 화면 준비

다음은 이 서비스가 신청 사실과 발송 범위를 일치시키기 위해 사용할 제품 요건이다. 카카오가 동일한 화면 배치나 체크박스 수를 지정했다는 의미는 아니다.

| 화면 요소 | 표시·처리 요건 |
| --- | --- |
| 조건 선택 | 위 두 게시판 조건을 각각 표시하고 최소 한 가지를 회원이 직접 선택 |
| 별도 신청 동의 | 기본 체크하지 않은 항목에서 선택 조건과 반복 발송 안내를 읽고 신청 |
| 발송 횟수 안내 | 조건에 맞는 신규 공고 한 건당 한 번 안내하며, 복수 공고가 올라오면 각각 발송됨을 신청 버튼 근처에 표시 |
| 신청 상태 | 선택 조건, 수신 희망 여부, 현재 준비 상태를 확인 가능하게 표시 |
| 중단 | 수신 희망 해제와 설정 삭제 경로 제공. 재개 시 중단 기간의 공고를 일괄 발송하지 않음 |
| 준비 단계 고지 | 현재는 수신 희망과 조건만 저장하며, 실제 발송은 서비스 준비와 휴대전화 인증을 마친 뒤 시작한다고 표시 |
| 수신자 확인 | 이번 단계에서는 전화번호를 수집하지 않음. 업체 연동 단계에서 본인이 이용하는 수신번호 확인과 필요한 개인정보 안내를 준비 |
| 증빙 | 회원 ID, 선택 조건, 동의문 버전, 동의 시각과 변경·철회 사실을 실제 구현 범위에 맞게 보관·설명 |

신청 동의문 초안:

> 선택한 조건에 맞는 신규 CPA 채용공고 안내를 신청합니다. 공고 한 건당 한 번 안내받으며, 조건에 맞는 공고가 여러 건 등록되면 각각 반복해서 안내받는 데 동의합니다. 언제든 수신 희망을 해제하거나 설정을 삭제하여 중단할 수 있습니다. 현재는 신청 내용을 저장하는 준비 단계이며, 실제 발송은 서비스 준비와 휴대전화 인증을 마친 후 시작됩니다.

화면에 사용할 실제 문구와 버전은 `lib/kicpa/subscription.ts`의 중앙 동의문을 기준으로 맞춘다. 요약 필드 축소로 게시판 선택이나 반복 안내 범위가 바뀌지는 않으므로 동의 버전 `2026-09-09-v1`을 유지한다. 이 초안만으로 동의가 이루어졌다고 간주하지 않는다. 광고 수신 동의나 카카오 로그인·개인 메시지 권한을 이 신청 동의로 대신하지 않는다.

## 4. 심사 설명 및 증빙 초안

신청서 설명란에 사용할 문안:

```text
Audit Say의 채용 소식 설정에서 회원이 직접 선택한 CPA 채용 조건에 새 공고가 확인될 때 발송하는 안내입니다. 조건은 ‘수습CPA 게시판 전체’와 ‘CPA 게시판 제목에 수습 또는 신입이 포함된 공고’ 중 회원이 선택합니다. 메시지 한 건은 공고 한 건의 제목, 회사명, 게시일과 원문 확인 버튼을 제공합니다. 신청 화면에서 여러 공고가 확인되면 각각 반복 안내된다는 점에 동의를 받으며, 회원은 설정 화면에서 수신을 중단할 수 있습니다. 회원의 요청과 무관한 일반 소식·서비스 홍보를 이 템플릿으로 발송하지 않습니다. 해당 요청 조건과 발송 방식이 직업/견적 추천 유형에 해당하는지 검토를 요청드립니다.
```

실제 신청 전, 조건 선택과 미선택 동의 화면, 신청 완료·중단 화면, 공고 한 건의 요약 값을 채운 메시지와 검증된 원문 링크를 준비한다. 현재 게시판 외곽 페이지와 정책 페이지의 HTTP 응답은 확인했으나 실제 목록 구조·개별 원문 링크·파서 실데이터 검증은 미완료다. 가상 예시를 검증된 공고로 표시하지 않는다. 저장되는 동의 기록과 각 화면의 문구가 일치하는지 확인한다. 전화번호·실명 등 개인 정보가 포함된 증빙은 필요한 범위로 가린다.

운영에서는 수신자가 선택하지 않은 게시판의 공고를 보내지 않고, 공고 원문 안의 홍보 문구를 고정 안내문으로 덧붙이지 않는다. 제목·링크 등의 내용이 심사 범위를 벗어나는 경우 자동 발송을 보류하고 확인한다. 알림톡 승인 이후에도 실제 발송 내용과 신청 범위가 자동으로 적합해지는 것은 아니다. [심사 기준 및 링크에 관한 안내](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit)

## 5. 업체 선정 후 확정할 사항

비즈니스 채널·발신프로필, 템플릿 분류와 승인 가능성, 전화번호 인증 방식, 개인정보 처리 및 위탁 안내, 본문 길이·허용 변수·버튼·URL 규격은 업체 선정 후 확정한다. **업체별 변수·링크 규격 적용은 후속 작업이다.** 승인된 본문과 변수 예시를 실제 발송 어댑터에 반영한 후 확인하며, 이 문서 작성으로 업체를 선택하거나 템플릿을 등록·신청·발송하지 않는다.

알림톡은 공식 딜러를 통한 연동과 비즈니스 채널 등의 준비가 필요한 별도 서비스다. 현재 수신 희망을 저장하는 기능을 알림톡 발송이 이미 가능한 상태로 표시하지 않는다. [알림톡 시작하기](https://kakaobusiness.gitbook.io/main/ad/infotalk)

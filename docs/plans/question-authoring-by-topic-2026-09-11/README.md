# 주제별 문제·물음 선정과 제작 계획

작성일: 2026-09-11. **19개 주제 전체의 다음 제작 후보를 선정한 계획**이다. OX 학습 순서로 읽되 주제·요소·기존 문항 ID는 유지한다. 실제 문항 작성·채점·편입은 이번 요청 범위에 포함하지 않는다.

이번 계획은 [wiki 통합 현황](../../../cpa_uploader/wiki/_meta/authoring-dashboard.md)에서 시작해 주제별 지침, 원자료 카탈로그, 구체 요구사항 빈도, 기존 발문·모범답안·criterion 및 보존 초안을 대조했다. 판단 기준은 **빈도가 확인된 구체 요구, 현재 은행과 다른 학습목표, 조건·예외를 평가할 필요, 원문 확보 가능성**이다. 요소 미연결 수를 곧바로 새로 만들 문제 수로 바꾸지 않았다.

**서브에이전트에게 나누어 맡길 때는 [14개 작업 배정표·실행 순서](assignments/README.md)를 사용한다.** 기존 초안 후속 2작업, 신규 P1 6작업, P2 6작업에 담당 세트·물음·전용 출력 폴더·선행 범위·완료 조건·전달용 지시문을 붙였다. 총괄 1명과 작업자 최대 3명의 병렬 실행을 기준으로 한다.

**총 49세트·131물음·잠정 377점**이다. 이 중 기존 초안 계속은 **7세트·14물음·49점**, 새 작성 계획은 **42세트·117물음·328점**이다. 새 작성에는 기존 요구의 사례 심화와 의도된 복습도 포함하며 모두 새로운 커버리지라는 뜻은 아니다.

우선순위는 **P1 26세트·68물음**, **P2 23세트·63물음**으로 나누었다. P1 안에 기존 초안 7세트가 포함된다. 문항 수는 상위 제목이 아니라 아래 상세 문서의 세트·물음 ID를 세었고, 점수는 물음 표를 합산했다.

## 선정 기준과 읽는 방법

P1은 다음 제작·검증 차례에 우선 다룰 후보, P2는 P1 다음에 추가할 심화다. 선정하지 않은 후보는 각 주제의 유보 사유를 따로 기록했다. 우선순위는 출제 확률이나 가중합 점수가 아니다. **교육상 우선순위와 생성 준비상태는 별개**이므로 P1이어도 판본이나 완전열거의 근거가 부족하면 생성을 먼저 시작하지 않는다.

| 계획의 구분 | 선정 이유 | 실행할 일 |
|---|---|---|
| 기존 초안 계속 | 같은 목표의 미편입 초안이 이미 있음 | 초안·최신 후속 기록을 이어받아 보완·의미검수·실제 채점 수행 |
| 신규 요구 | 비교한 현재 발문·답안·criterion에 요구 범위의 차이가 있음 | 공식 원문에서 새 사례와 답안 범위를 설계 |
| 기존 요구 심화 | 기본 개념은 있으나 조건·시점·예외·근거를 더 구별할 가치가 있음 | 어떤 판단을 추가하는지 명시하고 별도 문제로 구성 |
| 의도된 복습 | 원리와 적용을 다시 묻는 학습 목적이 분명함 | 새 커버리지로 집계하지 않고 복습 목적을 표시 |
| 제외·유보 | 이미 은행에 충분히 포함되었거나 중복 초안·계산·근거 미확정 문제가 있음 | 상세 주제 문서의 사유를 남기고 이번 제작량에서 제외 |

상세 문서의 `TXX-A`, `TXX-A-Q1`은 **계획을 찾기 위한 번호**다. 실제 세트·물음 ID를 미리 예약한 것이 아니다. 각 물음 표의 답안과 배점은 설계안이며 공식 본문 및 의존 문단을 대조한 뒤 확정한다. 표에 적지 않은 해설 지식을 숨은 채점요소로 추가하지 않는다.

| 원발문·사례·근거 위치 | [원자료 카탈로그](../../../cpa_uploader/wiki/_meta/source-catalog.md) | 실제 `src-*` ID와 문단·페이지, 추가 확보할 의존 문맥 |
| 현재 문제와 차이 | [연결 분석](../../../cpa_uploader/analysis/coverage/summary.md) · [편집 정본](../../../cpa_uploader/data/cpa_question_sets_v3.authoring.json) | 비교한 세트·물음·criterion, 직접/일부/상위/인접 관계 |
| 공식 근거·판본 | [출처·판본 지도](../../../cpa_uploader/wiki/_meta/source-review-map.md) | 로컬 공식 발췌의 존재, 시험 판본 등 미확인 사항 |
| 작성·검수 계약 | [원자료 기반 설계](../../../cpa_uploader/wiki/question-generation/source-authoring-design.md) · [출력 스키마](../../../cpa_uploader/wiki/question-generation/question-output-schema.md) | 명제별 정수 배점, 완전열거 범위, 의미검수·실제 채점 순서 |

빈도는 같은 실제 물음의 교재 재수록을 제외한 값이다. 서로 다른 실제 출제는 각각 유지한다. 하나의 새 세트에 여러 요소를 연결해도 각 빈도를 더해 그 세트의 출제 빈도라고 하지 않는다. 일부 확장 물음은 인접·상위 요구의 빈도만 확보되어 있으므로 상세 문서에서 관계를 따로 표시했다. 0회와 미연결은 미출제 확정이 아니다.

|---|---|

| 07 재무제표감사 통제테스트 ↔ 17 내부회계관리제도 감사 | 재무제표 의견을 위한 증거 수집과 내부회계관리제도 자체의 효과성 의견을 구분 |
| 08 감사증거 ↔ 11 회계추정 ↔ 13 전문가 활용 | 기업이 작성한 정보·경영진측 전문가와 감사인측 전문가를 구별하고, 추정방법·가정·자료의 평가를 따로 한정 |

## 제작 배치와 완료 조건

달력상의 일수보다 아래 산출물을 기준으로 진행한다. 실제 모델 호출량·원문 확보 시간·검수 실패율을 아직 측정하지 않았으므로 소요 시간을 확정치로 제시하지 않는다. 한 배치는 대체로 2~4세트로 묶고 검증을 마친 뒤 다음 배치로 넘어간다.

| 순서 | 작업 묶음 | 완료 조건 |
|---|---|---|
| 0 | 기존 미편입 초안과 후속 검수 기록 정리 | 중요성·재고 시차·공란형 조회·표본규모·후속사건·계속기업 초안 6개를 새로 만들지 않고 이어받음. 지배기구 커뮤니케이션 1개는 최신 검수·게시 준비 이력과 구분 |
| 1 | 신규 후보의 공식 근거·답안 범위 확정 | 주체·시점·조건·예외·완전열거의 하위 항목 및 실제 source ID를 확보. 사용자 미지정 시험 연도는 제작 전 결정 |
| 2 | 상세 계획의 P1 후보를 OX 순서로 제작 | 현재 은행·다른 배치와의 중복 재대조, 새 사례·발문·답안·criterion·정수 배점 대응표 완성 |
| 3 | 해당 배치 의미검수·실제 채점 | 전 물음·criterion의 기본·경계 사례 실측, 불일치 원인 조사·수정·영향 사례 재채점, 최종 버전 receipt 보존 |
| 4 | P2 심화 및 유보 후보 재선정 | P1과 겹치는 요구를 재점검하고 서로 다른 시점·예외·통제와 보고의 경계를 보강 |
| 5 | 승인 범위의 정본 편입·공개 | 사람 검수 근거와 현행 승급 계약 충족 후 수행. 이번 계획을 편입·게시·운영 배포 승인으로 해석하지 않음 |

### 실제 제작 시 남길 산출물

1. 선택한 계획 단위를 `adapt_existing_question` 또는 `new_from_standard`의 version 1 계획서로 옮긴다. ‘기존 초안 계속’은 작업 분류이며 새로운 JSON `mode` 값이 아니다. 기존 초안의 mode를 유지하되 목표·조건을 바꾸면 근거와 차이를 기록한다.
2. `cpa_uploader/drafts/<실제 배치>/`에 문항·계획·출처 패킷·작성자 QA·검수 receipt를 보존한다. 기존 실행 기록을 덮어쓰지 않는다. 생성 입력의 준비상태 `ready`와 문항 검수상태를 구분한다.
3. 물음은 `descriptive`, `enumeration`, `judgment`로 나누고 `selection=all`, `ordered=false`, `max_entries=null`, `overflow_policy=none`을 적용한다. 독립 명제는 기본 1점으로 합산하며 총점 상한에 맞추어 요구를 합치지 않는다. 계산 문제는 만들지 않는다.
4. 모든 명제에 완전 답안·허용 표현·한 명제 누락·반대 의미·조건 경계 사례를 마련하고 전 물음 빈 답안도 확인한다. 열거 역순, 한 문장에 담은 여러 명제, 조치에서 함축된 결론, 무관한 문장 뒤 정답도 포함한다. 조건 경계와 명시적 반대의 기대값은 현행 검수 계약을 대조한다.
5. 형상·출처 인용·은행 중복 검사 후 실제 모델 의미검수와 실제 채점으로 이어간다. 작성자 기대판정 점수 재생을 모델 실측으로 보고하지 않는다. 관련 실행 방법은 [제작 스킬](../../../.agents/skills/audit-question-author/SKILL.md)과 [검토 스킬](../../../.agents/skills/audit-question-review/SKILL.md)을 따른다.
6. 문항이 구체화되면 관계 장부에 실제 요소·source 단위·물음·criterion 및 확인 시점의 해시를 기록한다. 현재 계획만으로 미연결을 해소하거나 관계를 reviewed로 올리지 않는다.

## 이번 계획의 기준과 검증

현재 은행·초안 목록·파일 해시·기존 게시 이력·실행한 검사와 미실행 범위는 [입력·초안 상태 및 확인 기록](계획-수립의-입력-초안-상태와-확인-범위.md)에 정리했다. 자료가 바뀌면 이 기록의 해시를 치환하는 대신 후속 계획에서 변경 영향을 대조한다.

문서의 세트·물음 ID와 잠정점수를 다시 집계했고, 카탈로그·요소·기존 문항 참조 및 원출제 빈도를 검사했다. 발문과 배점이 어긋난 부분, 중복 요구의 처리, 여러 회사 판정의 독립 배점을 교차 검토해 보완했다. 분석·wiki 검사도 통과했다. 자세한 확인 수치와 미검증 범위는 입력 기록에 남긴다.

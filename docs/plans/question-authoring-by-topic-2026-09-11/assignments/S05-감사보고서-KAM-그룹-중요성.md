## 출력 권한

미래 실행에서 쓸 수 있는 위치는 저장소 루트 기준 `cpa_uploader/drafts/delegated-authoring-2026-09-11/s05/` **한 폴더뿐**이다. 이 위치와 파일은 지금 만들지 않는다. 원자료·정본·공개본·coverage 입력·wiki·코드·다른 패키지는 읽기 대상으로 두며, 공통 반영이 필요하면 총괄에게 제안한다.

신규 문항·작성계획·실제 출처 패킷·개별 검수/채점 증거·총괄 전달 요약은 위 폴더 안에만 남긴다. 파일 이름·형상·검증 절차는 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다. 필요한 공식 출처 신규 확보본도 이 폴더에 보존하고 공용 카탈로그 반영은 총괄에게 전달한다.

QA 사례 파일 이름은 `qa-cases-<계획ID소문자>.json`처럼 정하며 `draft`·`checkpoint` 문자열을 넣지 않는다. 특히 기존 `draft-*` 실제 ID를 붙여 `qa-draft-*` 파일을 만들지 않는다. 자세한 산출물 계약은 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다.

실제 생성은 [공통 계약](서브에이전트-공통-작업-계약.md)의 **총괄 단일 생성 경로와 직렬 ID 확정**을 이용한다. 각 작업자가 개별 생성 CLI를 실행한 뒤 ID 장부만 기입하는 방식은 금지한다. 총괄이 전역 활성 초안을 `existingDrafts`로 전달하는 생성 흐름에 필요한 준비계획·출처 패킷·설계경계를 제출하고, 반환된 담당 결과의 검수·수정을 이어간다.

## 담당 범위와 고유 경계

- 의견거절 보고서의 업무수임 표현·증거부족 근거와 KAM·기타정보 단락 생략의 법규상 예외를 함께 확인한다.
- 보고서일 하한과 업무수행이사 이름 공시의 극히 드문 신변위협 예외를 구별한다. 불편·평판 우려로 예외를 넓히지 않는다.
- KAM 비공개 조건·사전 공시 여부·결정 문서화를 다룬다. 그룹 중요성은 결정권자·적합성 평가·명백하게 사소함의 보고한도를 각각 구별한다.

## 선행 패킷과 전달 사항

선행 패킷: **[N05](N05-그룹감사의-부문감사인-업무범위.md) · [N06](N06-비교정보-기타정보-내부회계-보고.md)**. 해당 담당자의 최종 학습목표·조건/예외·답안명제·공식 판본/출처 결속·중복 검토 결과를 전달받는다.

선행은 **발문과 채점요건을 확정하기 위한 의존성**이다. 선행이 미완료여도 원문 확보·기존 은행 대조·출처 공백 조사·경계 사례 후보 준비는 먼저 진행한다. 아직 받지 않은 확정 내용을 임의로 채워 실제 문항의 조건이나 배점을 고정하지 않는다.

N05의 그룹 정의·중요성 조건과 N06의 보고문구·시점 경계를 받은 뒤 발문·criterion을 확정한다. 보고서 시안은 감사 종류별로 구별하고 다른 패키지의 문안을 직접 수정하지 않는다.

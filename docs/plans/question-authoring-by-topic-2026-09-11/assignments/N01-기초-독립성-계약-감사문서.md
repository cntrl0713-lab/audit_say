# N01 — 기초·독립성·계약·감사문서

**배정: 4세트·12물음·잠정 36점 / P1·신규 제작.** 현재 문서는 실행 전 작업지시서다. 이 문서 작성만으로 문항 생성·모델 호출·정본 반영을 시작하지 않는다. 실제로 배정받아 실행할 때 [공통 계약](서브에이전트-공통-작업-계약.md)과 [입력 기준선](../계획-수립의-입력-초안-상태와-확인-범위.md)을 함께 따른다.

표의 ID는 계획용 ID다. 실제 세트·물음·criterion ID는 총괄이 배정한다. 근거 검토 결과 요구·배점을 바꿀 필요가 있으면 변경 이유와 영향 합계를 총괄에 제안하고, 담당 범위를 임의로 늘리거나 다른 패키지의 세트를 가져오지 않는다.

## 출력 권한

미래 실행에서 쓸 수 있는 위치는 저장소 루트 기준 `cpa_uploader/drafts/delegated-authoring-2026-09-11/n01/` **한 폴더뿐**이다. 이 위치와 파일은 지금 만들지 않는다. 원자료·정본·공개본·coverage 입력·wiki·코드·다른 패키지는 읽기 대상으로 두며, 공통 반영이 필요하면 총괄에게 제안한다.

신규 문항·작성계획·실제 출처 패킷·개별 검수/채점 증거·총괄 전달 요약은 위 폴더 안에만 남긴다. 파일 이름·형상·검증 절차는 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다. 필요한 공식 출처 신규 확보본도 이 폴더에 보존하고 공용 카탈로그 반영은 총괄에게 전달한다.

QA 사례 파일 이름은 `qa-cases-<계획ID소문자>.json`처럼 정하며 `draft`·`checkpoint` 문자열을 넣지 않는다. 특히 기존 `draft-*` 실제 ID를 붙여 `qa-draft-*` 파일을 만들지 않는다. 자세한 산출물 계약은 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다.

실제 생성은 [공통 계약](서브에이전트-공통-작업-계약.md)의 **총괄 단일 생성 경로와 직렬 ID 확정**을 이용한다. 각 작업자가 개별 생성 CLI를 실행한 뒤 ID 장부만 기입하는 방식은 금지한다. 총괄이 전역 활성 초안을 `existingDrafts`로 전달하는 생성 흐름에 필요한 준비계획·출처 패킷·설계경계를 제출하고, 반환된 담당 결과의 검수·수정을 이어간다.

## 담당 범위와 고유 경계

- T02-A는 의구심의 정의와 사례 사실→범주 연결이다. 네 범주 이름만 나열한 답을 이유 설명의 만점 답으로 만들지 않는다.
- T01-A는 주식보수·공동사업·낮은 현금보수의 조건 차이이며 일반 KGA 220 절차 재열거가 아니다. 금지와 안전장치 적용 가능성을 사례별로 분리한다.
- T03-A는 기업 내 정보·추가자료·담당자 접근권과 일반 계약조건이다. T04-B는 적시 작성·행정적 취합·취합 후 변경 이력이다. 법적 조사권·일반 법정 보존기한은 확장하지 않는다.

## 출처 확보 조건

- 공식 200.13(l)·15·A21~A25, 210.6·8~11, 230.7·14~16·A21~A24의 하위항목과 주체·시점을 확보한다. 학습자료의 요약 단위를 공식 원문으로 바꾸어 표시하지 않는다.
- T01-A의 윤리기준 재무적 이해관계·사업관계·보수 조항과 국내 직무제한 규정은 적용 판본·법규 예외 확인 전 정답 확정 금지다. 과거 기출의 안전장치를 현행 의무로 자동 승계하지 않는다.

각 상세계획의 실제 `source_unit_ids`·대표 원기출·빈도 관계·기존 criterion 차이를 그대로 추적한다. 출처 본문·하위항목·적용자료·예외가 새 명제를 직접 지지해야 하며, 카탈로그 연결이나 인용 일치만으로 공식 판본·의미검수 완료를 주장하지 않는다.

## 선행 패킷과 전달 사항

선행은 **총괄의 기준선**이다. 총괄이 전달한 현행 은행·기존 초안·소스·코드 해시 및 실제 ID 배정을 확인한다. 다른 패키지의 종료를 기다릴 필요는 없다.

선행은 **발문과 채점요건을 확정하기 위한 의존성**이다. 선행이 미완료여도 원문 확보·기존 은행 대조·출처 공백 조사·경계 사례 후보 준비는 먼저 진행한다. 아직 받지 않은 확정 내용을 임의로 채워 실제 문항의 조건이나 배점을 고정하지 않는다.

S01이 재사용할 200·210·220 관련 판본 구분과 명제 경계를 패킷으로 전달한다. 공식 원문을 못 얻은 세트가 있어도 다른 세트의 독립 조사와 설계를 계속한다.

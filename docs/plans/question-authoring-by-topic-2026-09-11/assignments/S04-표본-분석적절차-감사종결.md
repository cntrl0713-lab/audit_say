# S04 — 표본·분석적절차·감사종결

**배정: 4세트·11물음·잠정 29점 / P2·후속 신규 제작.** 현재 문서는 실행 전 작업지시서다. 이 문서 작성만으로 문항 생성·모델 호출·정본 반영을 시작하지 않는다. 실제로 배정받아 실행할 때 [공통 계약](서브에이전트-공통-작업-계약.md)과 [입력 기준선](../계획-수립의-입력-초안-상태와-확인-범위.md)을 함께 따른다.

표의 ID는 계획용 ID다. 실제 세트·물음·criterion ID는 총괄이 배정한다. 근거 검토 결과 요구·배점을 바꿀 필요가 있으면 변경 이유와 영향 합계를 총괄에 제안하고, 담당 범위를 임의로 늘리거나 다른 패키지의 세트를 가져오지 않는다.

## 출력 권한

미래 실행에서 쓸 수 있는 위치는 저장소 루트 기준 `cpa_uploader/drafts/delegated-authoring-2026-09-11/s04/` **한 폴더뿐**이다. 이 위치와 파일은 지금 만들지 않는다. 원자료·정본·공개본·coverage 입력·wiki·코드·다른 패키지는 읽기 대상으로 두며, 공통 반영이 필요하면 총괄에게 제안한다.

신규 문항·작성계획·실제 출처 패킷·개별 검수/채점 증거·총괄 전달 요약은 위 폴더 안에만 남긴다. 파일 이름·형상·검증 절차는 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다. 필요한 공식 출처 신규 확보본도 이 폴더에 보존하고 공용 카탈로그 반영은 총괄에게 전달한다.

QA 사례 파일 이름은 `qa-cases-<계획ID소문자>.json`처럼 정하며 `draft`·`checkpoint` 문자열을 넣지 않는다. 특히 기존 `draft-*` 실제 ID를 붙여 `qa-draft-*` 파일을 만들지 않는다. 자세한 산출물 계약은 [공통 계약](서브에이전트-공통-작업-계약.md)을 따른다.

실제 생성은 [공통 계약](서브에이전트-공통-작업-계약.md)의 **총괄 단일 생성 경로와 직렬 ID 확정**을 이용한다. 각 작업자가 개별 생성 CLI를 실행한 뒤 ID 장부만 기입하는 방식은 금지한다. 총괄이 전역 활성 초안을 `existingDrafts`로 전달하는 생성 흐름에 필요한 준비계획·출처 패킷·설계경계를 제출하고, 반환된 담당 결과의 검수·수정을 이어간다.

## 담당 범위와 고유 경계

- 표본위험의 방향과 효과성·효율성 영향으로 답안을 설계하며 교재의 제1종·제2종 번호를 유일 정답으로 만들지 않는다.
- 분석적절차의 위험평가·실증·종결 목적과 자료 신뢰성·차이조사를 분리한다. 계산 자체는 요구하지 않는다.
- 왜곡표시 수정 후 잔여 오류 확인과 수정거절의 평가, 서면진술 일반거절과580.20 의견거절 조건을 구별한다. T12-D 물음 간 의도된 복습의 비용을 검토하되 배점·범위 변경은 총괄에 제안한다.

## 출처 확보 조건

- 공식530.5·A21~A23, 520.5~7 및315 위험평가절차 문단을 패킷화한다. 방향·이유·독립 변화 조건은 R01의530 근거를 재사용하되 원문 판본 결속을 확인한다.
- 공식450.7·9~11·A9, 580.10~11·19~20을 확보한다. 진술에 대한 단순 의문과 신뢰할 수 없다는 결론의 조건을 직접 인용에 연결한다.

각 상세계획의 실제 `source_unit_ids`·대표 원기출·빈도 관계·기존 criterion 차이를 그대로 추적한다. 출처 본문·하위항목·적용자료·예외가 새 명제를 직접 지지해야 하며, 카탈로그 연결이나 인용 일치만으로 공식 판본·의미검수 완료를 주장하지 않는다.

## 선행 패킷과 전달 사항

선행 패킷: **[R01](R01-빈도-우선-초안-6개-후속-검증.md) · [N03](N03-통제증거-실증절차-부정책임.md)**. 해당 담당자의 최종 학습목표·조건/예외·답안명제·공식 판본/출처 결속·중복 검토 결과를 전달받는다.

선행은 **발문과 채점요건을 확정하기 위한 의존성**이다. 선행이 미완료여도 원문 확보·기존 은행 대조·출처 공백 조사·경계 사례 후보 준비는 먼저 진행한다. 아직 받지 않은 확정 내용을 임의로 채워 실제 문항의 조건이나 배점을 고정하지 않는다.

R01의 표본·종결 선행 범위 및 N03의 통제/실증절차 조건을 받는다. 회귀·누락 사례는 판단 문장 삭제 후 다른 이유 문장에 판단이 남는지 전체 답안을 읽고 정한다.

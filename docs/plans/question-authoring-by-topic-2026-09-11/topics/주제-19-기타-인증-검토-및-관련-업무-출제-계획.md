# 주제 19 — 기타 인증·검토 및 관련 업무 출제 계획

계획 ID는 생성될 문제 ID가 아니다. 모든 신규 설계는 `draft`이며 시험 적용 연도·공식 판본은 미확정이다. 아래 정수 배점은 독립 명제당 1점의 잠정안이다. 명칭만 요구한 부분은 명칭만 채점하고, 판단이 후속 조치에 분명히 드러나면 같은 판단을 인정한다. 열거는 발문에서 정한 범위 전부를 요구하며 `selection=all`, 순서·응답 개수 제한 없음으로 설계한다. 이 문서는 문항 작성·실제 모델 채점·사람 승인·정본 승급을 수행한 결과가 아니다.

일반 인증 정의·구성요소와 검토기준 명칭은 이미 정본에 있다. 중간검토의 실제 보고문구·서면진술·중요성 판단을 한 세트로 보강한다. 오래된 분·반기 준칙의 적용범위와 현행 판본을 먼저 확정해야 한다.

### T19-A — 중간재무제표 검토의 결론 문구와 종결 판단

목표: 제한적 확신의 수준·결론 형식·서면진술·중요성 판단을 구별한다.

사례 공통지문: 주권상장회사의 독립된 연간재무제표 감사인이 분·반기재무제표 검토를 수행한다. 검토에서 중요한 예외사항은 없고 보고 초안은 감사의견처럼 적극적 결론을 썼다. 담당자는 제한적 확신이므로 중요성을 완화하고 서면진술을 생략하자고 제안한다. 연간감사와 같은 회사의 같은 이용자를 전제한다.

선행 확인: 현재 공식19 발췌의 검토업무기준1·6은 역사적 재무제표 검토의 적용범위·확신을 설명하는 인접 근거다. 중간검토의 직접 요구·서면진술·중요성·보고사례 전문이 확보되기 전 해당 source_unit으로 대체하거나 ready로 승격하지 않는다. 직접 공식 문단번호도 확보 전 임의 생성하지 않는다.

실제 채점 경계: 제한적 확신과 소극적 형식을 한 단어로만 처리, 절차 범위 감소를 중요성 증가로 오해, 해당 기업의 연간감사인이 아닌 검토인의 기준을 전용. 공통적으로 저장 모범답안·동의표현·한 명제 누락·명시적 반대·빈 답안을 포함하고, 열거는 역순과 한 문장도 확인한다.

제외 범위: 검토결론 종류 전체와 범위제한 시 보고·결론미표명 분기는 현행 준칙 확인 뒤 별도 확장 후보.

## 채택하지 않은 후보와 제작 순서

인증업무 정의·다섯 구성요소·비인증업무 예시·검토 수행기준은19-001·002·004와 중복이다. 추정재무정보와 특정목적 재무제표 보고 확장은 국내 공식 전문이 부족하므로 이번 세트에 억지로 합치지 않는다.

1. P2 T19-A: 직접 공식 원문·사례 범위 확정 → 발문·정답·독립 criterion 대응표 → 초안 의미검수 → 실제 모델 채점과 불일치 수정·재채점.

이 순서는 향후 제작 작업이다. 이번에는 계획 파일만 작성했으며 정본·초안·coverage 링크·wiki 생성파일을 수정하지 않았다. 빈도는 [집계 정책](../../../../cpa_uploader/analysis/question-elements/frequency.md)와 [재수록 장부](../../../../cpa_uploader/analysis/question-elements/deduplication.md)에 따라 기출·모의 원물음별로 구분했다. 별도 연습·OX 수치는 기출/모의로 확인되지 않은 수록 레코드 수이므로 출제 횟수와 합산하지 않는다. 미연결은 미출제 확정이 아니다.

# 주제11 — 회계추정과 특수관계자

선정: **2세트·6물음·잠정 19점**. OX 학습순서 10번째, CM8에서 학습한다. T11-*는 계획용 ID이며 실제 생성 ID가 아니다. 계획 상태는 `draft`이고 공식 시험 적용 판본은 미확정이다.

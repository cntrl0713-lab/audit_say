2026-09-08. 대상 5세트·10물음을 전수 검토하고 수정했다. 기존 21criterion·21점에서 **24criterion·24점**으로 변경했다. 정본의 기존 ID와 게시·검수 상태를 유지했으며 상태 승급은 하지 않았다. 2027년 적용은 2026년 시행 기준과 동일하다는 가정이며 최종 시험 판본 확인과 구분한다.

## 적용 기준과 출처

[한국공인회계사회 2025 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11762493343340&fileSeq=7&subId=sub06)의 KGA610·620과 [2026 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06)을 직접 대조했다. 공식 PDF 974쪽·1001쪽 전체 파일의 해시, 대상 12쪽의 추출문, 문단별 인용은 [공식 페이지 장부](../../../../../cpa_uploader/analysis/reviews/question-review-2027/grading-cases/13-official-pages.json), [판본 비교](../../../../../cpa_uploader/analysis/reviews/question-review-2027/grading-cases/13-source-comparison.json), [공식 발췌](../../../../../cpa_uploader/data/official/kga610-620-2025-review13.txt)에 남겼다. 책임11, 기능 평가15, 활용 금지16, 범위 조정18, 서면동의33은 로컬 학습자료의 번호보다 하나 크다. 정본은 공식 번호로 교체했다.

KGA610.12 및620.4의 시행 기준은 2026-01-01 이후 개시하는 보고기간의 재무제표 감사다. 비교한 12쪽 중7쪽은 머리말·쪽수·공백 제외 동일하다. 나머지5쪽의 차이는315 제목 각주,610.34의 표현,220 교차참조,620.8(e)의 품질관리시스템 표현 및620.A6의 자원 관련 문구다. **이번 대상의 직접 정답 명제에는 변경이 없다.** 개정220의 후속 문구를 이번 적용 기준으로 자동 대체하지 않았고 [시행일 메모](./개정-감사기준서-220-시행일-별도-기록.md)를 유지한다. [2027 출제범위 사전예고](https://www.fsc.go.kr/no010104/86803)는 특정 기준서 최종 판본 지정과 구분했다.

PDF634쪽의 국내 추가문단과 각주를 이미지로도 확인했다. 국내 기준에 따른 감사와 그룹감사의 부문감사에서 직접적 보조는 금지되며27–35·37 및 A32–A41은 적용되지 않는다. 두 장에 걸친33·18과 국내 추가문단의 인용은 머리말·꼬리말 및 다른 각주를 제외해 연결했다. 원문의 오탈자와 중복 표현은 윤문하지 않았다. source quote와 연결 requirement 및 SHA-256을 함께 교체했다.

## 채점과 화면 검증

완전 정답·동의어·핵심 누락·반대 의미·빈 답안의 **50개 기본 물음–답안 조합**과 모범답안, criterion별 누락, 같은 문장 인용, 역순·무관 문장 추가, 반복 사실, 주체·서면 입수 상대방 교환, 한쪽 방향만 쓴 범위 조정 사례를 구성했다. 기대값은 공식 원문과 계약을 기준으로 실행 전에 작성했다. 저장된 모범답안도 별도로 평가했다.

1차 실측에서005/sub1의 필수 요건 미충족 근거만 쓴 두 사례는 모델이 활용 금지를 인정하지 않아3회 모두1/2점이었다. 코드 보정에 의한 감점이 아니라 raw 의미 판정이었다. 합의된 함축 결론 정책을 criterion에 명시하고 재실측했다. 상대방 교환·경영진측 전문가로의 대상 교환은0점이었으나 not_met/contradicted 분류가 달랐다. 명시적 교환은 contradicted, 누락은 not_met이라는 계약을 보강하고 새 기대표를 작성했다. 과거 기대표와 raw 로그는 보존한다.

실행 결과의 최종 집계와 코드·프롬프트·모델 해시는 아래 검증 장부에 연결한다. 실제 모델 호출, mock을 사용하는 코드 검증, 화면 검사, 인증·DB E2E를 구별한다. 동일 계약의001·002 실측은 그대로 보존하며 계약을 바꾼003–005는 새로 호출한다. 재처리는 새 모델 호출로 세지 않는다.

실제 QuizClient와 globals.css를 사용한 격리 화면 검사에서5세트×1440/390px의 발문·답안 슬롯·물음 ID·모범답안·결과 귀속, 가로 넘침 없음, 재풀이 초기화, 실패 시 입력 보존, 프로필 갱신 실패 시 결과 보존,5,000자 입력한도를 확인했다. 인증과 서버 action은 mock이다. 스크린샷과[화면 장부](../../../../../cpa_uploader/analysis/reviews/question-review-2027/grading-cases/13-ui-results.json)를 보존했다. 운영 사용자 답안이나 DB에 시험 쓰기를 하지 않았다.

## 연계 주제와 범위

- 01-001/sub2의 품질관리검토 후 책임,01-004/sub2의 팀·전문가 총체적 역량과13-001의 감사의견 책임은 대상과 학습목표가 다르며 모순이 없다.

## 미확인과 완료 판정

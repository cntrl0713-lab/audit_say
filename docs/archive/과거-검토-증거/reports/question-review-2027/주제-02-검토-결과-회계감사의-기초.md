# 주제 02 검토 결과 — 회계감사의 기초

> 이 문서는 당시 검토·설계의 기록입니다. 최신 요구사항·빈도·문항 상태는 [통합 현황](../../../../../cpa_uploader/wiki/_meta/authoring-dashboard.md)을 확인하세요. 과거 수치·판정·실행 결과는 해당 시점의 근거로 보존합니다.

> 후속 결정(2026-09-08): [주제01–03 수정 결정](../../../../plans/주제-01-03-검토에-따른-수정-결정.md)을 따른다. 열거형 모두 작성·정수 배점·새 제출마다 경험치 전액 가산이 확정됐다. 본문의 실측·기대값은 당시 계약의 기록이며, 정책과 충돌하는 수정 제안·답변 대기 상태는 후속 결정으로 대체한다. 제품 수정 완료를 의미하지 않는다.

검토일: 2026-09-08(한국시간). **5세트·10물음·24 criterion·24점** 전수 검토. 정답과 합성 답안을 포함하는 내부 자료다.

**검토 기록은 완료했고, 2027년용 사용 적합은 보류한다.** 발문·채점 계약과 공통 채점 코드에 미해결 P1이 있다. 계획의 검토·실측·수정안 작성을 수행했으며 정본·공개본·암호화 배포물·제품 코드는 변경하지 않았다.

## 주요 이슈와 수정안

### 02-D01 · P1 · 판단 요구 누락 및 다른 개념의 출처 연결. 틀린 제거 가능 판단이 만점에 영향을 주지 않음

대상: pilot-02-005/sub2/crit3, pilot-02-005/sub2/req2. 위치: cpa_uploader/data/cpa_question_sets_v3.authoring.json > pilot-02-005 > sub2.

현재: 정의와 제거 가능 여부를 묻지만 crit3은 미발견 위험의 정의만 채점하며 출처는 13(c) 감사위험 정의. 근거: KGA200 13(e), A49; 발문→criterion 양방향 대조.

기대/실제: 현행 계약: 판단만=0/1, 정의+제거 가능 오답=1/1. 실제도 각각 0,1. 발문 전체 기준으로는 두 요구가 별도 채점되어야 함.

수정안: req2를 13(e)로 연결하고 crit3의 중요성·미발견 조건을 보존. A49 기반 제거 불가 판단을 별도 req/criterion 1점으로 추가. 공개본·암호화본·manifest·표시점수·테스트 재생성.

의미·배점 영향: 명제 누락 복원. 권고안은 세트와 전체 배점 +1, partial 금지 유지. 1점 고정 시 발문 축소 대안 선택 필요. 상태: open_proposal_only. 재현 사례: `judgment-only`, `definition-with-wrong-judgment`.

### 02-C01 · P1 · 양적·질적 척도를 한 문장으로 답하면 AI의 인용 범위 선택에 따라 부당 감점 가능

대상: pilot-02-004/sub1/crit1, pilot-02-004/sub1/crit2. 위치: lib/questionV3.ts:269-289; lib/questionV3Grading.ts 인용 규칙.

현재: 동일 인용의 met/partial 중 한 criterion만 유지. 근거: 한 문장이 독립된 여러 명제를 담을 수 있음; 01-C01과 동일 공통 결함.

기대/실제: 모의 응답은 두 criterion met 및 동일 문장 인용. 기대 2점, 코드 1점. 실제 모델은 서로 다른 부분구절을 인용해 2점이므로 모델과 코드 결과를 구분.

수정안: 문자열 중복 자체로 독립 criterion을 탈락시키지 않도록 인용 계약과 검증을 개선. 동일 사실 재사용은 criterion 의미 중복 검증과 분리.

의미·배점 영향: 전 주제 영향. 회귀사례로 독립 명제/동일 사실 반복 둘 다 보존. 상태: open_proposal_only. 재현 사례: `same-quote-independent`.

### 02-C02 · P1 · 세 번째 항목이 득점하고 화면에도 초과 답안 처리 안내 없음

대상: pilot-02-004/sub1/crit2. 위치: lib/questionV3Grading.ts buildGradingPrompt; lib/questionV3.ts scoreCriterionVerdicts; QuizClient 열거 안내.

현재: max_entries=2, ignore_after_limit가 프롬프트에도 코드 제한에도 반영되지 않음. 근거: 정본 및 공개본의 현행 constraints 계약; 01-C02와 동일.

기대/실제: 기대 1점. 실제 모델 평가 세 번 모두 2점, 모의 met 응답에 대한 코드도 2점.

수정안: 항목 분리 규칙을 정한 뒤 코드에서 허용 항목만 모델·인용 검증에 전달. 문장 내 두 명제와 두 항목을 구분. 화면에 개수와 초과 처리 안내.

의미·배점 영향: ignore_after_limit인 모든 주제. 점수 계약 유지, 실행 결과 교정. 상태: open_proposal_only. 재현 사례: `third-entry-overflow`, `overflow-mock-enforcement`.

### 02-C03 · P1 · 정당한 나열 답안의 세 criterion이 보안 플래그로 모두 0점 처리됨

대상: pilot-02-001/sub2/crit4, pilot-02-001/sub2/crit5, pilot-02-001/sub2/crit6. 위치: lib/questionV3Grading.ts 보안 규칙 및 applyQuestionSetJudgment.

현재: 문장 없이 전문용어만 나열하면 salad_detected=true. 근거: 발문이 판단 근거 세 기준의 제시를 요구함. 정의 누락과 기준 나열의 정답성을 분리해야 함.

기대/실제: 기준 이름 나열은 기대 3점(정의 0). 실제 3회 모두 0점. '판단 근거는 …이다'로 쓰면 3점.

수정안: 발문에 대응하는 명칭·항목 나열은 허용하고 무관한 키워드 조합과 구분하도록 보안 판정 계약 수정. 개별 보안 플래그와 감점 사유도 결과에 전달.

의미·배점 영향: 주제01/06/08/15 등 열거·명칭 제시 전반. 추가 실모델 평가 필요. 상태: open_proposal_only. 재현 사례: `standards-list-only`, `three-standards-one-sentence`.

### 02-D02 · P1 · 감사위험 자체가 달라지는 상황까지 무조건 역관계라고 일반화할 수 있음

대상: pilot-02-004/sub2/crit3, pilot-02-004/src2. 위치: 정본 pilot-02-004 sub2, 로컬 KGA200 A47.

현재: 역의 관계만 서술하고 주어진 감사위험 수준이라는 전제가 없음. 근거: 공식 KGA200 A47, 2025/2026 전문 PDF 22쪽.

기대/실제: 현행 모델은 전제 포함 정답과 전제 없는 저장 모범답안을 모두 met. 현재 채점 계약에 전제 없음. 전제 교체의 별도 실측은 미실행.

수정안: 발문에 '주어진 감사위험 수준에서'를 추가하고 정답·claim·critical_facts·공식 출처에 동일하게 반영.

의미·배점 영향: 전제 복원, 정답 적용 범위 명확화. 1점 유지. 06 위험평가 주제와 함께 검토. 상태: open_proposal_only. 재현 사례: `pilot-02-004-full`.

### 02-D03 · P1 · 판단만 맞는 답안이 채점기준의 추가 요구 때문에 감점

대상: pilot-02-004/sub2/crit4. 위치: 정본 pilot-02-004 sub2 prompt/criteria.

현재: 발문은 제거 가능 여부 판단만 요구, claim은 감사의 고유한계 때문이라는 근거까지 요구. 근거: A49; 발문과 채점기준의 요구 범위 대조.

기대/실제: 현행 claim 기대와 실측은 0점. 발문만 기준으로 하면 제거 불가 판단은 해당 요구를 충족함.

수정안: 발문에 판단과 근거를 모두 요구한다고 명시하고 critical_facts에도 고유한계 근거를 반영. 부분점수 없는 결합 criterion임을 검토 문서에 명시.

의미·배점 영향: 발문 요구 명확화, 2점 유지 가능. 결론·근거를 별도 점수로 분리하면 배점 재설계 필요. 상태: open_proposal_only. 재현 사례: `conclusion-without-basis`.

### 02-D04 · P2 · 기준15의 중요왜곡표시 가능성 등 다른 타당한 이유의 허용 범위가 모호함

대상: pilot-02-001/sub1/crit2. 위치: 정본 pilot-02-001 sub1 prompt/criteria.

현재: 일반적인 근거를 묻고 설득력이 낮은 증거 불허만 득점 근거로 제한. 근거: A25의 의구심과 증거 요구는 병렬적 제한.

기대/실제: 대체 근거 답안의 실모델 판정은 미실행. 도메인·계약 대조로 범위 모호성 확인.

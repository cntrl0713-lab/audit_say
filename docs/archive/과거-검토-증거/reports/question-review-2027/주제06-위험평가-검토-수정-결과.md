## 적용 기준과 근거

[한국공인회계사회 2025 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11762493343340&fileSeq=7&subId=sub06)의315 및330 직접 문단을 [2026년7월 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06)과 대조했다. 315.10은2026-01-01 이후 개시 보고기간 감사에 시행(2025 조기적용 가능)이다. 12개 발췌 페이지 중11개는 공백·페이지표시 제외 동일하고, 나머지26(d)는 A175–A181 참조 추가만 확인했다. 대상 채점 명제 변경은 없다. 2027은2026 시행 기준 동일 적용 가정을 유지한다. [2027 출제범위 사전예고](https://www.fsc.go.kr/no010104/86803)는 특정315판본의 최종 지정으로 취급하지 않는다.

공식 PDF는 pypdf로 추출했고 2열표의 추출 순서는 보존했다. 출처는 cpa_uploader/data/official/kga315-330-2025-review06.txt에 연결했다. source_ref 및 requirement 인용을 실제 추출문과 대조하고 SHA-256을 재계산했다. 정확한 문단·페이지·URL·판본 비교는 [06.json](../../../../../cpa_uploader/analysis/reviews/question-review-2027/06.json)과 기준대장에 있다. 기존 검수·게시 상태는 승급하지 않았고 과거 메모 뒤에 후속 검토 사실을 덧붙였다.

## 채점·화면 검증

- 기본50개 물음-답안 조합(완전정답/표현변형/핵심누락/반대/빈답안), 은행 모범답안10개, 추가61개 대상 답안. 세트 단위91개 모의 응답 사례 모두 기대와 일치.
- 28criterion 각각의 정답·누락·반대 판정과 partial불허 경계를 확인했다. 별도 경계58건은 정수 합산, 부분점수 차단, 보안플래그, 허위·교차물음 인용을 검증했다. 전부 빈 답안5세트는 모델0회·0점.
- 현재 기능 설정 gpt-5.6-luna로 **실제86회**, raw판정·인용과 최종판정·점수 불일치0건, 호출오류0건. 불일치가 없어 재측정 대상 없음. 실제 응답모델 gpt-5.6-luna. 토큰 사용 입력156315,출력29771. 영구 무오류를 의미하지 않는다.
- 독립 명제 동일 인용, 정상 명칭만 나열, 역순+무관한 추가 문장, 같은 사실 반복도 실측했다. 실제 모델 판정과 코드 보정 후 결과를 별도 기록했다.
- typecheck, questions:v3:validate 통과. 관련7파일37테스트 통과. 당시 전체은행96세트·192물음·503criterion·501점. 중간의 출처표시/공개본 불일치는 수정 후 해소했다.
- compile 성공, 공개본 일치·암호화본 복호화 일치·비공개 source_quote/requirements/criteria/model_answer 비노출 확인. 06 허용 기준목록에 실제 연결되는330을 추가했다.
- 실제 QuizClient+globals.css를 데스크톱1440/모바일390에서5세트 전수 확인. 총20개 문제·결과 화면 캡처 및 연락판 시각검토. 문구·답안ID·결과귀속·줄바꿈·수평넘침 없음. 제출 action과 인증은 합성 어댑터이므로 운영 E2E라고 부르지 않는다.

## 연계 주제

02의 감사위험·적발위험과06의 고유위험 평가를 구별했다. 04-003/sub2의315위험평가절차와330추가감사절차 구분에 모순이 없다. 07-002/sub1·07-004/sub1의 통제테스트 조건과06-005/sub2가 연결되며,06은 식별 이유·대응 연결,07은 두 조건 열거라는 학습목표를 유지한다.07내 두 물음의 높은 중복도는07 검토사항이다.08-001/sub1의 일반적 증거 관련성·신뢰성과06-002/sub2의 과거 정보 당기 재사용 판단은 적용맥락이 다르다. 미검토 주제의 내용 적합을 승인한 것은 아니다.

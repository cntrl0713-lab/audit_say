`all`은 모든 criterion의 점수를 합산하는 계약이고, `max_entries`/`overflow_policy`는 답안 중 어떤 항목을 채점할지를 정한다. 둘을 구별해야 한다. 01-003/sub1은 네 가지 사항을 모두 쓰는 `all` 문제이면서, 제출한 앞4개 항목만 채점하도록 설정돼 있다. 따라서 C02는 ‘여러 정답 중 N개 선택’ 문제에만 발생하는 결함이 아니다.

현재 `best_n`은 11-003/sub1 한 물음에 있고 `at_least_n`은 없다. 이들의 의미 채점은 이번 주제01 실행 대상이 아니다. `best_n` 점수 합산의 기존 단위 테스트 통과를 선택형 열거 전체 동작의 보증으로 보지 않는다.

추가 관찰:

- 실제 서버 액션을 격리하여, 소속되지 않은 물음 ID 거절 전에 한도를 소비하는 동작, 진도 저장 실패를 반환 성공과 구별하지 않는 동작, 반복 제출 때마다 진도를 호출하는 동작을 확인했다.
- 경험치의 반복 가산 정책은 사용자 질문에 대한 답변 대기다. 운영 DB의 동시성·권한·RPC·실제 인증은 검증하지 않았다.
- 서비스의45초×최대3회와 라우트 실행상한60초의 조합은 배포환경 시간초과 검증이 필요하다. 이번31회 실제 모델 호출에는 전송 오류가 없었다.
- 정본·공개본·암호화본은 전체 일치했다. public에는 model_answer·criteria·requirements·source_quote가 노출되지 않았다.

공통 코드를 수정할 때에는 영향받는 ID를 현재 은행에서 다시 추출하고, 주제별 검토 완료 사례를 재실행한다. 정답 내용 판정과 코드 합산·증거 검증·화면 결과를 구분해 기록한다.

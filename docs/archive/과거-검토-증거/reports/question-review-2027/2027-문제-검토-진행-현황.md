[주제01–03 수정 결정](../../../../plans/주제-01-03-검토에-따른-수정-결정.md)에 문항별 수정, 전체 열거 정책 변경, 공통 채점·화면·경험치 처리와 검증 순서를 정리했다. 아래 실측과 각 보고서는 변경 전 계약의 기록이다. 특히 초과 항목 득점 사례를 낮은 점수로 되돌리는 과거 수정 제안은 새 모두 작성 정책으로 대체한다. 제품 코드·문제은행에 수정 결정을 아직 적용하지 않았다.

[공통 코드 이슈](./공통-코드-검토-장부.md)와 [기준대장](../../../../../cpa_uploader/analysis/reviews/question-review-2027/standards-register.json)은 현재 주제01·02의 확인 결과를 포함한다.

# 2027 대비 문항 검토 보고서

> 이 문서는 당시 검토·설계의 기록입니다. 최신 요구사항·빈도·문항 상태는 [통합 현황](../../../../../cpa_uploader/wiki/_meta/authoring-dashboard.md)을 확인하세요. 과거 수치·판정·실행 결과는 해당 시점의 근거로 보존합니다.

이 폴더에는 사람이 읽는 주제별 보고서, 판단 근거, 당시 공백 분석과 제작안을 보존한다. [전체 결과](./2027-문제-검토-진행-현황.md)에서 탐색한다.

기계 판독 장부·채점 실행 결과·외부 원자료는 [`analysis/reviews/question-review-2027`](../../../../../cpa_uploader/analysis/reviews/question-review-2027/README.md)로 이전했다. 파일 내용과 당시 판정은 바꾸지 않았으며 [이전 장부](../../../../../cpa_uploader/analysis/reviews/question-review-2027/migration-manifest.json)에 구 경로와 현재 경로, 원래 SHA-256이 있다. 보고서의 실제 파일 링크는 새 위치로 연결한다.

과거 실행 명령·JSON에 내장된 경로는 이력으로 남을 수 있다. 과거 보고서의 `완료`와 [공백 지도](./출제-공백-지도-위키-기준-2026-09-08.md)는 당시 범위·방법에 대한 결과이며 현재 문제은행이나 최신 빈도를 자동으로 반영하지 않는다. 현재 대응·공백·제작 상태는 [`analysis/coverage`](../../../../../cpa_uploader/analysis/coverage)에서 확인한다.

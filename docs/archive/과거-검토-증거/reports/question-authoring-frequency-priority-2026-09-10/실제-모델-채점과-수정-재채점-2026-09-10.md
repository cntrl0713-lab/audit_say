# 실제 모델 채점과 수정·재채점 — 2026-09-10

6세트·12물음·37점의 실제 채점을 수행했다. 현재 초안의 기본 121사례 모두에 실측 결과가 있으며, 기본 모델 `gpt-5.6-luna`에서 **119사례는 현재 입력의 모든 실행이 일치, 1사례는 반복 불일치, 1사례는 판정 변동**이다. 저장 모범답안 12개는 모두 해당 물음의 만점을 받았다. 잔여 오류 때문에 검증 완료·게시 가능으로 판정하지 않는다.

## 실행 범위

- 앱의 실제 `gradeQuestionSetV3`를 사용하여 원시 criterion 판정, 답안 인용 검증, 보안 보정, 최종 점수를 보존했다. 작성자 기대값을 모델 출력 대신 주입하지 않았다.
- 최초 121사례 중 112사례가 기대 판정과 일치했고 9사례에서 차이가 있었다. 불일치 9사례를 같은 설정으로 총 3회씩 확인했다. 수정 후 영향받는 후속사건·계속기업의 43사례, 기대값 또는 답안을 명료화한 경계 3사례를 다시 실행했다. 새 버전의 보안 오탐 1사례도 총 3회 확인했다.
- 실제 채점 경로 실행은 **188건**이다. 이 중 모델 호출이 필요한 답안은 **171건**(기본 모델 170건, 비교 모델 `gpt-5.6-sol` 1건), 빈 답안의 모델 미호출 경로는 **17건**이다. 별도의 인용 프롬프트 진단 호출 1건과 내용 검토 호출은 이 수치에 더하지 않았다.
- 현재 입력의 요청·스키마·코드·모델·답안과 일치하는 실측만 현재 사례 집계에 사용했다. 입력이 바뀐 과거 실측과 최신 성공만 골라 낸 결과를 섞지 않았다. 과거 실패도 함께 보여 준다.
- 모델명은 요청한 설정값이다. 공용 호출기가 실제 응답 모델명·응답 ID·토큰 사용량을 반환하지 않아 이 정보는 미보관이다. 키와 실제 사용자의 답안은 기록하지 않았다.

문제의 요구 범위와 37점 배점은 유지했다. 수정 전 문항·기대표·작성 본문과 실측은 [최초 입력 스냅샷](../../../../../cpa_uploader/drafts/frequency-priority-2026-09-10/live-grading/r1/input-snapshot.json)에 보존했다. 변경된 3개 요소↔물음 관계는 원문과 새 criterion을 대조하여 [재확인 기록](../../../../../cpa_uploader/drafts/frequency-priority-2026-09-10/coverage-reassessment.json)을 남겼으며 검토 대기 상태를 유지했다.

## 남은 두 사례

1. **재고실사 q2 동의 표현 — 반복 인용 오류.** 정상 답안의 “통제가”를 모델이 “통수가”로 바꿔 인용했다. 의미 판정은 모두 met이지만 원문 인용 검증에 실패하여 기대 4점이 3점이 된다. 같은 설정으로 3회 재현됐다. 인용의 글자 일치를 강조한 별도 진단 프롬프트도 해결하지 못했다. 비교 모델 `gpt-5.6-sol`의 동일 답안 1회는 4점이었으나, 이를 기본 모델의 해결이나 전체 문제에 대한 대체 모델 검증으로 간주하지 않는다. 정상 답안을 바꾸거나 인용 검증을 완화하지 않았다.
2. **후속사건 q1 조건 경계 — 보안 오탐 변동.** “경영진의 일부 수정은 허용되지만 승인권자는 전체를 재승인해야 해도 두 조건을 충족한 것으로 처리한다”는 잘못된 감사 판단 답안이다. 독립적으로 맞은 수정 허용 부분의 기대 점수는 1점이다. 수정된 criterion에서 원시 판정은 이를 맞게 식별했지만 1회는 채점 조작 지시로 오인하여 0점으로 보정했고, 이후 2회는 정상적으로 1점을 주었다. 실패 1회를 제외하지 않고 변동 사례로 남긴다.

두 사례는 정상 답안을 손질하거나 기대 점수를 낮출 문제가 아니다. 기본 모델의 정확한 인용 반환과 감사 판단/평가자 지시의 구분을 개선한 뒤 동일 반례 및 관련 정상 답안을 다시 확인해야 한다. 공통 채점 엔진·기본 모델 설정·운영 배포는 이번에 변경하지 않았다.

## 의미검수 및 게시 상태

정식 `review_question_draft_v3.ts`도 시도했다. 첫 시도는 검토 모델 설정 부재로 호출 전에 종료됐고, 기본 채점 모델을 지정한 실행은 필수 검수 단위·사례·인용 경로 누락으로 차단됐다. `gpt-5.6-sol` 재시도는 API 전송 오류로 완료하지 못했다. 유효한 정식 의미검수 receipt가 생성되었다고 주장하지 않는다.

추가로 모든 37 criterion의 간결한 모델 내용 검토 의견을 확보했으나 인용의 줄바꿈 생략 등 원문 일치 오류가 있어 정식 증거를 대체하지 않는다. 중요성 A6의 이유는 공식 예시를 주어진 일시적 변동 사실에 적용한 추론임을 구분했다. 조회 문제의 기존 09-007과 중복된다는 모델 의견은 기존 발문이 **대체절차로 필요한 증거를 얻을 수 있는 상황**을 명시하고 있어 채택하지 않았다. 새 문제는 회신 자체가 필수인 505.13의 예외를 묻는다.

초안은 `needs_review` / `needs_human_review`로 유지한다. 사람 승인·정본 편입·공개본 생성·운영 DB 배포는 수행하지 않았다.

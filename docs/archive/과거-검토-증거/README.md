# 과거 검토 증거

현재 운영 문서와 구분하기 위한 과거 검토·제작 기록 보관소다. 문서의 내용·판정·당시 수치는 변경하지 않고, 현재 진입점에서 사용하는 링크만 이 보관 위치로 연결한다.

## 보관 범위

- 2027 대비 전수 검토의 초기 계획과 주제별 보고서
- 빈도·출제 공백 기반의 이전 제작 문제지와 검증 결과
- 주제별 제작 검토의 이전 버전(v1·v2·배점 정책 v1)
- 현재 계획으로 대체된 배점 검토 초안

기계 판독 실행 증거와 원시 응답은 기존 소유권에 따라 `cpa_uploader/analysis/reviews/`와 `cpa_uploader/drafts/`에 그대로 둔다. 이 보관소에는 사람이 읽는 문서만 이동한다.

각 문서는 당시 상태의 기록이므로 현재 문제은행·검토 상태·시험 적용 판본을 확정하는 최신 자료로 사용하지 않는다. 현재 상태는 `cpa_uploader/wiki/_meta/authoring-dashboard.md`에서 확인한다.

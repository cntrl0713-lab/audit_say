# T08-C 물음 분할과 기준서형·사례형 분리

사용자 확정 기준은 **주어진 사실관계와 연계해 답해야 하면 사례형, 기준서만으로 답할 수 있으면 기준서형**이다. 사실관계가 있는 학습 문제에는 사례형 물음만 배치하고 기준서형은 지문 없는 별도 문제로 구성했다.

T08-C의 기존 물음2(17점)를 업무 이해·발견사항/결론 평가 8점과 가정·방법·사용자료 검토 9점으로 분리했다. 기존 criterion ID와 정답 명제는 그대로이며 새 물음 ID는 sub4다. 원본의 sub3 불일치 대응은 유지했다. 원 세트 총점은 22점이고, 학습 화면에서는 사례형 1물음·3점과 기준서형 3물음·19점으로 별도 구성한다.

기존 49세트의 물음 수는 131→132이며 총점은 521점이다. 물음별 재분류 결과는 기준서형 **64개**, 사례형 **68개**이며 74개 학습 문제 묶음으로 구성했다. 기준서형 중 사례를 가리키던 표현은 25세트·35발문에서 독립적으로 읽히도록 정리했다. 특정 초안·대상·날짜·팀원 제안을 해석해야 하는 요구는 사례형으로 남겼다.

실제 모델 의미검수·채점은 이번 변경에 대해 실행하지 않았다. 이전 HTTP429 이후의 API 중지 상태를 유지하며, 과거 receipt를 새 발문·구조에 승계하지 않는다. 재개에는 현재 입력과 코드로 새 실행 잠금·출력 경로가 필요하다. 정본 편입·게시·배포는 수행하지 않았다.

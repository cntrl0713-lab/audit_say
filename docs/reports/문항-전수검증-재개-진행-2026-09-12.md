[소량의 가용성 진단](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/api-availability-v1/result.json)은 Luna 입력 9·출력 5토큰으로 성공했다. 잔액 소진으로 단정하지 않으며 A의 중단 세트만 새 출력에서 단일 스트림으로 재개한다. 의미검수의 내용 미통과는 별도로 모으며 API 실행 중 은행·계획·출처·공통 코드를 수정하지 않는다. 나머지 생성사례 채점·작성자 QA 및 비빈 학습 단위 249개 실측은 후속 단계다.

### 이전 실행과 후속 결정

resume-003의 선행 실행은 종료했다. A는 같은 실제 요청·응답을 확인한 의미검수 11단위를 연결했고, 새 채점기 생성 사례 39/39 및 작성자 QA 35/35가 통과했다. B는 의미검수 11단위와 작성자 QA 35/35가 통과했으나 생성 사례 39개 중 2개가 불일치했다. C는 작성자 QA 22/22가 통과했지만 의미검수 8단위 중 직접 출처 지지와 중복 관계에 미통과가 있어 생성 사례 채점을 시작하지 않았다. 작성자 QA 합계 92/92 최초 일치와 의미검수·생성사례 미통과를 구분한다.

B의 원답안을 각각 총 3회 관측했다. “감사 중 식별된 … 지배기구에 서면으로 커뮤니케이션”을 적시에 전달한 것으로 읽은 과다 인정은 3/3 재현되어 원 기대 2점을 유지한다. “미비점 자체의 내역은 제시하지 않는다”는 명시적 반대이므로 생성된 omission/not_met 기대가 잘못되었다. 독립적으로 맞힌 잠재 영향 1점은 유지한다. [B 후속 조사](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/execution-resumes/resume-2026-09-12-v3/canary/grading-b/pilot-05-003/investigation-v1/README.md)에 원문·관측·근거를 보존했다.

C의 실제 source_excerpts에는 A11이 가리키는 KGA 210.6(b)의 책임 범주가 직접 포함되지 않았다. 이미 보관된 공식 원문의 6(b)(i)–(iii), L325–343을 source_ref로 추가한 [후보 v8](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/c/prepared-reviewed-v8/README.md)을 별도로 준비했다. 문항·답안·criterion·배점은 유지하고 세 criterion의 직접 출처 연결만 보강했다. 03-006의 사례 적용과 03-001의 일반 고려사항은 부분 관계로 명시했다. 은행 해시가 바뀌므로 옛 의미검수 해시를 갱신하지 않고 새 검수 실행을 준비한다.

채점 지침·중립 누락 사례 생성 지침과 후속 QA를 보완하고 관련 회귀 39/39를 통과했다. 그러나 runtime-v7의 Luna 실제 진단 5회 중 시점 누락 답안 3회가 모두 과다 인정됐다. A의 해지 조치 누락과 B의 목적 배제 누락은 각 1회 통과했고, 계획한 잔여 4회는 중단해 미실행으로 남겼다. [5관측 원시 검증](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/c/resume-review-2026-09-12/semantic-case-contract-proposal-v1/early-regression-results.json).

같은 시점 누락 원답안을 Terra와 Sol로 각각 실제 채점하여 둘 다 최초 관측에서 기대 2점과 일치했다. Terra의 선행 QA 94개도 모두 첫 관측에서 일치했다(비빈 실제 응답 88개·빈 답안 6개). 이 비교 진단은 종료했고, 사용자가 Luna 유지를 명시하여 모델 전환 및 현행 실측으로의 승계는 하지 않는다. 추가 입력 구조 실험도 API 호출 전에 보류했다.

resume-004에서 119세트 전체 의미검수·생성사례 채점·작성자 QA와 학습 단위 249개 모범답안 채점을 진행한다. 허용된 ±1점 편차를 없애기 위한 추가 진단 반복은 하지 않고 다음 문항으로 이어간다. 완전한 물음별 기대점수를 확인할 수 없는 생성 사례는 근거를 대조해 비교 가능성을 먼저 확인한다. 작성자 QA 실행기에 내장된 반복이 실행된 경우 실제 관측 수에 그대로 남긴다. 새로운 원문·정답·출처 오류는 모아 후속 수정하며 API 실측 중 동결 입력을 고치지 않는다.

현재 실행 결과는 [resume-004 canary 폴더](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/execution-resumes/resume-2026-09-12-v4/canary/)와 [resume-004 remaining 폴더](../../cpa_uploader/analysis/reviews/point-review-and-publication-2026-09-11/execution-resumes/resume-2026-09-12-v4/remaining/)의 worker별 `run.json`, 세트별 `summary.json`, 최종 `summary.json`, receipt·원시 로그로 확인한다. 전송 후속 재개는 기존 폴더를 덮어쓰지 않고 별도 manifest와 출력으로 연결한다. 최종 summary가 없는 착수 기록과 부분 응답을 완료로 계산하지 않는다.

사용자의 편차 허용 결정 전에는 불일치를 같은 원답안과 조건으로 총 3회 관측했다. 현재는 근거상 물음당 편차가 ±1점 이내임을 확인하면 그 오차를 없애려는 추가 호출을 하지 않는다. 고정된 작성자 QA 실행기에 내장된 반복은 실제 발생한 관측으로 보존하며, 마지막 성공으로 이전 불일치를 지우거나 모델에 맞춰 기대값을 바꾸지 않는다.

사람의 실제 확인, 정본 승급, 게시·컴파일, 운영 DB 반영은 아직 수행하지 않았다. 모든 필수 검증과 근거를 갖춘 후 앞서 승인된 범위로 진행한다.

## 부분정답과 분리·통합

독립적으로 인정할 수 있는 의미마다 1점을 부여하여 충족한 기준을 합산한다. 같은 뜻이나 대안 표현을 중복 배점하지 않고, 0.5점으로 쪼개지 않는다. 판단·근거는 독립 기준으로 평가하며 답안의 근거가 결론을 분명히 함축하면 판단도 인정한다.

- 거래·사건의 경영진주장: 12점 한 물음을 6·6·3·4점의 네 물음으로 분리했다. 명칭과 정의를 구별하고 정의 일부의 독립 부분정답을 인정한다.
- 감사인측 전문가 업무 평가: 10점을 발견사항·결론 3점, 가정·방법 4점, 원천데이터 3점으로 분리했다.
- 기타정보 단락의 구성요소: 10점을 두 개의 5점 물음으로 분리했다.
- 남은 1점 물음 네 개는 단일 개념·원칙 자체를 묻는 경우로 유지했다.

## 실제 채점과 수정

Luna로 총 582회 호출했다. 최초 576개 답안 중 575개가 ±1점 이내였고, 검수 계승이 불가능한 잔존 물음의 추가 3개 답안도 정확히 일치했다.

IT 응용프로그램·기타 IT 환경 식별의 부분답안은 기대 2점인데 최초 0점이 나왔다. 기준서·발문·답안과 실행 당시 규칙을 다시 대조하여 발문의 전제 반복을 요구한 과소채점으로 판단했다. 원 답안과 기대 2점을 보존하고, 해당 물음의 전제와 두 criterion의 허용 범위를 명확히 했다. 후속 실측은 모범 4점·부분 2점·오답 0점이 모두 정확히 일치했다.

최종 판본에 연결한 대표답안 579개는 모두 ±1점 이내이며 567개가 정확히 일치했다. 최초 실패를 포함한 전체 582관측 중 581개가 ±1점 이내이다. 원 실패·원 기대값·원 응답과 사용량은 삭제하지 않았다. 이는 관측된 채점 일관성이며 모든 가능한 답안의 정확도나 통계적 신뢰수준을 뜻하지 않는다.

193세트는 이번 실제 검토·대표 채점 근거를 사용하고, 삭제 후 내용이 그대로 남은 50세트는 원 승인·분류·답안·채점 입력의 동일성을 검증해 근거를 계승했다. 새 모델 의미검수 API나 사람의 대리 검수로 기록하지 않았다.

## 운영 전달과 코드 검증

실제 운영 DB의 19세트·44개 범위 조건을 비공개 문항 조회 → 학습 물음 → 채점 입력까지 대조했다. 기존 12개 테이블의 역사행 보존 검사와 승인된 55세트의 정확한 비활성화 검사를 통과했다. 분석·보존·wiki 생성/검사도 통과했다.

전체 코드 검사 최초 실행은 592개 중 591개 통과·1개 실패였다. 실패는 기존 사례 문항의 검수 보조 분석 파일이 재생성된 문제로, 당시 실행에 함께 봉인된 수집 기록과 동일 해시 보존본을 확인하는 경로를 추가했다. 실제 문항 출처·답안·실측 입력의 현재 검증은 유지했다. 후속 표적 회귀 62개가 통과했으며 전체 테스트를 다시 실행한 결과는 아니다. 원 실패 로그와 후속 회귀 결과는 작업 장부에 각각 보존했다. 삭제 계승 회귀 9개와 퇴역 DB 회귀 2개, 타입·대상 lint 검사도 통과했다.

실제 반환 사용량에 고정 단가를 적용한 전체 호출 비용 추정은 약 $0.601853이다. 청구서 확정액과 구별하며 원 응답의 입력·캐시·출력 토큰과 요청 식별자는 각 실행에서 확인할 수 있다.

## 수정 문안과 영향

### 03-D01 · P2 · 001/sub1의 요구 범위

현재 ‘경영진으로부터 확인받아야 하는 전제조건의 핵심 내용’은 재무보고체계 수용가능성까지 포함하는 전제조건 전체로도 읽힌다. criterion은 경영진 책임 세 범주와 수임 거절만 평가한다.

제안: **“감사업무 수임 전에 경영진으로부터 동의를 받아야 하는 경영진 책임의 세 가지 범주를 기술하시오. 경영진이 그 책임을 인정하지 않을 때의 수임 여부와 법규상 예외도 설명하시오.”**

기존 4점 구조를 유지하는 수정안으로 정리했다. 이는 검토 중 제시한 기본안이며 사용자 확정으로 기록하지 않는다. 전제조건 전체로 확대하려면 004/sub1과의 중복 및 배점을 함께 재설계해야 한다.

A11 요약뿐 아니라 6(b)를 직접 근거로 보강한다. 세 범주는 해당 체계에 따른 재무제표 작성(해당 시 공정표시 포함), 중요한 왜곡표시가 없는 재무제표 작성에 필요한 내부통제, 정보·추가정보와 기업 내부 관계자에 대한 제한 없는 접근의 제공이다. **현재 핵심 세 범주 계약에 새로운 하위 배점을 만들지 않는다.** A14의 강제수임 시 경영진에게 중요성과 보고서 영향을 설명하는 내용도 후속 해설로 구별한다.

### 03-D02 · P2 · 002/sub1의 판단 근거 요구

현재 발문은 ‘수임 여부를 판단하고 예외를 설명’하도록 하지만 crit1은 주어진 범위제한→의견거절 예상 사실의 재진술에 1점을 부여한다.

제안: **“감사업무 수임 전에 경영진 또는 지배기구가 업무범위를 제한하여 재무제표에 대한 의견거절이 예상된다. 해당 업무의 수임 여부를 판단하고, 판단 근거와 법규상 예외를 설명하시오.”**

근거 1점과 법규 예외를 포함한 결론 1점을 유지한다. 결론만 / 근거만 / 결론은 맞고 근거가 반대인 답안은 각각 기대 1점과 일치했다.

### 03-S01·S02 · P2 · 004의 출처와 검수 상태

- src1/req1은 문단 6의 도입문만 담았다. 하위 (a)(b)와 책임 내용을 포함하도록 연결한다.
- src4/req2는 문단 8의 도입문만 담아 두 금지 사유와 19 예외를 직접 뒷받침하지 못한다. 8(a)(b)를 포함하고 19의 source를 추가해 crit3와 연결한다. crit3의 critical_facts에도 claim에 있는 19 예외를 명시한다.
- 004의 source_refs 4개 모두 저장된 content_hash가 인용의 실제 SHA-256과 다르다. 다른 세트의 7개 hash는 일치한다. 보강된 최종 인용의 hash를 재계산한다.
- review_status=verified와 ‘게시 전 사람 의미 검수 필요’라는 notes가 혼재한다. 검수 상태를 실제 완료 범위에 맞춰 정리한다.

출처 추적과 계약 일치를 위한 수정으로 배점 변화는 없다. 정본 수정 시 공개 변환·암호화본도 재생성해야 한다.

## 화면·연계 주제

실제 QuizClient.tsx와 globals.css를 사용하고 인증·서버 액션은 합성 어댑터로 격리했다. 네 세트 × 1440/390px에서 풀이·결과 **16장**을 저장해 화면과 DOM을 확인했다. 전 발문·모범답안, sub1/sub2 슬롯, set ID, 답안 줄바꿈, 물음별 결과가 일치하고 가로 넘침이나 겹침은 없었다. 실패 후 답안 보존과 다시 풀기 초기화도 확인했다. 초과 항목 안내가 없고 빈 답안은 HTML required로 막히는 차이를 기록했다. 버튼·결과·오류 안내에서 추가 오탈자는 발견하지 못했다.

운영 로그인·Next 라우팅·Supabase 저장을 연결한 E2E는 미실행이다. UI 결과 데이터는 모의 채점 결과이며 실모델 평가와 구분한다. [화면 검사](grading-cases/03-ui-results.json), [모바일 모음](grading-cases/03-contact-390.png), [데스크톱 모음](grading-cases/03-contact-1440.png)을 남겼다.

주제 01의 수임 후 정보 보고·역량은 감사인 측 책임, 210은 기업 측 전제와 합의다. 주제 09의 수행 중 조회 거부·입회 불능은 대체절차와 보고 대응으로 수임 전 거절과 구별된다. 주제 15의 의견거절은 증거 미입수 영향의 중요성·전반성이 조건이고 03-002/sub1은 그 의견거절 예상이 이미 주어진 경우다. 직접 모순은 발견하지 못했으며 연계 주제 전체 검토 완료를 의미하지 않는다.

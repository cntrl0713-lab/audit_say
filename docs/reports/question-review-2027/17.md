# 주제17 내부회계관리제도 검토·수정 결과

2026-09-08. **4세트·8물음의 원래 24criterion을 전수 검토하고 최종 26criterion·26점으로 수정했다.** 정본·공개본·암호화본, wiki와 검토 스킬을 갱신했다. 검토 기록 완료와 2027 시험 사용 적합은 구별한다. 최종 시험 판본 및 회사별 적용 법규의 일부 현행성은 미확정이다.

## 공식 기준과 적용 범위

[한국공인회계사회 2025 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11762493343340&fileSeq=7&subId=sub06)의 KGA1100.4는 2026-01-01 이후 개시 보고기간부터 적용하며, 법규상 회사별 시행시기가 다르면 법규를 따른다. 89·A6·A7·A111은 기업의 평가·보고 기준 적용기간에 따른다는 예외가 있다. [2026년 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06)과 직접 관련 17페이지를 비교했다. 16페이지는 공백·쪽수 제외 동일하며, 나머지 867/894쪽도 문단68의 KGA250 제목 변경만 있다. 대상 정답 명제 변경은 없다.

웹 도구가 공식 첨부의 octet-stream을 열지 못해 기존 공식 다운로드 PDF의 SHA-256을 확인하고 pypdf로 추출했다. 869쪽 원본 이미지를 직접 확인했다. 출처의 판본·쪽·문단·해시와 비교 결과는 [출처 장부](grading-cases/17-source-comparison.json), 실제 인용은 [공식 추출문](../../../cpa_uploader/data/official/kga1100-2025-review17.txt)에 있다. 페이지 표시가 삽입된 추출 파일에 대한 문자 일치이며 원 PDF의 서식을 재현했다는 뜻은 아니다. 9의 잘못된 교차참조 8(a)(iii)는 원문 그대로 보존하고 실제 전제조건은7(a)(iii)에 있음을 확인했다. 검수 상태를 승급하지 않았다.

법규 확인은 다음과 같이 구별했다.

- [금융위 2024-12-06 자료](https://www.fsc.go.kr/no010101/83522?curPage=64&srchBeginDt=&srchCtgry=&srchEndDt=&srchKey=sj&srchText=)는 자산1천억원 미만 상장사의 감사 면제·검토 유지가 2023-01 법 개정사항임을 확인한다. 1천억원 미만과 이상을 같은 범위로 쓰지 않는다.
- [금융위 2023-12-13 시행령 의결 자료](https://www.fsc.go.kr/no010101/81242)는 2조원 미만 상장사의 연결 도입을 5년 연기한 시행령이 2023-12-19 시행됨을 확인한다. [2023 보완방안](https://www.fsc.go.kr/no040101?cnId=1750&curPage=219&pastPage=219&srchKey=&srchText=)의 2조원 이상 기업에 대한 신청별 최대2년 유예와 2조원 미만 기업의 유예를 구별한다.
- 신규 상장사 자산1천억~5천억원의 3년 유예, 연결 의견으로 별도 의견을 대체하는 방안은 2023 발표만으로 현행 시행으로 확정하지 않았다. 2023-12 의결 자료에도 당시 법 개정 검토 중으로 표시된다. 이번 법령정보센터 현행 조문 열람은 실패하여 **2026년 현재 시행 여부·세부 유예 요건과 비상장사 규모별 면제, 연결 규모 구간별 정확한 최초연도는 미확정**으로 남긴다.

현재 8물음은 회사의 법정 의무 적용 여부를 판단하는 사례가 아니며 KGA1100에 따른 감사가 수행되는 상황을 전제한다. 규모·연도·신규상장 여부를 숨은 득점 조건으로 만들지 않았다. 그런 조건을 추가하는 신규 출제는 이번 수정에 포함하지 않았다. 2027년은 2026 시행 기준 동일 적용 가정을 유지한다.

## 채점·화면 검증

기본40개 물음-답안 조합, 저장 모범답안, criterion별 누락·정답·반대, 한 문장에 여러 독립 명제, 역순·추가문장·반복, 시점·보고주체 교환을 실행했다. 최초81개 모의 응답 사례는 모두 코드 기대와 일치했다. 전체 빈 답안은 모델 무호출이며 1점criterion의 partial 불허, 허위·물음 간 인용 차단, 합산·상한·salad와 injection 차등 처리도 확인했다.

**실제 모델 호출은 중간 수정·재측정을 포함해186회**, 호출 오류0회, 입력431,688/출력71,979토큰이다. 현행 기능 설정과 실제 응답 모델은 모두 gpt-5.6-luna였다. 최종001 중심 검증(v4)28회 및002 검증(v5)22회는 판정·인용·점수 불일치0회이고, 수정된 축약 명칭2사례와 독립 영향 평가1사례는 최종 계약에서 각각3회 통과했다. 변경 없는003/004의 유효한 이전 호출까지 포함한92개 raw응답은 최종 프롬프트 입력 해시가 같고 현재 코드 재처리 결과도 동일함을 확인했다. 최종 유효 계약의 점수 불일치는0회이며,004의 분류 불안정2회는 아래에 별도 기록했다. 재처리92건은 새로운 모델 호출로 집계하지 않는다.

실측에서 ‘제목, 수신인, 의견, 근거, 책임, 정의, 한계’ 답안은 모호한 ‘책임’ 두 요소를 제외한5점이 기대값인데 최초3회 모두2점이었다. 모델이 발문으로 특정된 대상의 수식어 생략까지 감점한 원인이다. 공통 수식어 생략 허용을 해당 criterion에 명시하고001세트 전체 사례와 추가 경계를 새로 실측했다. 후속 측정에서 책임 주체를 제대로 적은 짧은 명칭과 쉼표로 구별한 정의·한계를 감점하는 사례도 있어 두 허용 범위를 명시했다. 각 중간 계약·원래 로그를 보존하고 최종 계약은17-v4에 분리했다. 기대값을 모델의 낮은 점수에 맞추어 낮추지 않았다.

구두로 보고한 정보에 대한 서면 보고를 생략해도 된다는 반례는 총3회 모두0점이나, contradicted 대신 not_met을 반환하는 분류 불안정성이 남았다. 오득점은 없지만 판정까지 전부 일치했다고 기록하지 않는다.

보완통제의 영향을 평가한다고 썼으나 운영효과성 테스트는 생략하겠다는 추가 반례에서도, 테스트 오류가 독립된 영향 평가 점수까지 없애는1회 불일치가 있었다. 최초3회0/1/1점으로 확인하고 영향 평가criterion에 독립 판정 계약을 명시했다.002세트와 해당 반례를17-v5에서 새로 측정했으며 이전 낮은 점수를 정상 기대값으로 바꾸지 않았다.

- 타입 검사 통과, 관련 테스트41개 통과. 최종 은행 검증은96세트·192물음·521criterion·521점으로 통과했다. 은행 전체 수치에는 다른 주제의 동시 수정이 포함되며 주제17은26점이다. 작업 중 다른 주제 변경에 따른 실패와 최종 통과를 구별한다.

## 연계 주제와 문서

05의265 유의적 미비점 서면 보고는 재무제표감사의 요구이며1100의 모든 미비점에 대한 경영진 서면 보고와 감사보고서 발행 전이라는 시점을 대체하지 않는다. 06의 설계·실행 평가는 운영효과성 테스트와 구별한다. 07의 이중목적 테스트는 통제테스트와 세부테스트의 동시 수행으로,1100의 두 감사목적과 동일하지 않다. 15의 재무제표 보고서·보고서일과1100.69/71을 대조했고,16의 기타정보·강조사항/기타사항을1100 보고서 요소로 추가하지 않았다. 다른 주제의 전수 내용 검토를 완료한 것으로 집계하지 않는다.

wiki question-design에 주제17 범위·시점·예외를 추가하고 현행 빌더로 집계를 갱신했다. 최종 wiki lint는 오류0개이며 question-design 분할 권고1건이 있다. audit-question-review 스킬에는 해당 지침 참조를 추가했고 quick_validate.py는 UTF-8 모드로 통과했다. 기존 스킬 내용과 다른 주제의 병행 수정은 보존했다.

# 주제19 — 기타 인증과 관련서비스 검토·수정 보고서

검토일: 2026-09-08. [계획](../../plans/2027-question-review/19.md) · [전수 장부](19.json).

4세트·8물음·23개 criterion을 검토하고 정본·공개본·암호화본을 수정했다. **총23점 유지**, 모든 criterion은 충족1점/미충족·반대0점이며 partial은 없다. 검토 기록과 로컬 수정·회귀는 완료했다. 국내800·분반기2015 전문과2027 최종 시험 판본의 확인이 남아 있으므로 **2027 시험 사용 적합 확정은 유보**한다.

## 적용 기준과 직접 근거

- [KICPA 인증업무개념체계2022](https://www.kicpa.or.kr/board/list.brd?boardId=acc04):6·8·10·17·26. 인증인의 범위, 증거를 포함한 정의, 비인증 예시 및 다섯 구성요소 대조. 인증업무기준9와 연결해2023-01-01 이후 인증보고서부터 적용되는 판본임을 확인.
- [KICPA 역사적 재무제표 검토업무기준2021](https://www.kicpa.or.kr/board/list.brd?boardId=acc0501):1–2·5–8·13. 2020-12-31 이후 개시 보고기간부터 시행. 해당 기업의 재무제표 감사인이 아닌 검토인의 범위와 제한적 확신·질문/분석·추가절차를 확인.
- [KICPA 합의된 절차 수행업무기준](https://www.kicpa.or.kr/board/list.brd?boardId=acc0701):7, 2006-09-28 개정 전문. 일반 독립성 원칙과 계약 조건·목적 등에 따른 별도 요구, 공정 유지 근거.
- KGA200.18·23: 기존 공식2025 전문 PDF11–12 직접 대조. 특정목적감사의 관련 기준 준수와 예외적 이탈·대체절차의 국내 직접 근거. 주제19 허용 기준 목록에도 KGA200을 추가했다.
- [IRBA 게재 IAASB ISA800 공식문서](https://www.irba.co.za/upload/IAASB-ISA-800-Revised_0.pdf):8–9, PDF6. 수임 세 사항과 모든 관련기준 준수 대조. 국내800 판본 확인으로 주장하지 않는다. 웹 발췌에서 각주번호를 제외했으므로 해당 세트 fidelity는 excerpt로 표시했다.
- [KICPA 분·반기준칙](https://www.kicpa.or.kr/board/list.brd?boardId=acc1401):2014-12-30 원문1·1-1과 [금융위 현행 게시](https://www.fsc.go.kr/po040200/84640)의2015-20/2015-07-01 시행 표기를 구별했다.2015 전문 첨부 다운로드가 HTML을 반환해 본문 대조는 남아 있다.

공식 첨부의 원본·해시·URL·판본·확인일은 [출처 장부](grading-cases/19-sources.json), 실제 발췌는 [출처 문자열](grading-cases/19-source-quotes.json), 각 requirement·criterion 연결은19.json에 있다. 정본 source quote는 공식 추출문을 보존하고 model answer만 자연스러운 문장으로 작성했다. 이전 source hash 불일치 0건은19.json에 보존했으며 현재 인용 해시는 모두 일치한다. 최종 PDF 페이지 번호 정정은 인용·채점 입력을 바꾸지 않았다. 기존 published/verified 표시는 유지했으며 새로운 검수 승급은 하지 않았다.

## 채점 검증

- 기본40개 물음-답안 조합을 포함한 **80개 합성 세트 사례**: 완전정답·변형표현·누락·반대·빈 답안,모범답안,23개 criterion별 누락,동일 인용,역순/무관문장,중복 사실,추가 도메인 반례. [기대표](grading-cases/19-v2-cases.json).
- mock으로80/80 사례 통과,별도47개 코드 경계 통과. 빈 답안4세트 모델 무호출0점,부분점수 미허용,허위·다른 물음 인용 거절,정상 salad 무감점과 injection 감점을 분리했다. [코드 결과](grading-cases/19-v2-offline.json). 이는 모델 의미 판정 실측과 별도다.
- 현행 설정 gpt-5.6-luna, 최초76건+불일치2회 재측정=78회 호출. 001 변형답안 최초1회에서 '재무제표 작성 서비스'를 미인정(4/5점);같은 설정 재측정2회는5점. raw도 not_met이어서 인용 검증·점수 코드 문제가 아닌 모델 의미 판정 불안정이었다. [v1 원로그](grading-cases/19-live.jsonl).
- 공식17에서도 재무제표 작성업무로 표현하므로 동의어 허용을 crit1에 보강. 변경된001의18개 사례+변형답안 추가2회,총20회 재실측 모두 일치했다. 해당 변형답안은 최종 계약에서3/3회5점. [v2 원로그](grading-cases/19-v2-live.jsonl).
- 최종 비어있지 않은 **76개 사례 전체**의 criterion 판정·원문 인용·최종 점수가 기대와 일치한다. 001은v2,002–004는 채점 계약·프롬프트 코드·사례가 동일한v1 실측을 사용하고 raw를 현행 코드로 재처리했다. 이전 실패를 삭제하거나 재처리를 새 모델 호출로 계산하지 않았다. 설정·프롬프트·스키마 요청과 응답은 각 원로그,버전/해시는 메타데이터에 보존했다.

## 화면과 연계 주제

실제 QuizClient와 CSS를 사용해4세트×1440/390폭의 풀이·결과16장 확인. 물음 문구·ID·답안슬롯·결과 귀속·모범답안·가로넘침·다시풀기·실패 시 답안 보존·프로필 갱신 실패 시 결과 보존·5,000자 속성을 검사했다. [UI 결과](grading-cases/19-ui-results.json). action/auth는 mock이며 운영 인증·DB·경험치 E2E 통과를 의미하지 않는다. 최종 동의어 수정은 내부 criterion 문구만 변경하여 공개 발문·답안·결과 형상은 동일하다.

02의 이탈·관련 기준·증거 척도,03의 수임 전제,15의 감사의견,16의 강조사항문단과 대조했다.19-003/sub2와02-002/sub1의 이탈 요건은 의도적 기초개념 반복이며,특정목적 맥락을 이유로 별도 이탈 권한이 있다고 만들지 않았다. 직접근거 재인용은 허용하되 동일 사실의 중복배점은 없다. 각 비교 대상과 판단은19.json을 참조한다.

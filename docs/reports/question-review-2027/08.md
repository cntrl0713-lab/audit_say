# 주제08 감사증거 검토·수정 결과

2026-09-08. **5세트·10물음·27개 채점기준을 전수 검토하고 수정했다. 총27점 유지.** 문항 검토 기록·로컬 채점·화면 검증은 완료했다. 2027년 시험 사용 적합은 최종 시험 판본 미확정으로 보류하며 운영 제출·경험치의 공통 미해결사항도 별도 관리한다.

## 기준과 출처

[한국공인회계사회 2025 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11762493343340&fileSeq=7&subId=sub06)의 KGA500.3은 2026-01-01 이후 개시 보고기간 감사에 적용한다. [2026년7월 개정 전문](https://www.kicpa.or.kr/board/fileMngr?cmd=down&boardId=acc0102&bltnNo=11786004332051&fileSeq=1&subId=sub06)과 대상9페이지를 대조했다. 7페이지는 공백·페이지번호 제외 동일하고, 369/379쪽은 각주에 인용된315·240·250 제목의 차이만 있다. 이번 직접 채점 명제 변경은 없다. [2027 출제범위 사전예고](https://www.fsc.go.kr/no010104/86803)는 확인했으나 특정500 최종 시험 판본 지정으로 보지 않는다. 2027년은2026 시행 기준 동일 적용 가정을 유지한다.

공식 URL의 web 도구 열람은 첨부파일 형식 때문에 실패하여 기존 공식 다운로드 PDF를 SHA-256으로 대조하고 pypdf로 읽었다. 검사·관찰 및 신뢰성 일반화의376/379쪽은 이미지도 확인했다. 실제 인용을 [공식 추출문](../../../cpa_uploader/data/official/kga500-2025-review08.txt)으로 연결하고, requirement·source_ref·인용 해시·문단·쪽을 정합화했다. A35의 예외와 A63/A66/A67의 추출방법 구분을 보존했다. source quote를 윤문하지 않았고 기존 게시·검수 상태를 승급하지 않았다.

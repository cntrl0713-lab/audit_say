# 회계법인 리서치 화면 개선 — 2026-09-08

## 적용 범위

- 감사대상회사 용어 통일, 두 연도 축 표시, 네 탭 파일 분리.
- 공통 DataTable / YearAxis / Basis / Footnote와 주요 지표 타일 위계 적용.
- 공개 집계의 부문별 인원·매출, 순이익, 이사당 직원 수, 이사 보수 노출.
- `v_firm_headcount`와 `v_firm_audit_input` 마이그레이션 및 공개 조회 추가. 두 뷰 모두 `security_invoker=true`, 접수번호 조인, 공개 SELECT 권한 명시.
- 공인회계사·전 임직원·등록회계사는 별도 값과 계열로 유지. 인원 원문 중복 출현 및 단위 배수 이상은 미확보 처리.
- 보수 집계 인원이 5명 미만 또는 미확보이면 평균 보수 미표시.
- 서버 렌더링 SVG 추이·근속 분포와 접이식 원표 추가. 결측은 선을 끊고 복수 기수는 별도 점으로 유지. 수치가 1~2개 보고기간뿐이면 카드로 표시.
- 인쇄 시 접힌 차트 원표도 표시하도록 스타일 추가.

## 검증 근거

- 순수 함수 테스트: 결측/0/단일 점/음수 눈금, 복수 기수 미합산, 세 인원 모집단 분리, 인원 중복과 단위 이상, 보수 5명 경계, 감사 투입 분모.
- PGlite에 실제 삼일 축약 공시를 적재한 뒤 신규 SQL을 실행·재실행. 익명 역할에서 공인회계사 3,073명과 감사 투입 조회 성공, `security_invoker` 확인. 접수번호가 다른 행은 조인에서 제외됨을 확인.
- 로컬 개발 서버의 실제 공개 데이터로 삼일 네 탭 전환, 연도 축 분리, 근속 차트 원표 펼침, 375px 포트폴리오 핵심 열을 확인. 가로 넘침 없음.
- 아크의 2024년 제4기·제5기가 각각 39명/40명 및 21.4억원/36.9억원으로 표시됨을 확인. 포트폴리오 미수집 상태는 0곳으로 표시되지 않음.
- 현대는 현행 제외 정책에 따라 제19기·제21기만 존재하므로, 복수 기수 시각 검증은 아크와 합성 사례로 수행.
- 임시 로컬 검증 화면에서 삼일 fixture의 전 임직원 4,263명·공인회계사 3,073명과 기존 공개 근속표의 등록회계사 2,813명을 동시에 확인. 감사 투입 2,142,905시간 ÷ 2,118명 = 1011.8시간 확인.
- 합성 사례로 결측 연도에서 두 경로로 분리됨, 같은 연도의 별도 점, 보수 집계 4명일 때 평균 타일 0개/총액 유지 확인.
- SVG title의 여러 텍스트 자식으로 발생하던 hydration 오류를 문자열 하나로 합쳐 수정. 수정 후 새 브라우저 탭의 오류·경고 로그 0건. 375px 차트 눈금과 원표 가로 넘침 재확인.
- 임시 검증 라우트는 삭제했으며 배포물에 포함하지 않음.

## 검증 결과 및 남은 확인

최종 검증: `npm run typecheck`, 전체 테스트 190개, `npm run build`, 변경 파일 대상 ESLint 통과. 각 단계 커밋에서도 타입 검사와 전체 테스트를 실행했다.

`npm run lint` 전체 실행은 기존 파일과 임시 사본에서 30 errors / 53 warnings로 실패했다. 주요 기존 오류는 `contexts/AuthContext.tsx`, `lib/supabaseServer.ts`의 explicit-any, `.cache/firm_collector`와 `tmp/*`의 과거 작업 사본이다. 이번 리서치 화면 변경 범위의 lint 오류는 없다.

운영 Supabase에는 마이그레이션을 적용하지 않았다. 운영 연결 개발 화면에서 공인회계사와 감사 투입이 미확보로 보이는 것은 새 뷰 미적용 상태이다. 승인 후 `20260908005001_firm_headcount_and_audit_input_views.sql`을 별도로 적용하고 삼일 보고기간 **2024-07-01 ~ 2025-06-30**에서 신규 지표가 실제로 표시되는지 확인해야 한다. 이는 **2025 결산 공시 / 2024 보고기간 시작연도**이며 두 연도 표기를 혼동하지 않는다.

# 회계법인 리서치 화면 개선 — 2026-09-08

## 적용 범위

- 감사대상회사 용어 통일, 두 연도 축 표시, 네 탭 파일 분리.
- 공통 DataTable / YearAxis / Basis / Footnote와 주요 지표 타일 위계 적용.
- 공개 집계의 부문별 인원·매출, 순이익, 이사당 직원 수, 이사 보수 노출.
- `v_firm_headcount`와 `v_firm_audit_input` 마이그레이션 및 공개 조회 추가. 두 뷰 모두 `security_invoker=true`, 접수번호 조인, 공개 SELECT 권한 명시.
- 공인회계사·전 임직원·등록회계사는 별도 값과 계열로 유지. 인원 원문 중복 출현 및 단위 배수 이상은 미확보 처리.
- 보수 집계 인원이 5명 미만 또는 미확보이면 평균 보수 미표시.
- 서버 렌더링 SVG 추이·근속 분포와 접이식 원표 추가. 결측은 선을 끊고 복수 기수는 별도 점으로 유지. 수치가 1~2개 보고기간뿐이면 카드로 표시.
- 인쇄 시 접힌 차트 원표도 표시하도록 스타일 추가.

## 검증 근거

- 순수 함수 테스트: 결측/0/단일 점/음수 눈금, 복수 기수 미합산, 세 인원 모집단 분리, 인원 중복과 단위 이상, 보수 5명 경계, 감사 투입 분모.
- PGlite에 실제 삼일 축약 공시를 적재한 뒤 신규 SQL을 실행·재실행. 익명 역할에서 공인회계사 3,073명과 감사 투입 조회 성공, `security_invoker` 확인. 접수번호가 다른 행은 조인에서 제외됨을 확인.
- 로컬 개발 서버의 실제 공개 데이터로 삼일 네 탭 전환, 연도 축 분리, 근속 차트 원표 펼침, 375px 포트폴리오 핵심 열을 확인. 가로 넘침 없음.
- 아크의 2024년 제4기·제5기가 각각 39명/40명 및 21.4억원/36.9억원으로 표시됨을 확인. 포트폴리오 미수집 상태는 0곳으로 표시되지 않음.
- 현대는 현행 제외 정책에 따라 제19기·제21기만 존재하므로, 복수 기수 시각 검증은 아크와 합성 사례로 수행.
- 임시 로컬 검증 화면에서 삼일 fixture의 전 임직원 4,263명·공인회계사 3,073명과 기존 공개 근속표의 등록회계사 2,813명을 동시에 확인. 감사 투입 2,142,905시간 ÷ 2,118명 = 1011.8시간 확인.
- 합성 사례로 결측 연도에서 두 경로로 분리됨, 같은 연도의 별도 점, 보수 집계 4명일 때 평균 타일 0개/총액 유지 확인.
- SVG title의 여러 텍스트 자식으로 발생하던 hydration 오류를 문자열 하나로 합쳐 수정. 수정 후 새 브라우저 탭의 오류·경고 로그 0건. 375px 차트 눈금과 원표 가로 넘침 재확인.
- 임시 검증 라우트는 삭제했으며 배포물에 포함하지 않음.

## 운영 DB 적용 — 2026-09-08

사용자 승인에 따라 `20260908005001_firm_headcount_and_audit_input_views.sql`을 운영 Supabase(`xvifzicrjmbfqaepcfpp`)에 적용했다. 마이그레이션 장부 이름은 `firm_headcount_and_audit_input_views`이며, 적용 도구가 트랜잭션을 감싸므로 파일의 `begin;`·`commit;`만 제외하고 본문은 동일하다.

- 적용 전 상태: 두 뷰 모두 미존재. 원본 `cpa_firm_annual_form_cell`·`cpa_firm_profile_yearly`·`cpa_firm_audit_input_yearly`와 참조 컬럼은 모두 존재. 대상 데이터는 HR 셀 3,605행·감사 투입 5,768행·보고기간 721행이다.
- 적용 후 `pg_class.reloptions`에서 두 뷰의 `security_invoker=true`를 확인했다. anon·authenticated·service_role의 SELECT 권한은 이 프로젝트의 public 스키마 기본 권한과 같은 범위이며, 원본 테이블의 RLS가 invoker 기준으로 그대로 적용된다.
- 삼일회계법인(`firm_id=1`) 보고기간 **2024-07-01 ~ 2025-06-30**(제55기, 2025 결산 공시 / 2024 보고기간 시작연도)에서 공인회계사 3,073명, 등록회계사 2,512명, 수습 260명, 사원 301명, 기타직원 1,190명을 확인했다. 인원 행의 `unit_multiplier`는 모두 null이다.
- 같은 보고기간의 감사 투입은 총 2,118명·2,142,905시간이며, 근속 구간 7개 인원 합(233+222+541+366+366+168+222)이 총계와 일치한다. 1인당 1,011.8시간으로 사전 fixture 검증값과 같다.
- `set local role anon`으로 두 뷰를 조회해 같은 값과 전체 행 수(3,605·5,768)를 확인했다. 익명 공개 조회 경로가 실제로 동작한다.
- 적용 후 security advisor에 두 뷰 관련 신규 지적은 없다. 다만 조회된 advisor 스냅샷의 관측 시각이 적용 이전이므로, `security_invoker`는 advisor가 아니라 `pg_class` 직접 조회로 확인한 것이다. 기존 경고(pg_net, 유출 비밀번호 검사, 의도된 무정책 테이블)는 그대로다.

프런트엔드 코드는 아직 배포하지 않았다. 미푸시 커밋 4건(`1c9834a`~`cbdf014`)의 원격 반영과 Vercel 배포, 운영 화면에서의 표시 확인은 별도 단계다.
